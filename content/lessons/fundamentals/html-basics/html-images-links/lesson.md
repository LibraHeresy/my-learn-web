# 图片与链接 — 丰富你的音乐卡片

::music-analogy
`<img>` 像**乐谱中的插图**，为页面增添视觉元素；`<a>` 链接像**反复记号**，指向另一个地方。
::

::explain{title="添加图片"}
纯文字太单调了——就像一份只有音符没有指法的谱子。img 标签可以在网页中插入图片，它是单标签——不需要结束标签，就像单击泛音，竹头点一下弦面立刻离开。

src 属性告诉浏览器图片在哪里（📍特有属性，只有 img/audio/video 等需要"资源文件"的标签才有），alt 属性在图片显示不出来时显示替代文字（📍特有属性——就像给一首没有录音的扬琴新作写一段文字描述）。
```html
<img src="图片地址" alt="图片描述">
```
- `src` — 图片的地址（可以是网上链接）
- `alt` — 图片加载不出来时显示的文字

错误示范：如果 src 地址写错了 → 图片显示不出来，页面显示 alt 文字。如果连 alt 都不写 → 屏幕阅读器什么都读不出来，就像乐谱没有曲名。
::

::explain{title="添加链接"}
a 标签可以创建超链接——点击后跳转到另一个页面（内联元素，在文字流中不换行）。href 属性指定跳转的目标地址（📍特有属性，必须写完整网址含 https://）。就像乐谱上的反复记号 D.C.——指向另一个位置，告诉演奏者"跳过去"。
```html
<a href="网址">点击这里</a>
```
- `href` — 要跳转的网址
- 标签中间的文字是显示给用户看的

错误示范：href 不写 https:// → 浏览器以为这是你网站里的一个文件名，找不到！必须写完整的网址，就像反复记号必须指明回到哪里。
::

::example{title="完整示例"}
就像练一首曲子先分手再合手，我们也分三步来构建这张音乐卡片：
**第 1 步：先写标题**
```html
<h1>肖邦</h1>
```
**第 2 步：加入图片**
```html
<h1>肖邦</h1>
<img src="https://oss.tan8.com/yuepuku/155/77798/77798_prev.jpg" alt="作曲家肖像">
```
→ 翻译：插入一张图片，文件在 src 指定的地址，如果显示不出来就显示 alt 指定的"作曲家肖像"五个字。
**第 3 步：加上介绍文字和链接**
```html
<h1>肖邦</h1>
<img src="https://oss.tan8.com/yuepuku/155/77798/77798_prev.jpg" alt="作曲家肖像">
<p>
  了解更多，请访问
  <a href="https://zh.wikipedia.org/wiki/肖邦">肖邦的维基百科</a>
</p>
```
→ 翻译：加一段介绍文字，其中"肖邦的维基百科"是可以点击的链接，href 指定了点击后跳转的网址。
::
