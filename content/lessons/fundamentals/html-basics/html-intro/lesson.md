# 认识 HTML

::music-analogy
HTML 就像五线谱，它决定页面上有什么内容。
::

::explain{title="什么是 HTML？"}
HTML 是网页的骨架。浏览器会根据 HTML 的结构，决定页面上显示什么内容。
::

::example{title="看一个例子"}
```html
<h1>你好，音乐世界！</h1>
<p>我开始了我的编程之旅。</p>
```
::

::task{title="动手试试"}
:::step{purpose="体验修改代码后页面立即变化" expected="标题变成你写的文字"}
把 `<h1>` 改成你自己的名字。
:::

:::step{purpose="练习新增一个元素" expected="页面上多出一行新的段落"}
在下面再添加一个 `<p>` 标签。
:::
