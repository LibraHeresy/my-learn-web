# 链接与导航

::music-analogy
超链接就像乐曲中的转调，把你带到新的主题与段落。
::

::explain{title="a 标签"}
`<a href="...">` 是网页的“通道”。它可以指向站内页面，也可以指向外部网站。
::

::example{title="一个链接示例"}
```html
<a href="https://developer.mozilla.org/">MDN Web Docs</a>
```
::

::task{title="本地练习（local）"}
:::step{purpose="练习相对路径" expected="点击后能从首页跳到 about 页面"}
创建 `index.html` 和 `about.html` 两个文件，用相对路径链接它们。
:::

:::step{purpose="练习新标签页打开" expected="点击后在新标签页打开外部网站"}
给外部链接加上 `target="_blank"`。
:::
::
