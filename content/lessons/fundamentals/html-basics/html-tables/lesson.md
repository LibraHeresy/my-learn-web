# 表格 — 整理你的音乐数据

::music-analogy
表格就像一张**曲目单**或**节目表**——用行列分明的结构组织信息。每一行是一个条目，每一列是一种属性，就像节目中第一列是作曲家、第二列是曲目、第三列是时长。
::

::explain{title="表格的基本结构"}
表格由外到内有三层标签：
- `<table>` — 整个表格的容器
- `<tr>` — **表行**（table row），一行
- `<td>` — **表单元格**（table data），一个格子
```html
<table>
  <tr>
    <td>巴赫</td>
    <td>巴洛克</td>
    <td>德国</td>
  </tr>
  <tr>
    <td>肖邦</td>
    <td>浪漫主义</td>
    <td>波兰</td>
  </tr>
</table>
```
每一对 `<tr></tr>` 是一行，里面每个 `<td></td>` 是一个格子。
::

::explain{title="表头与分区"}
`<th>` 代替 `<td>` 可以做**表头**（加粗居中）：
```html
<tr>
  <th>作曲家</th>
  <th>时期</th>
  <th>国家</th>
</tr>
```
`<thead>`、`<tbody>` 把表头和表体分开，方便分别设置样式：
```html
<table>
  <thead>
    <tr><th>列1</th><th>列2</th></tr>
  </thead>
  <tbody>
    <tr><td>数据1</td><td>数据2</td></tr>
  </tbody>
</table>
```
::

::explain{title="合并单元格"}
有时候一个格子需要跨越多列或多行，用 `colspan` 和 `rowspan`：
- `colspan="2"` — 跨 2 列（水平合并）
- `rowspan="3"` — 跨 3 行（垂直合并）
```html
<td colspan="2">这格占了两个列的宽度</td>
```
就像节目单中的"中场休息"横跨整页！
::
