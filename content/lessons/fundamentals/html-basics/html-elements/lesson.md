# HTML 元素与标签

::music-analogy
{{term:HTML}} 元素就像乐谱上的小节与音符，每一个都有自己的位置与作用。
::

::explain{title="标签与元素"}
你写下的 `<p>...</p>` 是标签（tag），浏览器理解后形成的是元素（element）。
::

::task{title="本地练习（local）"}
:::step{purpose="感受结构与嵌套" expected="能在浏览器里看到标题与段落"}
在本地新建一个 `index.html`，写一个 `<h1>` 和两个 `<p>`。
:::

:::step{purpose="理解嵌套关系" expected="列表里出现 3 个条目"}
添加一个 `<ul>`，里面放 3 个 `<li>`。
:::
