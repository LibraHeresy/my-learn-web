# 条件判断 — 代码的分岔路口

::music-analogy
`if/else` 就像乐谱中的**反复记号**——满足条件就跳转，不满足就继续。也像**评委打分**：如果音准正确就给通过，否则请再练一遍。条件判断让代码有了"决策能力"。
::

::explain{title="if 语句 — 代码的\"如果\""}
if/else 条件判断让代码在不同情况下执行不同操作——就像练琴时"如果音准不对就停下来调整，否则继续往下弹"。比较运算符：=== 等于、!== 不等于、> 大于、< 小于、>= 大于等于、<= 小于等于。
```js
let score = 85;
if (score >= 80) {
  console.log("优秀！");
}
```就像评委打分：分数 ≥ 80 才算优秀。
::

::explain{title="else 与 else if — 多分岔路"}
`else` 处理"否则"的情况，`else if` 添加更多分岔：
```js
let score = 75;
if (score >= 90) {
  console.log("金奖！🥇");
} else if (score >= 80) {
  console.log("银奖！🥈");
} else if (score >= 60) {
  console.log("铜奖🥉");
} else {
  console.log("继续努力！");
}
```逻辑运算符：
- `&&` — 并且（两个条件都成立）
- `||` — 或者（任意一个成立）
```js
if (score >= 80 && score < 90) {
  console.log("优秀但未达金奖");
}
```
::

::example{title="看例子"}
下面的代码是一个作曲家答题器。输入答案后点击提交，JS 判断你的答案是否正确：
```js
let answer = document.querySelector("#answer").value;
if (answer === "肖邦") {
  display.textContent = "✓ 回答正确！";
} else {
  display.textContent = "✗ 再想想？提示：他是波兰人";
}
```切换到 JS 标签页，看 submit 按钮的点击事件中完整的 if/else 逻辑。
::

::task{title="动手试试 ✨"}
:::step{purpose="让你直观感受 `if/else` 的分支逻辑——同样的代码，输入不同，走的路径完全不同。就像音乐比赛评委会根据选手表现给出「晋级」或「淘汰」两种完全不同的结果。" expected="输入「肖邦」→ 绿色提示「回答正确！」；输入其他名字 → 红色提示「再想想？」。同一段代码根据条件走出了两条不同的路。"}
在预览区的输入框中输入「肖邦」，点击「提交答案」，观察反馈信息。再输入一个错误的名字（如「李白」），看反馈有什么不同
:::

:::step{purpose="`else if` 让你处理「中间情况」——不是对也不是错，而是「还没输入」。这就像音乐比赛中除了「晋级」和「淘汰」，还有「请先上台」的第三种情况。多层分支是构建复杂决策逻辑的基础。" expected="空输入时显示金色提示「请先输入一个名字哦 ~」，既不是正确也不是错误，而是第三种专门处理空值的情况。"}
空着输入框直接点击提交，观察 `else if` 分支给出的特殊提示。理解 `if → else if → else` 的三层判断结构
:::

:::step{purpose="`&&`（逻辑与）让你把多个条件「绑在一起」——全部满足才通过。就像「只有既是古典主义时期、又是德国作曲家」才归入某个分类。`&&` 和 `||` 是构建复杂判断的核心工具。" expected="只有当两个条件都满足时，才执行该分支的代码。如果只满足一个，则跳过这个分支走到下一个判断——逻辑运算符就像层层安检，一道不通过就不放行。"}
在 if 条件中试试用 `&&` 组合多个判断条件。比如：在正确回答的同时增加额外判断，如 `answer === "肖邦" && answer.length > 1`，体会逻辑与的「双重把关」效果
:::

:::step{purpose="练习扩展条件分支——不是简单地加一个 if，而是在 `if → else if → else if → else` 链中找到合适的位置插入。每个分支处理一种特定情况，分支之间互斥。" expected="输入「李斯特」→ 显示特殊提示（既不是「正确」的绿色，也不是「错误」的红色，而是第三种独特反馈）；输入其他名字 → 显示通用的错误提示。你的判断逻辑更精细了。"}
挑战：在已有的 if-else if-else 链中增加一个新分支，判断是否输入了「李斯特」。给出区别于正确答案的特殊提示，如「李斯特也是一位伟大的钢琴家，但标准答案是肖邦」
:::
