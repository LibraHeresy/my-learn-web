# 音乐展示页

::music-analogy
这是一次小型独奏排练：把结构、样式和一点点交互组合成完整作品。
::

::explain{title="目标"}
做一个单页展示：标题、专辑封面、曲目列表、一个“播放”按钮（只做交互提示即可）。
::

::task{title="项目步骤（local）"}
:::step{purpose="先把结构搭起来" expected="页面有标题、图片和列表"}
新建 `index.html`，加入 `<h1>`、`<img>`、`<ul><li>`。
:::

:::step{purpose="加入样式" expected="整体更像一个作品页"}
新建 `style.css`，做出合适的间距与字体。
:::

:::step{purpose="加入一点交互" expected="点击按钮会弹出提示或改变文字"}
新建 `script.js`，点击“播放”按钮时修改按钮文字或 `alert` 一句。
:::
::
