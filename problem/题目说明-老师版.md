# 题目说明与验收手册（老师版）

> 本手册供你（指导老师）验收学员成果时使用。含每道题的知识点、验收标准、**完整参考答案代码**、常见错误，以及整体难度曲线的设计思路。
>
> ⚠️ 本手册含全部答案，请勿发给学员。

---

## 一、整体设计思路

### 1. 目标
让学员通过 60 道题，从"看懂概念"到"独立输出有效代码"，最终达到**初级前端开发**的求职水平。

### 2. 难度曲线
```
阶段1  ⭐       填空式，纯函数，自动测试
阶段2  ⭐⭐     小算法，纯函数，自动测试
阶段3  ⭐⭐     页面交互，手动验收
阶段4  ⭐⭐⭐   异步/闭包，纯函数+自动测试
阶段5  ⭐⭐⭐   Vue 组件化，手动验收
阶段6  ⭐⭐⭐⭐ 综合项目，从零构建
```

**核心原则**：前两个阶段坚决不让学员从零写，通过"自动测试"提供即时反馈，建立成就感；中间阶段逐步放权；最后阶段完全独立。

### 3. 验收方式
- **阶段 1、2、4**：学员自行点击"运行测试"，全部 ✅ 通过即可。你只需抽查。
- **阶段 3、5**：学员打开 HTML 在浏览器验证交互，你对照"验收清单"逐项检查。
- **阶段 6**：学员提供可运行项目，你检查功能完整性 + 代码规范。

## 二、逐题验收标准与参考答案

### 阶段 1：JS 基本功回炉

#### 01 两数之和
- **知识点**：函数定义、参数、返回值
- **验收标准**：`sum(1, 2) === 3`，`sum(-1, 5) === 4`
- **参考答案**：
```js
function sum(a, b) {
  return a + b;
}
```
- **常见错误**：忘记 `return`、函数名拼写错误

#### 02 判断奇偶
- **知识点**：取模运算符 `%`
- **验收标准**：`isEven(4) === true`，`isEven(3) === false`
- **参考答案**：
```js
function isEven(n) {
  return n % 2 === 0;
}
```
- **常见错误**：写成 `n % 2 === 1` 漏掉负数情况

#### 03 数组最大值
- **知识点**：`for` 循环、比较
- **验收标准**：`findMax([1,5,3]) === 5`，`findMax([-3,-1,-7]) === -1`
- **参考答案**：
```js
function findMax(arr) {
  let max = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
  }
  return max;
}
```
- **常见错误**：初始值设 0 导致负数数组出错

#### 04 统计字符出现次数
- **知识点**：字符串遍历
- **验收标准**：`countChar('hello', 'l') === 2`
- **参考答案**：
```js
function countChar(str, char) {
  let count = 0;
  for (let i = 0; i < str.length; i++) {
    if (str[i] === char) count++;
  }
  return count;
}
```
- **常见错误**：用 `str.indexOf` 只能找第一个

#### 05 过滤偶数
- **知识点**：`Array.prototype.filter`
- **验收标准**：`filterEven([1,2,3,4])` 返回 `[2,4]`
- **参考答案**：
```js
function filterEven(arr) {
  return arr.filter(n => n % 2 === 0);
}
```
- **常见错误**：没有 `return`、返回原始数组

#### 06 反转字符串
- **知识点**：`split` / `reverse` / `join`
- **验收标准**：`reverseStr('abc') === 'cba'`
- **参考答案**：
```js
function reverseStr(str) {
  return str.split('').reverse().join('');
}
```
- **常见错误**：直接 `str.reverse` 报错（字符串无此方法）

#### 07 判断回文
- **知识点**：字符串反转 + 比较
- **验收标准**：`isPalindrome('level') === true`
- **参考答案**：
```js
function isPalindrome(str) {
  return str === str.split('').reverse().join('');
}
```
- **常见错误**：没处理大小写或空格

#### 08 数组去重
- **知识点**：`Set`
- **验收标准**：`unique([1,2,2,3])` 返回 `[1,2,3]`
- **参考答案**：
```js
function unique(arr) {
  return [...new Set(arr)];
}
```
- **常见错误**：返回 `Set` 对象而非数组

#### 09 累加求和
- **知识点**：`for` 循环累加
- **验收标准**：`sumTo(5) === 15`
- **参考答案**：
```js
function sumTo(n) {
  let sum = 0;
  for (let i = 1; i <= n; i++) {
    sum += i;
  }
  return sum;
}
```
- **常见错误**：循环条件写成 `< n` 漏掉 n

#### 10 遍历打印对象
- **知识点**：对象、`for...in`
- **验收标准**：`printObj({name:"Tom", age:20})` 返回 `["name: Tom", "age: 20"]`
- **参考答案**：
```js
function printObj(obj) {
  const result = [];
  for (let key in obj) {
    result.push(key + ': ' + obj[key]);
  }
  return result;
}
```
- **常见错误**：写成 `obj.key` 而非 `obj[key]`

### 阶段 2：JS 进阶

#### 11 reduce 累加求和
- **知识点**：`reduce`
- **验收标准**：`sumWithReduce([1,2,3,4]) === 10`
- **参考答案**：
```js
function sumWithReduce(arr) {
  return arr.reduce((acc, cur) => acc + cur, 0);
}
```

#### 12 reduce 统计词频
- **知识点**：`reduce` 进阶
- **验收标准**：`countWords(["a","b","a"])` 返回 `{a:2, b:1}`
- **参考答案**：
```js
function countWords(arr) {
  return arr.reduce((map, cur) => {
    map[cur] = (map[cur] || 0) + 1;
    return map;
  }, {});
}
```

#### 13 sort 对象数组排序
- **知识点**：`sort` 自定义比较
- **验收标准**：按年龄升序，不修改原数组
- **参考答案**：
```js
function sortByAge(arr) {
  return [...arr].sort((a, b) => a.age - b.age);
}
```

#### 14 find/some/every 运用
- **知识点**：数组判断方法
- **验收标准**：正确返回 hasEven、allPositive、firstNegative
- **参考答案**：
```js
function analyze(arr) {
  return {
    hasEven: arr.some(n => n % 2 === 0),
    allPositive: arr.every(n => n > 0),
    firstNegative: arr.find(n => n < 0),
  };
}
```

#### 15 对象 keys/values/entries
- **知识点**：`Object.keys` / `Object.values`
- **验收标准**：返回 keys、values、count
- **参考答案**：
```js
function objectSummary(obj) {
  return {
    keys: Object.keys(obj),
    values: Object.values(obj),
    count: Object.keys(obj).length,
  };
}
```

#### 16 字符串处理实战
- **知识点**：大小写转换、拼接
- **验收标准**：`formatName("john", "DOE") === "John Doe"`
- **参考答案**：
```js
function formatName(firstName, lastName) {
  const cap = s => s.charAt(0).toUpperCase() + s.slice(1).toLowerCase();
  return cap(firstName) + ' ' + cap(lastName);
}
```

#### 17 模拟微任务宏任务
- **知识点**：事件循环
- **验收标准**：按 sync → micro → macro 排序
- **参考答案**：
```js
function taskOrder(tasks) {
  const sync = tasks.filter(t => t.type === 'sync');
  const micro = tasks.filter(t => t.type === 'micro');
  const macro = tasks.filter(t => t.type === 'macro');
  return [...sync, ...micro, ...macro].map(t => t.name);
}
```

#### 18 深拷贝进阶
- **知识点**：递归、WeakMap 处理循环引用
- **验收标准**：拷贝后独立，能处理循环引用
- **参考答案**：
```js
function deepClone2(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (map.has(obj)) return map.get(obj);
  const result = Array.isArray(obj) ? [] : {};
  map.set(obj, result);
  for (let key in obj) {
    result[key] = deepClone2(obj[key], map);
  }
  return result;
}
```

#### 19 正则提取数字
- **知识点**：正则 `\d+`
- **验收标准**：`extractNumbers("a1b22c333")` 返回 `[1,22,333]`
- **参考答案**：
```js
function extractNumbers(str) {
  const matches = str.match(/\d+/g);
  return matches ? matches.map(Number) : [];
}
```

#### 20 对象数组按字段去重
- **知识点**：Set/Map 去重
- **验收标准**：按指定字段去重，保留第一个
- **参考答案**：
```js
function uniqueByKey(arr, key) {
  const seen = new Set();
  return arr.filter(item => {
    if (seen.has(item[key])) return false;
    seen.add(item[key]);
    return true;
  });
}
```

### 阶段 3：数据结构与算法

#### 21 斐波那契数列
- **知识点**：迭代 / 递归
- **验收标准**：`fib(5) === 5`，`fib(10) === 55`
- **参考答案**（迭代，推荐）：
```js
function fib(n) {
  if (n === 0) return 0;
  if (n === 1) return 1;
  let a = 0, b = 1;
  for (let i = 2; i <= n; i++) {
    let temp = a + b;
    a = b;
    b = temp;
  }
  return b;
}
```
- **常见错误**：递归无基准条件导致死循环

#### 22 判断质数
- **知识点**：循环、取模、`Math.sqrt` 优化
- **验收标准**：`isPrime(7) === true`，`isPrime(4) === false`
- **参考答案**：
```js
function isPrime(n) {
  if (n < 2) return false;
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) return false;
  }
  return true;
}
```
- **常见错误**：漏掉 1 和 2 的边界

#### 23 冒泡排序
- **知识点**：双层循环、交换
- **验收标准**：`bubbleSort([5,2,8,1])` 返回 `[1,2,5,8]`
- **参考答案**：
```js
function bubbleSort(arr) {
  const result = [...arr];
  for (let i = 0; i < result.length - 1; i++) {
    for (let j = 0; j < result.length - 1 - i; j++) {
      if (result[j] > result[j + 1]) {
        [result[j], result[j + 1]] = [result[j + 1], result[j]];
      }
    }
  }
  return result;
}
```
- **常见错误**：内层循环边界写错（应为 `j < len - 1 - i`）

#### 24 二分查找
- **知识点**：双指针、`while` 循环
- **验收标准**：`binarySearch([1,3,5,7,9], 5) === 2`
- **参考答案**：
```js
function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left <= right) {
    let mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```
- **常见错误**：`left < right` 漏掉边界元素；忘记 `return -1`

#### 25 找出重复数字
- **知识点**：Set / 哈希表
- **验收标准**：`findDuplicate([1,2,3,2]) === 2`
- **参考答案**：
```js
function findDuplicate(arr) {
  const set = new Set();
  for (let n of arr) {
    if (set.has(n)) return n;
    set.add(n);
  }
  return -1;
}
```
- **常见错误**：双循环 O(n²) 虽可行但不优

#### 26 两个数组交集
- **知识点**：Set
- **验收标准**：`intersection([1,2,3], [2,3,4])` 返回 `[2,3]`
- **参考答案**：
```js
function intersection(arr1, arr2) {
  const set = new Set(arr2);
  return [...new Set(arr1.filter(x => set.has(x)))];
}
```
- **常见错误**：结果未去重

#### 27 判断异位词
- **知识点**：排序 / 字符计数
- **验收标准**：`isAnagram('listen', 'silent') === true`
- **参考答案**：
```js
function isAnagram(s1, s2) {
  if (s1.length !== s2.length) return false;
  return s1.split('').sort().join('') === s2.split('').sort().join('');
}
```
- **常见错误**：未处理长度不等的情况

#### 18 统计元素频次
- **知识点**：Map / 对象
- **验收标准**：`countFreq(['a','b','a'])` 返回 `{a:2, b:1}`
- **参考答案**：
```js
function countFreq(arr) {
  const map = {};
  for (let x of arr) {
    map[x] = (map[x] || 0) + 1;
  }
  return map;
}
```
- **常见错误**：直接 `map[x] + 1` 遇到 `undefined` 变 `NaN`

#### 29 扁平化嵌套数组
- **知识点**：递归、`Array.isArray`
- **验收标准**：`flatten([1,[2,[3]]])` 返回 `[1,2,3]`
- **参考答案**：
```js
function flatten(arr) {
  const result = [];
  for (let item of arr) {
    if (Array.isArray(item)) {
      result.push(...flatten(item));
    } else {
      result.push(item);
    }
  }
  return result;
}
```
- **常见错误**：只处理一层，没递归

#### 30 深拷贝
- **知识点**：递归、引用类型
- **验收标准**：拷贝后修改原对象不影响副本
- **参考答案**：
```js
function deepClone(obj) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (Array.isArray(obj)) {
    return obj.map(item => deepClone(item));
  }
  const result = {};
  for (let key in obj) {
    result[key] = deepClone(obj[key]);
  }
  return result;
}
```
- **常见错误**：浅拷贝导致引用共享；漏掉 null 判断

### 阶段 5：JS 进阶（异步）

#### 41 Promise 延时
- **验收标准**：返回 Promise，3 秒后 resolve
- **参考答案**：
```js
function delay(ms) {
  return new Promise((resolve) => {
    setTimeout(resolve, ms);
  });
}
```

#### 42 async/await 延时
- **验收标准**：用 `async` 函数 + `await` 等待延时
- **参考答案**：
```js
async function wait() {
  await delay(3000);
  console.log('完成');
}
```

#### 43 fetch 请求
- **验收标准**：请求 JSONPlaceholder 成功并返回数据
- **参考答案**：
```js
async function getPosts() {
  const res = await fetch('https://jsonplaceholder.typicode.com/posts');
  const data = await res.json();
  return data;
}
```
- **常见错误**：忘记 `.json()` 二次处理

#### 44 防抖 debounce
- **验收标准**：连续触发只执行最后一次
- **参考答案**：
```js
function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

#### 45 节流 throttle
- **验收标准**：规定时间内只执行一次
- **参考答案**：
```js
function throttle(fn, interval) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn.apply(this, args);
    }
  };
}
```

#### 46 发布订阅
- **验收标准**：`on` 订阅、`emit` 触发、`off` 取消
- **参考答案**：
```js
class EventBus {
  constructor() { this.events = {}; }
  on(name, fn) {
    if (!this.events[name]) this.events[name] = [];
    this.events[name].push(fn);
  }
  emit(name, ...args) {
    (this.events[name] || []).forEach(fn => fn(...args));
  }
  off(name, fn) {
    this.events[name] = (this.events[name] || []).filter(f => f !== fn);
  }
}
```

#### 47 闭包计数器
- **验收标准**：每次调用计数 +1，状态保持
- **参考答案**：
```js
function createCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}
```

#### 48 call/apply/bind

#### 50 手写 Promise
- **验收标准**：能 `then` 和 `catch`，支持链式
- **参考答案**（简化版）：
```js
class MyPromise {
  constructor(executor) {
    this.state = 'pending';
    this.value = undefined;
    this.callbacks = [];
    const resolve = (value) => {
      if (this.state !== 'pending') return;
      this.state = 'fulfilled';
      this.value = value;
      this.callbacks.forEach(cb => cb.onFulfilled(value));
    };
    const reject = (reason) => {
      if (this.state !== 'pending') return;
      this.state = 'rejected';
      this.value = reason;
      this.callbacks.forEach(cb => cb.onRejected(reason));
    };
    executor(resolve, reject);
  }
  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => {
      const handle = () => {
        try {
          if (this.state === 'fulfilled') resolve(onFulfilled(this.value));
          else if (this.state === 'rejected') reject(onRejected(this.value));
        } catch (e) { reject(e); }
      };
      if (this.state === 'pending') {
        this.callbacks.push({ onFulfilled: () => handle(), onRejected: () => handle() });
      } else {
        handle();
      }
    });
  }
}
```
- **说明**：这是最难的一题，可作选做/加餐，简化版即可。

## 三、学员常见错误汇总（重点观察）

1. **忘记 `return`**：阶段 1 最高频错误
2. **字符串/数组方法混用**：`str.reverse` 这种
