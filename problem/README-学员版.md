# 前端闯关练习手册（学员版）

欢迎来到你的前端练习之旅！这套题目会带你从"看懂代码"走向"独立写代码"。

## 怎么使用这套题目

1. **按顺序做**：从阶段 1 开始，不要跳题。
2. **每题三步法**：
   - 第一步：先用大白话说出你的思路（说不清就再想想）
   - 第二步：写代码（可以查资料，但一定要自己敲）
   - 第三步：点"运行测试"，看结果，报错了就自己 Debug
3. **遇到报错先别问**：先自己读报错信息、`console.log` 变量，实在卡住 15 分钟再求助。
4. **做完一题默写一题**：阶段 1、2 的题，第二天合上书再默写一遍。

## 每日建议

- 每天 1-2 题，每题 30-60 分钟
- 不求快，求"每道题都真正跑通"
