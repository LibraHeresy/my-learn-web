# 三段工作流 — HTML → CSS → JS 的正确顺序

:::analogy
盖房子永远先搭骨架（HTML）、再装修（CSS）、最后接通水电（JS）。跳过任何一步都会让后面的工作混乱——顺序错了，返工就多了。
:::

:::prerequisite
**本节你需要知道这些词：**

- **HTML基础**：网页的骨架——用标签搭建页面结构
- **CSS基础**：控制网页的外观——颜色、布局、字体等
- **JS变量和函数**：变量是存储数据的容器，函数是一段可重复使用的代码
:::

:::explain{title="这一章你会学什么"}
这一章不是增加一门新语言，而是开始训练“怎么把前面学过的东西组织起来”。你会学到：
- 写页面的正确顺序
- 更好的命名、拆分与调试方式
- 怎样从“会写代码”走到“写得更稳”

学完这一章，你会开始建立真正的前端工作流意识。
:::

:::explain{title="为什么这章重要"}
这一章对应的不是单一语法点，而是 **工作流**。  
在工程语境里，你以后会频繁遇到这些词：**拆解问题**、**数据驱动**、**事件委托**、**调试流程**。  
它们解决的是“如何把混乱变成可维护的代码”。
:::

:::hint{title="给已经会一点、但还总写乱的你"}
如果你发现自己会写 HTML、CSS、JS，却一做综合页面就容易乱，这很正常。  
这说明你不是基础没学会，而是开始进入“组织能力”的阶段了。  
这一章就是帮你建立这种能力。
:::

:::explain{title="为什么顺序很重要？"}
在此之前，你已经学会了三门"工具"：
- **HTML**（HyperText Markup Language，超文本标记语言）— 页面的骨架
- **CSS**（Cascading Style Sheets，层叠样式表）— 页面的外观
- **JS / JavaScript** — 页面的"大脑"，让它能听你的指令做出反应
但从零开始构建一个页面时，**按什么顺序写**比写什么更重要。
标准的三段工作流：
**第一步：HTML 结构** — 把页面上所有内容先用标签写出来
- 标题、段落、图片、按钮……先全部摆上去
- 不关心颜色、大小、位置
- 就像先把零件写在设计图上
**第二步：CSS 样式** — 给每个元素穿上合适的"衣服"
- 颜色、字体、间距、背景……
- 从外到内，从大到小
- 就像给毛坯房刷墙和铺地板
**第三步：JS（JavaScript）交互** — 让页面"动起来"
- 点击按钮会发生什么？
- 用户输入后如何响应？
- 就像给电器接上电源——按开关灯就亮，按另一个就灭
> 💡 **关于 JS 和 JavaScript**：JS 是 JavaScript 的缩写，它们是同一个东西。就像"电视机"被叫做"电视"——JS 就是 JavaScript 的昵称。
:::

:::explain{title="倒过来写会怎样？"}
新手常犯的错误是：一上来就写 CSS 或 JS，结果 HTML 结构老在变，前面写的样式和逻辑全乱了。
就像先贴墙纸再改墙体结构——每次改结构都得重新贴墙纸，浪费时间。
**正确做法：先让 HTML 稳定下来，确认结构是对的，再动手写 CSS 和 JS。** 这就是之前把三门语言分开教的原因——先熟悉每件"工具"，现在协作篇教你如何一起执行它们。
:::

:::explain{title="两个常用的数学工具"}
在写 JS 交互时，经常需要"随机选一个"。JavaScript 内置了两个好用的数学方法：
`Math.random()` — 生成随机数
```js
Math.random(); // 返回 0 到 1 之间的随机小数，比如 0.3847、0.9215
```
每次调用都会返回不同的值，就像伸手到袋子里随机摸一颗糖。
`Math.floor()` — 向下取整
```js
Math.floor(3.8);  // 结果是 3
Math.floor(7.1);  // 结果是 7
Math.floor(0.95); // 结果是 0
```
把小数的小数部分直接切掉，只留整数部分。
**搭配使用 — 获取随机数组索引：**
```js
let arr = ["苹果", "香蕉", "橘子"];
let i = Math.floor(Math.random() * arr.length);
// Math.random()       → 0~1 之间的小数
// Math.random() * 3   → 0~3 之间的小数（如 1.2、2.8）
// Math.floor(...)     → 向下取整（如 1.2→1, 2.8→2）
// 最终 i 是 0、1、2 中的一个（三个索引）
arr[i]; // 随机选中的元素
```
这两个方法在后续课程中会经常用到！
:::

:::recap
你学会了前端开发的三段工作流——先写 HTML 结构（把内容全部摆上去），再写 CSS 样式（美化外观），最后写 JS 交互（让页面动起来）。按这个顺序写，不会因为改结构而让样式和逻辑全乱了。
:::
