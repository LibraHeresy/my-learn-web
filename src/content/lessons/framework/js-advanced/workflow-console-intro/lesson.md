# 读懂浏览器的"故障灯" — 开发者控制台入门

:::analogy
浏览器控制台就像汽车仪表盘——引擎故障灯亮了，你看一眼就知道哪里出了问题。代码报错了，控制台告诉你哪一行、什么错。学会读它，你就不怕报错了。
:::

:::prerequisite
**本节你需要知道这些词：**

- **JS基础**：JavaScript 的基本用法——变量、数据类型、最基本的操作
:::

:::explain{title="错误不是失败，是路标"}
写代码一定会遇到错误。即便是工作了 20 年的工程师，也天天看报错信息。区别在于：他们不慌张，而是**先看控制台**。
当你的 JS 不工作时，第一个动作不是盯着代码瞎猜——**先打开浏览器控制台**：
- Windows：按 `F12`，点击 "Console"（控制台）标签
- Mac：按 `Cmd + Option + J`
- 或者右键页面 → "检查" → "Console"
红色文字就是错误信息。**红色不可怕，可怕的是不读红字。** 就像汽车仪表盘的故障灯亮了你会去看——控制台就是代码的"仪表盘"。
:::

:::explain{title="读懂红字错误信息"}
每条错误通常包含三部分信息：
**1. 错误类型** — 告诉你"出了什么问题"：
- `ReferenceError: xxx is not defined` — 变量没声明就用了
- `TypeError: xxx is not a function` — 把不是函数的东西当函数调用了
- `SyntaxError: Unexpected token` — 语法错误，漏了括号或引号
**2. 文件名 + 行号** — 告诉你"在哪里出的错"：
- 例如 `at 3:15` 表示第 3 行第 15 个字符
**3. 错误消息** — 英文描述的具体原因
现在编辑器里的代码有 5 个故意埋下的错误。打开控制台，一个一个找出并修复它们！
:::

:::task{title="动手试试 ✨"}
::::step{purpose="学会打开控制台是所有前端调试的第一步。红色错误信息不是惩罚，而是路标——就像导航软件告诉你"前方路口左转"，它精确地指出错误类型和位置。" expected="控制台出现红色错误信息，包含错误类型（ReferenceError/TypeError）、文件名和行号。"}
打开浏览器控制台（F12），查看红色错误信息——第一条错误告诉你第几行出了什么错？
::::

::::step{purpose="ReferenceError 是最常见的错误类型——变量未定义。学会从错误信息中的行号定位代码，而不是盲目猜测，能大幅缩短调试时间。" expected="修复后再次运行，第一条红色错误消失，第二条错误出现——就像修好热水器后才发现水龙头也漏水——问题要一个一个解决。"}
根据第一条错误提示（document 拼写为 docuement），找到对应代码行并修复
::::

::::step{purpose="错误之间会互相掩盖——一个错误导致后续代码不执行。这就像多米诺骨牌——第一张倒了，后面全倒。逐个修复错误，直到所有代码顺畅运行。" expected="控制台变干净（无红色错误），点击收藏按钮后卡片状态正常切换，消息文字正确显示。"}
继续修复剩余 4 个错误：querySelector 大小写 → 变量名不一致 → textContent 拼写错误 → innerHTML 大小写
::::

:::

:::hint{title="需要一点线索？"}
5 个错误的类型分别是：
1. `document` 拼写错误 — ReferenceError
2. `querySelector` 大小写错误 — TypeError
3. 变量名不一致（声明和使用的名字不同）
4. DOM 方法名拼写错误
5. DOM 属性名拼写错误
控制台会精确告诉你每一个错误的位置。耐心读完红字！
:::

:::recap
你学会了打开浏览器控制台（F12）读懂红色错误信息——每条错误都告诉你错误类型、文件名和行号。遇到代码不工作时，第一个动作不是瞎猜，而是先看控制台报了什么错。
:::
