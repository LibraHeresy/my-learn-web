# 安装你的"乐器"：Node.js

:::music-analogy
学音乐之前，你得先有一件乐器。学前端工程化之前，你得先有 **Node.js**——它不是用来写代码的，而是用来**运行工具的**。就像钢琴本身不演奏，但有了它你才能弹出所有曲子。
:::

:::explain{title="Node.js 是什么？"}
到目前为止，你的 JavaScript 都运行在**浏览器**里。Node.js 让 JavaScript 可以运行在**你的电脑**上——就像以前只能在音乐教室弹钢琴，现在你家里也有了一台。
有了 Node.js，你才能使用：
- **npm** — 包管理器（相当于一个巨大的乐谱库）
- **Vite** — 构建工具（自动搭建排练厅）
- **终端命令** — 用文字指挥电脑
> 💡 不要被"安装"吓到。这就像第一次调音——看起来很专业，但其实只是拧几个旋钮。
:::

:::explain{title="安装步骤（Windows / Mac 通用）"}
1. 打开浏览器，访问 **nodejs.org**
2. 下载 **LTS 版本**（长期支持版，偶数是版本号，如 20.x）
   - LTS = Long Term Support，最稳定的版本
   - 不要下载"Current"版本——那是给尝鲜的人用的
3. 运行安装程序，一路点"Next"（全部默认选项即可）
4. 安装完成后，打开终端验证：
**Windows：** 按 `Win + R`，输入 `cmd`，回车
**Mac：** 按 `Cmd + 空格`，输入 `Terminal`，回车
在终端中输入：
```bash
node -v
```
如果看到版本号（如 `v20.11.0`），安装成功！🎉
再输入：
```bash
npm -v
```
如果也看到版本号（如 `10.2.4`），说明 npm 也装好了。
:::

:::task{title="你的任务 ✨"}
1. 从 nodejs.org 下载并安装 Node.js LTS 版本
2. 打开终端，运行 `node -v`，确认看到版本号
3. 运行 `npm -v`，确认看到版本号
4. 在终端中试试 `node -e "console.log('你好，工程化世界！')"` —— 这是用 Node.js 执行一行 JavaScript
> 完成之后，你已经迈出了工程化的第一步。接下来的所有课程都依赖 Node.js，确保安装成功再继续。
:::

:::hint{title="常见问题"}
- **"node 不是内部或外部命令"** → 安装时可能没勾选"Add to PATH"。重新运行安装程序，确保勾选这个选项。
- **Mac 权限问题** → 如果提示权限不足，尝试用管理员权限安装。
- **不确定有没有装过？** → 在终端运行 `node -v`，能显示版本号就是装过了。
- **版本号太旧？** → 推荐 v18 或 v20 以上。低于 v16 建议重新安装。
:::

:::recap
你学会了安装 Node.js——它是运行前端工具的基础环境。在终端输入 node -v 确认安装成功后，就可以使用 npm 安装各种包，用 Vite 创建项目，用终端命令高效操作文件。
:::
