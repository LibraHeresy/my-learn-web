# 安装你的"乐器"：Node.js

:::analogy
Node.js 不是你做菜用的食材，而是厨房里的**燃气管道和电源**。你不会直接吃电，但没有电，你的冰箱、烤箱、搅拌机全是废铁。同样，你不会用 Node.js 写网页，但没有它，npm、Vite、ESLint 这些工具一个都跑不起来。
:::

:::explain{title="问题：为什么装个前端项目还要装 Node.js？"}
很多初学者在这里卡住："我是学前端的，Node.js 不是后端技术吗？"

这个困惑的来源是名字没取好。Node.js 确实可以让 JavaScript 在服务器上运行（后端），但前端开发者装 Node.js 是为了另一件事：**运行开发工具**。

看看你接下来要用的工具，它们全部需要 Node.js：
- `npm` — 安装第三方库（Node.js 自带）
- `npx` — 运行一次性命令（Node.js 自带）
- Vite — 开发服务器 + 构建打包
- ESLint — 代码检查
- Prettier — 代码格式化

这些工具都是用 JavaScript 写的，而你的浏览器无法在本地运行 JavaScript 文件（浏览器的 JS 只能跑在网页里）。Node.js 填补了这个空白——它让你在电脑上直接运行 JS 程序。

**一句话总结：你装 Node.js 不是为了"写 Node.js 代码"，而是为了"用 Node.js 写的工具"。**
:::

:::explain{title="解决方案：下载、安装、验证三部曲"}
安装 Node.js 比装一个手机 App 还简单——不需要任何配置知识。

**第一步：下载 LTS 版本**

打开浏览器，访问 `https://nodejs.org`。你会看到两个大大的下载按钮：
- **LTS**（Long Term Support，长期支持版）——选这个。版本号是偶数（如 20.x、22.x），最稳定。
- **Current**（最新版）——不要选。这是给想尝鲜的人用的，可能有未发现的 bug。

点 LTS 按钮，下载安装程序（`.msi` 文件 或 `.pkg` 文件）。

**第二步：安装（一路默认）**

运行下载的文件：
1. 点 Next
2. 接受协议
3. 安装路径用默认的（不要改）
4. 确保勾选 **"Add to PATH"**（这一项很关键——它让你在终端任何位置都能运行 `node` 命令）
5. 点 Install，等进度条跑完

**第三步：验证**

打开终端（Windows：按 `Win+R`，输入 `cmd`，回车 | Mac：按 `Cmd+空格`，输入 Terminal，回车）。

输入以下两行命令，每行回车：
```bash
node -v
```
如果输出版本号（如 `v20.11.0`），说明 Node.js 安装成功。

```bash
npm -v
```
如果也输出版本号（如 `10.2.4`），说明 npm 也一起装好了（npm 随 Node.js 自动安装）。
:::

:::example{title="验证安装 + 运行第一行 Node.js 代码"}
在终端中运行以下命令，逐行理解：

```bash
node -v
```
输出 `v20.11.0`（你的版本号可能不同）。`-v` 是 `--version` 的缩写，意思是"告诉我你的版本号"。

```bash
npm -v
```
输出 `10.2.4`。证明 npm（包管理器）已经可用。

```bash
node -e "console.log('你好，工程化！')"
```
这行命令做了什么？逐部分拆解：
- `node` — 调用 Node.js
- `-e` — execute 的缩写，意思是"执行后面这串代码"
- `"console.log('你好，工程化！')"` — 一段 JavaScript 代码，在终端里打印文字

如果终端输出了 `你好，工程化！`，你就用 Node.js 成功运行了第一行 JS 代码。

**关键理解：** 这段 `console.log` 不是在浏览器控制台输出的，而是在你的电脑终端里输出的。这就是 Node.js 和浏览器的区别——Node.js 让 JavaScript 离开浏览器，直接在操作系统层面运行。
:::

:::hint{title="常见安装错误及解决办法"}
**错误 1：'node' 不是内部或外部命令 (Windows) 或 command not found: node (Mac)**

原因：安装时没有勾选 "Add to PATH"，或者安装后没有重启终端。

解决：
- Windows：重新运行安装程序，在安装选项页面**确保勾选 "Add to PATH"**。安装完后**关掉终端重新打开**。
- Mac：重新运行 `.pkg` 安装包，完成后重新打开终端。

**错误 2：下载了 Current 版本而不是 LTS**

Current 版本号是奇数（如 21.x），LTS 是偶数（如 20.x）。Current 可能有兼容性问题。回到 nodejs.org 重新下载 LTS 版本覆盖安装即可。

**错误 3：不确定有没有装过**

运行 `node -v`。如果显示版本号就是装过了。如果版本号低于 v16.x，建议去官网下载新 LTS 版本覆盖安装（直接安装新版本会替换旧版本）。

**错误 4：Mac 提示"无法验证开发者"**

进入 `系统偏好设置` → `安全性与隐私` → 点击"仍要打开"。
:::

:::explain{title="现实工作连接：每个前端开发者的电脑上都有 Node.js"}
- 入职第一天，IT 给你配电脑，第一个要装的软件除了 VS Code 就是 Node.js
- 任何前端项目的 README.md 第一行通常是："需要 Node.js >= 18"
- CI/CD 流水线（自动化测试和部署）的第一步就是 `actions/setup-node`
- 面试时被问"你用过 Node.js 吗？"，前端岗位的标准回答是"用它运行工具链"

Node.js 不是可选项，是基础设施。就像你不需要会造发动机才能开车，但你得知道车需要加油。
:::

:::task{title="安装 Node.js 并验证"}
::::step{purpose="从官网下载正确的版本。LTS 是最稳定的选择——你不会想因为工具版本问题而浪费时间排查。" expected="下载完成，安装文件在下载文件夹中。"}
下载 Node.js LTS 版本

1. 打开浏览器，访问 `https://nodejs.org`
2. 点击左侧的 **LTS** 按钮（不要点右侧的 Current）
3. 等待下载完成（文件大约 30-60 MB）
::::

::::step{purpose="安装时'Add to PATH'是最关键的一步。它把 node 命令注册到系统环境里，让你在任何文件夹都能调用。" expected="安装程序正常完成，没有报错。"}
安装 Node.js

1. 双击下载的安装文件（`.msi` 或 `.pkg`）
2. 点击 Next，接受协议
3. 安装路径保持默认，点 Next
4. **关键步骤：** 在看到 "Add to PATH" 选项时，确保它是勾选状态
5. 点击 Install，等待完成
6. 安装完成后，**关掉所有已打开的终端窗口**（这很重要——已打开的终端不会加载新的 PATH）
::::

::::step{purpose="验证 Node.js 和 npm 都能正常调用。看到版本号就是成功——不需要理解版本号数字的含义。" expected="node -v 输出版本号（如 v20.11.0），npm -v 也输出版本号（如 10.2.4），node -e 输出'你好，工程化！'。"}
在终端中验证安装

打开终端（VS Code 内置终端或系统终端都行），依次输入：

```bash
node -v
```
确认看到类似 `v20.11.0` 的版本号。

```bash
npm -v
```
确认看到类似 `10.2.4` 的版本号。

```bash
node -e "console.log('你好，工程化！')"
```
确认终端输出了 `你好，工程化！`。

如果以上三条命令都正常工作，Node.js 安装成功。
::::
:::
