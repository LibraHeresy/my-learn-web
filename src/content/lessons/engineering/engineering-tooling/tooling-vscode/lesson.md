# VS Code：从记事本到专业编辑器

:::analogy
用记事本写代码，就像用石头在树皮上刻字——能出字形，但慢、疼、容易出错。VS Code 是印刷机：自动排版、拼写检查、一键替换。全世界 75% 的前端开发者选择它，不是因为它免费，而是因为它真的省时间。
:::

:::explain{title="问题：记事本写代码到底哪里不行？"}
你可以用任何文本编辑器写代码——Windows 记事本、Mac 文本编辑，甚至 Word（千万别）。问题是：

1. **没有语法高亮** — 所有文字一个颜色。`function`、`"字符串"`、`// 注释` 混在一起，眼睛累，bug 藏得深。
2. **没有自动补全** — `document.querySelector` 要自己一个字母不差地敲完。敲 100 次就浪费 100 次时间。
3. **没有错误提示** — 少写一个括号，记事本不会告诉你。你只能在浏览器里看到莫名其妙的报错，然后回记事本里人眼扫描找。
4. **没有文件树** — 项目有 20 个文件时，你在文件夹和编辑器之间反复横跳。
5. **没有集成终端** — 编辑器是编辑器，终端是终端，两个窗口切来切去。
6. **没有 Emmet** — 写一个完整 HTML 骨架要敲 15 行。VS Code 里敲 `!` + Tab 就行。

这些不是"锦上添花"，是**每天省 30 分钟**的硬效率。
:::

:::explain{title="解决方案：VS Code 的 6 项核心能力"}
| 能力 | 效果 | 举例 |
|------|------|------|
| **语法高亮** | 标签、属性、字符串、关键字用不同颜色显示 | `<div>` 蓝色，`class="red"` 绿色，`const` 橙色 |
| **IntelliSense（智能提示）** | 你敲前几个字母，它列出候选 | 敲 `docu` → 弹出 `document`、`document.querySelector`... |
| **错误波浪线** | 语法错误、未定义变量标红色波浪线 | 写了 `cons x = 1`（少了 t），`cons` 下面立刻出现红线 |
| **文件资源管理器** | 左侧树状结构，所有文件一览无余 | 项目 50 个文件，点击即打开，拖拽即可移动 |
| **集成终端** | 编辑器底部直接嵌入命令行 | `Ctrl+`` 弹出终端，敲 `npm run dev`，不用切窗口 |
| **Emmet** | 缩写展开成完整代码 | `ul>li*5` → 一个 ul 里面 5 个 li |

这些功能不是你"以后才需要"的东西——你从第一个本地项目开始就会每天用到它们。
:::

:::example{title="10 秒生成一个完整 HTML 页面——Emmet 实战"}
在 VS Code 中新建一个 HTML 文件，输入一个感叹号：

```html
!
```

然后按 **Tab** 键。VS Code 瞬间展开为：

```html
<!DOCTYPE html>                        <!-- 文档类型声明，告诉浏览器这是 HTML5 -->
<html lang="en">                       <!-- 根元素，lang="en" 可改为 lang="zh-CN" -->
<head>                                 <!-- 头部区域开始 -->
  <meta charset="UTF-8">               <!-- 字符编码，UTF-8 支持中文 -->
  <meta name="viewport"                <!-- 移动端视口设置 -->
        content="width=device-width, initial-scale=1.0">
  <title>Document</title>              <!-- 页面标题，显示在浏览器标签页上 -->
</head>                                <!-- 头部区域结束 -->
<body>                                 <!-- 页面可见内容开始 -->

</body>                                <!-- 页面可见内容结束 -->
</html>
```

再多试几个 Emmet 缩写（每个都要按 Tab 触发）：

```html
div.container            →  <div class="container"></div>
ul>li*3                  →  <ul><li></li><li></li><li></li></ul>
a[href="#"]{点击这里}     →  <a href="#">点击这里</a>
div.card>img[src=""][alt=""]+h2{标题}+p{描述}
```
最后这条生成一个完整的卡片结构——图片 + 标题 + 描述，放在一个 div 里。**10 个字符展开了 6 行代码。**

这就是工具的力量：不是让你少敲几个字，是让你把注意力留给真正重要的逻辑和设计。
:::

:::hint{title="新手常见的 3 个操作错误"}
**错误 1：只打开单个文件，而不是打开整个文件夹**

如果你用 `文件 → 打开文件` 打开 `index.html`，左侧不会有文件树，你也看不到同目录下的其他文件。**正确做法：** `文件 → 打开文件夹`，选择项目根目录（如 `my-music-app`）。这样所有文件都在左侧树里。

**错误 2：不知道内置终端在哪**

菜单栏 `查看 → 终端`，或者快捷键 `Ctrl+``（反引号键，在 Esc 下方）。终端弹出后，你可以直接敲 `node -v`、`npm install` 等命令，不用切换窗口。

**错误 3：不装扩展，用"裸机"写代码**

VS Code 的扩展商店是它的灵魂。至少装这三个：
- **Prettier** — 代码格式化（保存时自动整理缩进、引号、分号）
- **Live Server** — 右键 HTML 文件，一键在浏览器打开（早期会用到）
- **Chinese (Simplified)** — 如果英文界面不习惯，中文语言包

打开扩展商店：左侧活动栏第五个图标（四个方块），或按 `Ctrl+Shift+X`。
:::

:::task{title="配置你的 VS Code 工作环境"}
::::step{purpose="一个文件夹就是一个'项目'。VS Code 以文件夹为单位管理文件树、终端工作目录、搜索范围。打开文件夹是每天上班的第一个动作。" expected="VS Code 左侧文件树显示 my-music-app 文件夹及其内容（src、readme.md）。"}
安装 VS Code 并打开项目文件夹

1. 访问 `https://code.visualstudio.com` 下载并安装 VS Code
2. 启动 VS Code
3. `文件` → `打开文件夹` → 选择你的 `my-music-app` 文件夹
4. 确认左侧文件资源管理器中能看到 `src/` 和 `readme.md`
::::

::::step{purpose="Emmet 是 VS Code 内置的 HTML 加速引擎。掌握 ! 和 . 两个快捷键，手写 HTML 的速度直接翻倍。" expected="按 Tab 后生成完整的 HTML5 骨架（DOCTYPE + html + head + body），第二个缩写生成一个带 class 的 div。"}
体验 Emmet 缩写

1. 在左侧文件树中，展开 `src` 文件夹，点击 `index.html` 打开它
2. 在编辑区输入 `!`，然后按 **Tab** 键——观察发生了什么
3. 把 `<html lang="en">` 改成 `<html lang="zh-CN">`
4. 在 `<body>` 标签内输入 `div.container`，按 **Tab**
5. 继续输入 `h1{我的音乐收藏}`，按 **Tab**
6. 按 `Ctrl+S`（Mac: `Cmd+S`）保存文件
::::

::::step{purpose="VS Code 内置终端比系统终端好用得多——它自动定位到项目文件夹，你不需要每次 cd 到项目目录。" expected="终端显示 node 版本号，且当前路径以 my-music-app 结尾。"}
打开集成终端并验证 Node.js

1. 快捷键 `Ctrl+``（Mac: `Cmd+``）弹出底部终端面板
2. 输入 `pwd`，确认当前在 `my-music-app` 文件夹
3. 输入 `node -v`，确认能看到版本号
4. 输入 `npm -v`，确认能看到版本号
5. 如果以上都正常，你的 VS Code 工作环境就位了
::::

::::step{purpose="保存时自动格式化是职业开发者的标配。不用再手动调缩进、对齐空格——Ctrl+S 搞定一切。" expected="打开设置，'Format On Save' 选项已勾选。"}
开启自动保存和格式化

1. 点击 `文件` → `自动保存`（勾选后前面会出现 ✓）
2. 按 `Ctrl+,`（Mac: `Cmd+,`）打开设置
3. 搜索 `format on save`，勾选该选项
4. 按 `Ctrl+Shift+X` 打开扩展商店，搜索 `Prettier`，点击安装
5. 现在每次保存文件，Prettier 会自动整理代码格式
::::
