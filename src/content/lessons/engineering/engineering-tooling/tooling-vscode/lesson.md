# 认识你的"乐谱架"：VS Code

:::music-analogy
音乐家有谱架，程序员有编辑器。**VS Code** 不是普通的记事本——它就像智能谱架：自动帮你对齐音符、标记错误、提示下一个和弦。全世界绝大多数前端开发者每天都在用它。
:::

:::explain{title="为什么需要专业的代码编辑器？"}
你可能用记事本写过代码——那种感觉就像在餐巾纸上写乐谱。VS Code 给你的是：
| 功能 | 类比 |
|------|------|
| 语法高亮 | 不同类型的音符用不同颜色标记 |
| 自动补全 | 你哼一个音，它就帮你找到后面的旋律 |
| 错误提示 | 弹错音时，调音器立刻报警 |
| 内置终端 | 谱架下面藏着一台节拍器 |
| 文件管理 | 所有乐谱按声部分类放好 |
| 插件市场 | 各种"效果器"任你挑选 |
> 💡 VS Code 是微软开发的，完全免费，Windows/Mac/Linux 都能用。
:::

:::explain{title="安装与初始化"}
1. 打开浏览器，访问 **code.visualstudio.com**
2. 下载并安装 VS Code
3. 启动 VS Code
**界面导览：**
- **左侧活动栏** — 最左侧的图标列（文件、搜索、Git、插件、...）
- **文件资源管理器** — 显示项目文件夹结构（快捷键 `Ctrl+Shift+E` / `Cmd+Shift+E`）
- **编辑区** — 中间最大的区域，写代码的地方
- **终端面板** — 底部可以弹出的面板（快捷键 `Ctrl+`` / `Cmd+``）
**打开终端面板：**
- 点击顶部菜单 `查看 → 终端`
- 或按快捷键 `Ctrl+``（Mac: `Cmd+``）
在 VS Code 内置终端中运行 `node -v`，确认能看到版本号。以后我们不再需要单独打开系统终端——所有操作都在 VS Code 里完成。
:::

:::task{title="你的任务 ✨"}
1. 下载并安装 VS Code
2. 在你的电脑上创建一个文件夹叫 `my-music-app`（可以放在桌面或文档目录）
3. 在 VS Code 中点击 `文件 → 打开文件夹`，选择 `my-music-app`
4. 按 `Ctrl+`` 打开终端面板，运行 `node -v`
5. 在左侧文件资源管理器中右键 → 新建文件 → `readme.md`，输入 `# 我的音乐应用`
> 成功打开文件夹并看到终端后，你的"排练厅"就布置好了。接下来我们开始往里面放东西。
:::

:::hint{title="小技巧"}
- **自动保存：** 点击 `文件 → 自动保存`，以后每次切换文件都会自动保存。
- **中文界面：** 如果英文不习惯，在插件市场搜索"Chinese"安装中文语言包。
- **字体大小：** `Ctrl +` / `Ctrl -` 可以随时调整。
:::

:::recap
你学会了安装和使用 VS Code——前端开发最常用的代码编辑器。它有语法高亮、自动补全、错误提示、内置终端等强大功能，通过插件市场还能安装各种扩展来增强自己的能力。
:::
