# 用 AI 写结构和语义

:::music-analogy
「AI 能把音符写下来，但只有懂乐理的人才知道这段旋律该配什么和弦。」
:::

:::explain{title="这一章你会学什么"}
这一章会把 AI 放回你已经熟悉的前端语境里。你会练习：
- 让 AI 生成 HTML、CSS、JS 的初稿
- 用你已有的前端知识审查它
- 发现“能生成”不等于“能直接用”

这一章的重点不是省掉你的工作，而是训练你在熟悉领域里和 AI 配合。
:::

:::explain{title="为什么从 HTML 开始"}
HTML 是最适合练 AI 协作判断力的入口，因为你已经学过它，而且结构是否合理通常比较容易审查。  
在工程语境里，你现在练的其实是：**需求表达**、**结果审查**、**语义正确性**、**可访问性意识**。  
这些能力后面会一路迁移到 CSS、JavaScript、Vue 甚至 AI 项目实战里。
:::

:::hint{title="这一章的正确目标"}
不要把目标定成“让 AI 一次生成完美代码”。  
正确目标是：让 AI 快速产出初稿，然后由你判断结构、术语、语义和边界是否成立。  
你不是在逃避基础，而是在用基础做审查。
:::

:::explain{title="一、让 AI 生成 HTML 结构"}
你在第一章手写了 HTML——标签、嵌套、语义化。现在试试让 AI 写。
打开 AI 工具，试试这个 Prompt：
> 我在做一个个人博客。请生成一个文章列表页面的 HTML 结构。每篇文章包含：标题（h2）、摘要（p）、作者名、发布日期、标签列表、一个"阅读更多"链接。要求：使用语义化标签（article、header、main、footer 等），结构清晰，class 命名用 BEM 风格。
AI 会生成一段 HTML。现在——**用你在第一章学到的知识审查它：**
- 用了 `<article>` 还是 `<div class="article">`？
- `<header>` 和 `<footer>` 的位置对吗？
- 标签列表用了 `<ul>` 还是几个 `<span>` 挤在一起？
- class 命名真的符合 BEM 吗？有没有叫 `red-text` 这种和表现相关的名字？
- 有没有遗漏任何你要求的内容？
你会发现：AI 的结构通常是合理的，但总有那么一两处不够语义化、不够干净。**这正是你的用武之地。**
:::

:::explain{title="二、常见的 AI HTML 问题"}
通过审查大量 AI 生成的 HTML，你会发现几个反复出现的模式：
**问题一：div 泛滥。** AI 倾向于用 `<div>` 包一切，因为它的训练数据里有海量的 `<div>`。当你要求"语义化标签"时它才用 `<article>`、`<nav>`，但没说的时候默认 `<div>`。
**问题二：缺失的 alt 属性。** AI 在生成 `<img>` 时经常会漏掉 `alt` 属性——因为在互联网上有太多图片没有 alt。这是一个"统计上常见但规范上错误"的行为。
**问题三：过度嵌套。** AI 有时候会 `<div><div><div><span>文字</span></div></div></div>`——多层不必要的容器。这是因为它在模仿一些复杂 UI 库的 DOM 结构。
**问题四：没有考虑可访问性。** `aria-label`、`role`、表单 label 关联——这些基本都会漏掉，除非你在 Prompt 里明确提出。
**你的任务：** 养成审查习惯。AI 输出的 HTML 不是"完成品"，是"初稿"——你来打磨。
:::

:::explain{title="三、练习"}
用 AI 生成以下三个需求的 HTML，然后对照第一章的知识点逐一审查：
**需求 1：** "一个网站的导航栏，包含 Logo、5 个导航链接、一个搜索输入框。"
→ 审查点：导航用了 `<nav>` 吗？搜索框有没有 `<label>`？
**需求 2：** "一个商品列表页面，每个商品有图片、名称、价格、加入购物车按钮。"
→ 审查点：图片有 `alt` 吗？按钮是 `<button>` 吗？结构是否扁平？
**需求 3：** "一个页脚，包含三列链接（产品、公司、支持）和底部版权信息。"
→ 审查点：三列的结构合理吗？版权行用了 `<small>` 吗？
每个需求，先让 AI 生成，然后**至少找出 2 处可以改进的地方并手动修改**。
:::

:::recap
AI 生成 HTML 结构通常合理，但容易出现 div 泛滥、缺失 alt 属性、过度嵌套、忽略可访问性四个常见问题。AI 的 HTML 输出是初稿——你用学过的语义化知识来打磨，多一层 `<nav>`、加一个 `alt`、少一层无意义的 `<div>`。
:::

:::task{title="这次 AI 协作是否合格"}
用下面 4 个问题检查你刚才的结果：
1. **能运行**：这段 HTML 是否真的能渲染出你要的结构
2. **能解释**：你能不能指出每个主要标签为什么放在这里
3. **能修改**：你能不能至少手动改掉 2 处不合理的结构
4. **能说明边界**：你能不能指出 AI 在语义化、alt、可访问性上最容易出错的地方

如果这 4 条做不到，这次练习就还没真正完成。
:::
