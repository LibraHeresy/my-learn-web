# 用 AI 写结构和语义

:::analogy
AI 是打字员——它能生成一堆标签。你是编辑——只有你才知道哪里该用 `<nav>`、哪里该用 `<article>`、哪里只是装饰性的 `<div>`。打字员管量，编辑管质。
:::

:::prerequisite
你已经学过 HTML 的语义化标签（`<header>`、`<nav>`、`<main>`、`<article>`、`<section>`、`<footer>`）、表单元素、以及可访问性基础（`alt`、`aria-label`、`role`）。
:::

## 一、你的问题

你让 AI 生成一个页面的 HTML，它写了 40 个 `<div>` 和一堆 `<span>`。结构"能渲染"，但既不语义化、也无障碍性差、class 命名混乱。你不知道从哪里开始改——改一个 `<div>` 成 `<article>` 会不会破坏样式？全部重写又太花时间。你要的是一套"快速审查 + 精准修改"的流程。

## 二、解决方案：三层审查法

拿到 AI 生成的 HTML 后，不要一行行读——太慢。用三层审查法，每层只关注一件事：

### 第一层：骨架审查（30 秒）

快速扫描，看页面的主要区域有没有对应的语义标签。

| 页面区域 | 应该用的标签 | AI 经常用的标签 |
|---------|-------------|---------------|
| 顶部导航 | `<nav>` | `<div class="header">` |
| 主要内容 | `<main>` | `<div class="container">` |
| 独立内容块 | `<article>` | `<div class="card">` |
| 侧边栏 | `<aside>` | `<div class="sidebar">` |
| 底部信息 | `<footer>` | `<div class="footer">` |

在这一层，你只需要做一件事：**把页面区域的容器标签替换成语义标签。** 如果标签名改变了，对应的 CSS 选择器也要同步改（`div.header` 变成 `nav`）。

### 第二层：内容审查（1 分钟）

检查列表、图片、表单、标题这三个最容易出错的地方：

1. **列表是不是真列表。** 标签列表、导航链接、步骤说明——如果它们有"多项并列"的关系，就用 `<ul>` / `<ol>`，而不是几个 `<span>` 挤在一起。检查：屏幕阅读器会怎么读这几个 `<span>`？"点、点、点"。
2. **图片有没有 alt。** AI 生成的 `<img>` 经常漏 `alt`，因为训练数据里太多图片没有 alt。每张图补一个描述性的 alt（装饰性图片用 `alt=""`，内容图片用有意义的描述）。
3. **表单有没有 <label>。** 搜索框、输入框——每个 `<input>` 都应该有关联的 `<label>`。检查：点击"邮箱"两个字，光标会不会跳进输入框？不会，说明没有 label-for 关联。
4. **标题层级是否跳级。** AI 可能 `<h1>` 后面直接 `<h4>`。标题应该从 h1 到 h6 连续递减，不跳级。

### 第三层：可访问性审查（30 秒）

1. 交互元素（按钮、链接）是否是可聚焦的？（`<div onclick="...">` 是反模式，应该用 `<button>`）
2. 有没有 `aria-label` 在纯图标按钮上？（比如关闭按钮只有一个 X，屏幕阅读器读不出来）
3. 主要内容区域有没有"跳转到内容"的链接？（`<a href="#main-content" class="skip-link">`）

:::example{title="审查示例：一个博客列表页"}
AI 生成了如下结构：
```html
<div class="blog-list">
  <div class="header">我的博客</div>
  <div class="post">
    <img src="vue-tips.jpg">
    <div class="title">Vue 3 入门</div>
    <div class="meta">2025-01-15 / 张三</div>
    <div class="tags"><span>Vue</span> <span>前端</span></div>
  </div>
</div>
```

**逐层审查和修改：**

第一层（骨架）：`class="header"` 的 div 是页头 → 改成 `<header>`。`class="post"` 的 div 是独立内容 → 改成 `<article>`。最外层 → 改成 `<main>`。

第二层（内容）：`img` 缺少 `alt` → 补上 `alt="Vue 3 入门教程封面"`。`tags` 里两个 span 是标签列表 → 改成 `<ul><li>Vue</li><li>前端</li></ul>`。

第三层（可访问性）：标题层级——"我的博客"没有用 `<h1>`，改。

**修改后：**
```html
<main class="blog-list">
  <header>
    <h1>我的博客</h1>
  </header>
  <article class="post">
    <img src="vue-tips.jpg" alt="Vue 3 入门教程封面">
    <h2 class="title">Vue 3 入门</h2>
    <p class="meta"><time datetime="2025-01-15">2025-01-15</time> / 张三</p>
    <ul class="tags">
      <li>Vue</li>
      <li>前端</li>
    </ul>
  </article>
</main>
```

6 处修改，花了 2 分钟。AI 省了你写 15 行 HTML 的时间，你花的 2 分钟保证了质量和可访问性。这就是分工——AI 出量，你出质。
:::

## 三、常见错误

**错误 1：看到 div 太多就直接重写。**
> "AI 写的全是 div，没法用，我自己重写吧。"
不要重写。替换语义标签通常不需要动结构——`<div class="nav">内容</div>` 改成 `<nav>内容</nav>`，CSS 选择器从 `.nav` 改成 `nav`，内容原封不动。改动量远小于重写。

**错误 2：改了 HTML 忘记改 CSS。**
> `<div class="header">` 改成 `<header>` → CSS 里 `.header { ... }` 不生效了 → 页面样式崩了。
改标签名时，搜索对应的 CSS 选择器，同步更新。

**错误 3：盲目信任 AI 生成的结构。**
> AI 用了 `<article>` → 你觉得语义化已经很好了 → 跳过审查。
AI 用 `<article>` 是因为你在 Prompt 里说了"用语义化标签"。但它的语义标签经常用错位置——比如在侧边栏里也用 `<article>`。审查不是不信任 AI，是履行你的职责。

## 四、实际工作中的场景

- **接手 AI 生成的原型：** 设计师用 AI 工具生成了页面原型 HTML，你需要把它集成到 Vue 项目中。原型是能看的，但 `<div>` 泛滥、没有表单 label、图片全无 alt。你的任务：把原型 HTML 改造成生产级代码。用三层审查法，30 分钟搞定一个 5 页面的原型。
- **快速搭建新页面：** 产品经理说"今天下班前上线一个 FAQ 页面"。你用 AI 生成 FAQ 的 HTML 结构，然后用审查法快速改掉 div 问题、补上可访问性、调整标题层级。1 小时从需求到上线。
- **无障碍改造：** 公司要求所有页面对 WCAG 2.1 AA 级别合规。你把每个页面的 HTML 贴给 AI："检查这个页面的可访问性问题。"然后根据 AI 的提示逐个修复——但最终判断"这个修复是不是真的改善了无障碍体验"，靠你的知识。

:::task{title="HTML 审查与修改实战"}
::::step{id="1"}
让 AI 生成一个"个人博客首页"的 HTML 结构，要求包含：顶部导航（Logo + 3 个链接）、文章列表（至少 2 篇文章，每篇含标题、摘要、日期、标签）、侧边栏（作者简介 + 分类列表）、页脚（版权 + 社交媒体链接）。不要告诉 AI 用语义化标签——就看它的默认习惯。
::::
::::step{id="2"}
对 AI 的输出进行三层审查。第一层：标记出所有该改成语义标签的 div。第二层：检查列表、图片、表单、标题。第三层：检查可访问性问题。用注释在 HTML 中标出每个需要修改的地方。
::::
::::step{id="3"}
实际修改 HTML，把审查出的问题一一修掉。记录你改了多少处、花了多少时间。对比：如果让你从零手写这个页面，要多久？
::::
::::step{id="4"}
用浏览器的无障碍检查工具（Lighthouse 或 axe DevTools）跑一遍你修改后的 HTML。看看还有没有遗漏的问题。
::::
:::

:::recap
AI 生成的 HTML 是粗胚，你来精加工。三层审查法：第一层（30 秒）替换区域容器为语义标签；第二层（1 分钟）检查列表、图片、表单、标题；第三层（30 秒）检查可访问性。AI 负责生产代码（量），你负责保证质量（质）——4 个 div 改成语义标签 + 2 个 alt 补全 + 1 个 label 关联，2 分钟让你的页面从"能看"变成"生产级"。
:::
