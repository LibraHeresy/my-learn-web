# CSS 入门 — 改变文字的颜色和大小

:::music-analogy
如果说 HTML 是乐谱上的音符，CSS 就是**演奏法记号**。它告诉浏览器：这个音符应该用什么力度（颜色）、多大音量（字号）来演奏。
:::

:::explain{title="什么是 CSS？"}
CSS（Cascading Style Sheets，层叠样式表）负责网页的外观。HTML 决定了"有什么"，CSS 决定了"长什么样"。
一句 CSS 规则由三部分组成：
```css
h1 {
  color: #8B2E2E;
  font-size: 32px;
}
```
- `h1` 是**{{term:选择器}}**——选中文档中的 `<h1>` 元素
- `color` 和 `font-size` 是**{{term:属性}}**——你想改变什么
- `#8B2E2E` 和 `32px` 是**值**——改成什么
:::

:::explain{title="CSS 注释：给样式加标注"}
和 HTML 一样，CSS 也有注释。CSS 注释用 `/*` 开头，`*/` 结尾：
```css
/* 这是标题的主色调 */
h1 {
  color: #8B2E2E;
  font-size: 36px;
}
/*
 * 多行注释也可以
 * 像这样写
 */
p {
  color: #6B5A4E;
}
```
注释中的内容不会被浏览器执行——你可以用它来标注每一段样式是干什么的。
**快捷键：** 选中代码按 `Ctrl + /`（Mac: `Cmd + /`），编辑器自动添加或移除 `/* */` 注释。这个快捷键在 HTML、CSS、JS 中都通用。
:::

:::explain{title="颜色值怎么表示？"}
颜色有多种写法：
- **颜色名**：`red`, `blue`, `gold` 等（简单但有局限性）
- **十六进制**：`#8B2E2E`（暗红）、`#3D2B1F`（深棕）——最常用
- **rgb**：`rgb(139, 46, 46)` — 用三个数字表示红绿蓝
就像调色盘一样，你可以调配出任何颜色！
:::

:::example{title="看例子"}
下面的代码就是编辑器中你看到的。我们给标题设置了暗红色和 36px 大小，给段落设置了深棕色：
```css
/* 标题样式 */
h1 {
  color: #8B2E2E;
  font-size: 36px;
}
/* 段落样式 */
p {
  color: #6B5A4E;
  font-size: 18px;
}
```
打开 CSS 选项卡可以看到完整样式，预览区能看到效果。
:::

:::recap
这一节你开始学习 CSS——给网页"化妆"的语言。一句 CSS 规则由三部分组成：选择器（对谁生效）、属性（改什么）、值（改成什么样）。你把标题改成了暗红色、段落改成了深棕色，第一次让文字有了颜色和大小。现在你已经跨过了"只能写黑白文字"的阶段，可以用 CSS 让网页变得好看了。
:::
