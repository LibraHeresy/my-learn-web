# CSS 入门 — 给 HTML 骨架穿上衣服

:::analogy
如果 HTML 是毛坯房的钢筋骨架，CSS 就是装修——刷什么颜色的墙、铺什么纹理的地板、家具怎么摆。HTML 决定"有什么"，CSS 决定"长什么样"。没有 CSS 的网页就像没装修的毛坯房：能用，但没人想住。
:::

:::prerequisite
**本节你需要知道这些词：**

- **HTML 标签**：`<h1>`、`<p>`、`<div>` 这些你已经会写的标签，CSS 就是用来美化它们的
- **HTML 属性**：`class`、`id` 是给元素贴的"标签"，CSS 通过这些标签找到元素
:::

:::explain{title="本节目标"}
学完本节，你将能够：
- 说出 CSS 能做什么、为什么要学它
- 区分行内样式、内部样式、外部样式三种写法
- 理解选择器、属性、值三个核心概念
- 用 `color` 和 `font-size` 写出第一条 CSS 规则
:::

:::explain{title="一、没有 CSS 的时候，页面长什么样？"}
浏览器会给 HTML 一套默认样式——黑色文字、白色背景、蓝色带下划线的链接。所有页面都长一个样，无法区分标题和正文的视觉层级：

```html
<h1>我的个人主页</h1>
<p>欢迎来到我的主页。我喜欢设计和写代码。</p>
<p>联系我：hello@example.com</p>
```

这段 HTML 在浏览器里显示出来，`h1` 只是字号大一点、加粗而已，`p` 就是普通的黑色文字。三个元素之间没有颜色区分、没有间距节奏、没有视觉层次——读者扫一眼不知道重点在哪。

**这就是 CSS 要解决的问题。**
:::

:::explain{title="二、CSS 解决了什么问题？"}
给上面同一段 HTML 加上 CSS 之后：

```css
h1 {
  color: #8B2E2E;     /* 文字颜色：暗红 */
  font-size: 36px;    /* 字号：36像素 */
}
p {
  color: #6B5A4E;     /* 文字颜色：深棕 */
  font-size: 18px;    /* 字号：18像素 */
}
```

现在标题是醒目的暗红色大字体，正文是柔和的深棕色——读者一眼就知道标题是"主角"，段落是"配角"。这就是 CSS 的核心能力：**控制页面的视觉层级**，让内容有主次、有节奏、有美感。
:::

:::explain{title="三、CSS 规则的解剖结构"}
一条 CSS 规则由三个部分组成，缺一不可：

```css
h1 {                   /* ← 选择器：对谁生效？ */
  color: #8B2E2E;      /* ← 属性：改什么？  值：改成什么？ */
  font-size: 36px;     /*    ↑               ↑              */
}                      /*    属性            值              */
```

- **选择器（Selector）**：选中文档中的哪个元素。`h1` 表示"所有 `<h1>` 标签"
- **属性（Property）**：你想改变这个元素的什么特征。`color` 是文字颜色，`font-size` 是文字大小
- **值（Value）**：改成什么。`#8B2E2E` 是一种暗红色，`36px` 是 36 个像素

写 CSS 本质上就是重复这个句式：**"选中谁 → 改什么 → 改成什么样"**。
:::

:::explain{title="四、CSS 写在哪？三种引入方式"}
CSS 可以写在三个地方，各有各的适用场景：

**方式一：行内样式（inline）——写在标签的 `style` 属性里**
```html
<h1 style="color: #8B2E2E; font-size: 36px;">标题</h1>
```
优点：直接，立刻看到效果。缺点：每个元素要单独写，改一处就要改一处。**只适合临时测试，不用于正式项目。**

**方式二：内部样式（internal）——写在 `<style>` 标签里**
```html
<style>
  h1 { color: #8B2E2E; }
  p  { color: #6B5A4E; }
</style>
```
优点：整页样式集中在一起管理。缺点：每个 HTML 文件都要写一遍，多个页面无法共享。**适合单页 Demo 或教学场景。**

**方式三：外部样式（external）——写在单独的 `.css` 文件里**
```html
<link rel="stylesheet" href="styles.css">
```
```css
/* styles.css */
h1 { color: #8B2E2E; }
p  { color: #6B5A4E; }
```
优点：一个 CSS 文件可以被全站所有页面引用，改一处全站生效。**这是实际项目中的标准写法。**

> 本项目默认使用方式二（内部样式），方便你在一个编辑器里同时看到 HTML 和 CSS。当你做真实项目时，记得把 CSS 提取到外部文件中。
:::

:::explain{title="五、CSS 注释：给样式写旁注"}
和 HTML 注释 `<!-- -->` 不同，CSS 注释用 `/* */` 包裹：

```css
/* 这是页面主标题的颜色 */
h1 {
  color: #8B2E2E;  /* 暗红色，和品牌色保持一致 */
  font-size: 36px;
}

/*
 * 多行注释可以像这样写。
 * 适合解释一大段样式是干什么的。
 */
p {
  color: #6B5A4E;
}
```

注释中的内容不会被浏览器执行——它们只给"人"看，包括三个月后回来改代码的你自己。**快捷键：** 选中代码按 `Ctrl + /`（Mac: `Cmd + /`），编辑器自动添加或移除 `/* */`。

**什么时候该写注释？** 当一段样式的意图不那么明显时——比如"这个颜色和品牌 Logo 保持一致"、"这个负 margin 是为了抵消父容器的 padding"。
:::

:::example{title="常见错误——看看你踩过几个坑？"}
**错误 1：忘记分号 `;`**
```css
h1 {
  color: #8B2E2E        /* ❌ 缺分号！整条规则可能失效 */
  font-size: 36px;
}
```
每条属性声明必须以 `;` 结尾。少写一个分号，后面的属性可能跟着一起失效。

**错误 2：花括号不配对**
```css
h1 {
  color: #8B2E2E;
  font-size: 36px;
/* ❌ 少了一个闭合花括号！后面的 CSS 全部失效 */
p {
  color: #6B5A4E;
}
```
每个 `{` 必须有对应的 `}`。建议写 `{` 的同时就打出 `}`，然后往中间填内容。

**错误 3：属性名拼错**
```css
h1 {
  colour: #8B2E2E;  /* ❌ colour 不是 CSS 属性名，正确的是 color */
}
```
CSS 属性名是固定的，拼错一个字母浏览器就不认识。多写几次就记住了。

**错误 4：颜色值少写一位**
```css
h1 {
  color: #8B2E2;   /* ❌ 只有5位，合法的是3位、4位、6位、8位 */
}
```
十六进制颜色码最常用的是 6 位（如 `#8B2E2E`），少写或多写都会导致颜色不生效。
:::

:::explain{title="六、color 和 font-size——排版的起点"}
`color` 和 `font-size` 是你最先学会的两个 CSS 属性，也是最直观的：

- `color` 改变文字颜色。值可以是颜色名（`red`）、十六进制（`#8B2E2E`）、rgb（`rgb(139,46,46)`）。十六进制最常用
- `font-size` 改变文字大小。`px` 是像素单位——数字越大字越大。标题通常 24-48px，正文通常 14-18px

**这两个属性背后是一个核心思想：** 所有的视觉层级，本质上就是"大和小、亮和暗、疏和密"的对比。你后面学的所有 CSS 属性，都是在不同的维度上制造对比。
:::

:::explain{title="七、实际工作中你会怎么用？"}
写一个页面时，你通常先不碰 CSS——先用纯 HTML 把内容和结构写完（这是上一章学的内容）。然后打开 CSS 文件，从上到下：

1. 先给 `body` 设背景色和默认字体，定下整个页面的"底色"
2. 再给各类标题（`h1`、`h2`、`h3`）设颜色和字号，建立标题层级
3. 再给正文 `p` 设字体、字号、行高、颜色，确保正文舒适可读
4. 再给链接 `a` 去掉下划线、改颜色，让链接融入设计
5. 最后处理特殊组件（卡片、按钮、导航栏）

**你现在在第 2、3 步——从标题和段落开始，建立最基本的视觉层级。**
:::
