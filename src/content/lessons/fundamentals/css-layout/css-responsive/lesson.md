# 响应式设计 — 适配不同的屏幕

:::analogy
响应式设计就像同一个App在手机和电脑上界面不同——内容一样，但布局会根据屏幕大小自动调整。用 media 查询适配不同屏幕。
:::

:::explain{title="什么是响应式设计？"}
响应式设计让同一个网页在桌面、平板、手机上都有良好的体验。核心工具是 `@media` 查询：
```css
/* 手机端（默认） */
.card { width: 100%; }
/* 平板（≥600px） */
@media (min-width: 600px) {
  .card { width: 48%; }
}
/* 桌面（≥900px） */
@media (min-width: 900px) {
  .card { width: 30%; }
}
```
@media` 后面跟着一个"条件"——当条件满足时，里面的样式才生效。
**移动端优先（推荐）**：先写手机样式作为默认，再用 `min-width` 逐步增强大屏。
:::

:::explain{title="常见的断点"}
三个常用的响应式断点：
| 断点 | 设备 | 典型宽度 |
|------|------|----------|
| 小屏 | 手机 | < 640px（默认） |
| 中屏 | 平板 | 640px ~ 1024px |
| 大屏 | 桌面 | > 1024px |
```css
/* 默认：手机（单列） */
.grid { grid-template-columns: 1fr; }
/* 平板：两列 */
@media (min-width: 640px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}
/* 桌面：三列 */
@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}
```
就像同一张照片有不同的尺寸——缩略图（手机）、中等尺寸（平板）、原图（桌面），内容不变，展示方式逐步增强！
:::

这一节你学会了让网页适配不同的屏幕——用 `@media` 查询根据屏幕宽度切换样式。手机端用单列布局，平板用两列，桌面用三列。推荐"移动端优先"的思路：先写好手机版的样式，再用 `min-width` 逐步为大屏增强。现在你写的网页在手机、平板、电脑上都能好好显示了。
