# 图片与链接 — 丰富你的页面

:::analogy
`<img>` 就像在文档里贴照片，`<a>` 标签链接就像书里的"参见第X页"——指向另一个地方。网页有了图和链接，才从"一页文字"变成了"一张互动的名片"。
:::


:::prerequisite
**本节你需要知道这些词：**

- **标签（tag）**：用尖括号包裹的标记，如 `<h1>`、`<p>`——第一节"认识 HTML"中学过。
- **单标签**：`<br>` 不需要结束标签——第三节"文本与强调"中学过。`<img>` 也是单标签。
- **列表**：`<ul>`（无序）和 `<ol>`（有序），`<li>` 必须放在它们里面——第四节"列表"中学过。
:::

:::explain{title="问题：只有文字的网页缺少什么？"}
你已经能写标题、段落、列表了——但一个网页如果只有文字，就像一份没有图片的报纸、一本没有超链接的百科全书，用户只能看，不能"走"。

浏览网页时，你会看到两样东西到处都是：**图片**和**链接**。图片让信息更直观——一张头像比"这是一个人"更快被理解。链接让网页彼此连通——点一下就能从百度跳到维基百科，这就是"互联网"的"联"字。

你现在需要学会两件事：如何在页面上插入图片，如何让一段文字变成可点击的链接。
:::

:::explain{title="img — 插入图片"}
`<img>` 标签可以在网页中插入图片。它是**单标签**——不需要结束标签，就像拍照时按一下快门：

```html
<img src="图片地址" alt="图片描述">
```

- `src` — 图片的来源地址（source）。可以是网上的 URL，也可以是本地文件路径。
- `alt` — 替代文字（alternative text）。当图片加载失败时显示，也是屏幕阅读器读给盲人用户的内容。

**绝对路径 vs 相对路径：**
- **绝对路径**：完整的网址，以 `https://` 或 `http://` 开头。例如 `https://example.com/photo.jpg`。无论页面在哪，都能找到图片。
- **相对路径**：相对于当前 HTML 文件的位置。例如 `images/photo.jpg` 表示当前目录下 images 文件夹里的图片。如果文件移动了路径，图片就会找不到。
:::

:::explain{title="常见错误：图片路径写错了会怎样？"}
以下三个错误是初学者最常踩的坑：

```html
<!-- 错误 1：src 地址写错了或者图片已被删除 -->
<img src="https://xxx.com/不存在的图片.jpg" alt="设计师肖像">
<!-- 结果：页面显示 alt 文字"设计师肖像"，图片位置是一个裂开的图标 -->

<!-- 错误 2：根本不写 alt -->
<img src="https://example.com/photo.jpg">
<!-- 结果：图片加载失败时，屏幕阅读器什么都读不出来——盲人用户完全不知道这里有一张图 -->

<!-- 错误 3：相对路径写错 -->
<img src="images/photo.jpg">
<!-- 结果：如果 HTML 文件位置移动了，图片就会找不到。新手建议先用绝对路径练手 -->
```

**现实工作中的代价：** 电商网站上一张商品图加载不出来还写了 `alt`，用户至少知道"这里本该有一张商品图"；如果连 `alt` 都不写，用户只会看到一个空位——然后关掉你的页面。
:::

:::explain{title="a — 创建超链接"}
`<a>` 标签可以创建超链接——点击后跳转到另一个页面：

```html
<a href="网址">点击这里</a>
```

- `href` — 跳转的目标地址（hypertext reference）。必须写完整网址，包括 `https://`。
- `target="_blank"` — 在新标签页中打开链接（不写这个属性则在当前页面打开）。
- 标签中间的文字是显示给用户看的——用户看到的是"点击这里"，点击后跳到 `href` 指定的地址。

**常见错误：** `href` 不写 `https://`，写成 `href="www.baidu.com"`——浏览器会以为这是你网站里的一个文件夹名，打不开。必须写成 `href="https://www.baidu.com"`。可以这样记：在浏览器地址栏复制过来的完整地址直接贴上，就不会漏掉 `https://`。
:::

:::explain{title="现实中的图片与链接"}
随便打开一个网页——新闻首页、微博、淘宝——每一张图背后都是 `<img>` 标签，每一个可点击的区域背后都是 `<a>` 标签。导航菜单是一组 `<a>` 包在 `<li>` 里，文章插图是 `<img>` 嵌在 `<p>` 中，社交头像是一张 `<img>` 外面再包一个 `<a>`——点击头像跳转到个人主页。这些就是网页最基本的"积木组合"。
:::

:::example{title="看例子"}
就像搭积木先摆底座再往上加，我们也分三步来构建这张个人卡片：

**第 1 步：先写标题和列表结构**
```html
<!-- h1：卡片大标题 -->
<h1>张三</h1>
```

**第 2 步：加入图片**
```html
<h1>张三</h1>
<!-- img 是单标签。src：图片地址；alt：图片显示不出来时的替代文字 -->
<img src="https://oss.tan8.com/yuepuku/155/77798/77798_prev.jpg" alt="设计师肖像">
```

**第 3 步：加上介绍文字和链接**
```html
<h1>张三</h1>
<img src="https://oss.tan8.com/yuepuku/155/77798/77798_prev.jpg" alt="设计师肖像">
<p>
  了解更多，请访问
  <!-- a 标签：href 指定点击后跳转的完整网址（含 https://） -->
  <a href="https://zh.wikipedia.org/wiki/张三">张三的维基百科</a>
</p>
```
:::

:::recap
这一节你学会了在网页中插入图片和链接——`<img>` 用 `src` 指定图片地址，`<a>` 用 `href` 指定点击后跳转到哪里。`alt` 是图片显示不出来时的替代文字，也是盲人用户能"听到"的描述。`href` 必须写完整的 `https://` 地址，否则浏览器找不到目标。图片和链接是互联网的"肉"和"血管"——没有图网页太干，没有链接网页就真的是孤岛。
:::
