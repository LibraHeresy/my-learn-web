# 综合项目 — 制作你的个人音乐主页

:::music-analogy
一场完整的音乐会需要节目单（列表）、演奏者介绍（标题/段落）、演出照片（图片）、曲目链接（链接）、舞台分区（div/span）、声部标注（语义化标签）、曲目表（表格）。现在把这些元素组合起来，就像指挥把各个声部合成一部完整的交响乐。
:::

:::explain{title="你已经学会了很多！"}
回顾一下你学过的所有标签。下面按"你想做什么"分类，方便查找：
**我想在页面上写文字：**
h1~h6（标题，数字越小字越大）| p（段落）| strong（加粗强调）| em（斜体强调）| br（换行，单标签）
**我想列一个清单：**
ul（无序列表，前面是圆点）| ol（有序列表，前面是数字）
ul 和 ol 里面必须放 li（列表项），就像曲目单上的每一行必须属于某张单子
**我想放图片或链接：**
img（图片，单标签）+ src 属性（图片地址）+ alt 属性（替代文字）
a 标签（超链接）+ href 属性（跳转地址，必须写 https://）
**我想把内容分组：**
div（块级容器，独占一行）| span（内联容器，不换行）
通过 class 属性给它们贴标签分组，通过 id 属性给某个元素唯一编号
**我想搭页面结构：**
header（页头）| nav（导航）| main（主体）| section（区块）| article（文章）| footer（页脚）
**我想嵌入音频或视频：**
audio（音频）+ video（视频）+ source（备选格式）
三个布尔属性：controls（显示播放按钮）、autoplay（自动播放）、loop（循环播放）
**我想做表格：**
table 是整个表格 → thead（表头区）+ tbody（数据区）→ 每个 tr 是一行 → 每行里 th（标题格，加粗居中）或 td（数据格）
跨列用 colspan，跨行用 rowspan
**我想做表单收集信息：**
form（表单容器）→ input（输入框，单标签）+ label（标签文字）+ textarea（多行文本）+ select（下拉框 → option 选项）+ button（按钮）
四组关键属性配合：input 的 id ↔ label 的 for（配对后点击文字就聚焦输入框）| name（提交时数据的名称）| value（填写的值）
**属性速查：这个标签能用哪些属性？**
| 标签 | 它的特有属性 |
|------|-------------|
| img | src, alt, width, height |
| a | href, rel |
| audio / video | src, controls, autoplay, loop |
| input | type, placeholder, name, value, min, max, checked |
| label | for |
| textarea | rows, placeholder |
| td / th | colspan, rowspan |
除了上面这些"某个标签专属的"，还有**全局属性——任何标签都能用**：class（分类名，可重复）| id（唯一编号，不重复）| style（内联样式）| lang（语言）| hidden（隐藏）

有些属性是**布尔属性——只有"有"和"没有"两种状态，不需要写值**：controls | autoplay | loop | checked | disabled | hidden

就像扬琴踏板——踩下去就止音，放开就不止音，没有"踩一半"。
现在，把这些知识组合起来，做一张属于你自己的"个人音乐主页"！
:::

:::task{title="逐步构建你的主页 ✨"}
::::step{purpose="页面第一印象来自 header。`<header>` 是页头区域，`<nav>` 是导航——告诉访问者你是谁、这里有什么。" expected="顶部标题变成了你的名字。导航栏的项目也改成你想展示的内容分类。"}
**修改标题和介绍**——把 `<header>` 中的标题改成你的名字，修改 `<nav>` 导航项目
::::

::::step{purpose="`<section>` + `<p>` + `<img>` 组合成内容区块。这是网页中最常见的内容模式。" expected="「关于我」区域展示了你的个人故事和新图片。`src` 链接正确时，新图片会显示。"}
**修改「关于我」**——在 `<p>` 中写下你的音乐故事，换一张喜欢的音乐家图片
::::

::::step{purpose="列表（`<ul>`/`<li>`）和表格（`<table>`）是结构化数据的两种主要方式。本章所有的标签知识都在这一步骤中综合运用。" expected="列表和表格都变成了你的个性化内容。你不再是一个模板的填写者，而是真正的作者。"}
**丰富音乐收藏**——在列表中替换成你喜欢的作曲家或曲目，在表格中添加你喜欢的音乐数据
::::

::::step{purpose="从零创建一个 `<section>`——从 HTML 标签到 CSS 样式，完全由你决定。这是从「模仿」到「创造」的关键一步。" expected="页面中多了一个你自己设计的区块。完成之后，这就是你的第一章毕业作品！"}
**挑战：新增自己的区块**——在 `<main>` 中再添加一个 `<section>`，内容自定
::::

:::

:::hint{title="别忘了这些要点"}
- 标签要**成对**使用，有开就有合（`<img>` 除外）
- 嵌套关系要清晰：`<ul>` 里放 `<li>`，`<table>` 里放 `<tr>` 再放 `<td>`
- 语义化标签让页面结构清晰：`header` → `main` → `section` → `footer`
- 完成之后，这就是你的**第一章毕业作品**！🎉
:::
