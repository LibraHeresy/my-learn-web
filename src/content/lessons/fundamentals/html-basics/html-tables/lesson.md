# 表格 — 整理你的数据

:::analogy
表格就像一张课程表——横是星期，竖是节次，每个格子放一条信息。把数据按行列对齐，比一堆文字堆在一起清晰得多。但注意：表格只用来展示"表格数据"，别用来做页面布局——那是 `<div>` 和 CSS 的活。
:::


:::prerequisite
**本节你需要知道这些词：**

- **标签（tag）**：用尖括号包裹的标记，成对出现——第一节"认识 HTML"中学过。
- **div 与 span**：`<div>` 是块级容器（独占一行），`<span>` 是内联容器（不换行）——第六节"div 与 span"中学过。
- **语义化标签**：`<header>`、`<main>`、`<footer>` 等——第七节"语义化标签"中学过。
- **列表**：`<ul>`（无序列表）、`<ol>`（有序列表）、`<li>`（列表项）——第四节"列表"中学过。
:::

:::explain{title="问题：多条数据并列对比，列表不够用了"}
列表是一维的——从上到下一项一项排。但如果数据有两个维度呢？比如你收集了 5 位设计师，每个人有名字、时期、国籍、代表作——你要同时对比所有人的所有信息。

用列表写出来是这样的：

```html
<p>张三：巴洛克，德国，《赋格的艺术》</p>
<p>李四：古典主义，奥地利，《第40号交响曲》</p>
<p>王五：浪漫主义，波兰，《降E大调夜曲》</p>
```

能看，但对不齐。你想一眼找到"所有人的时期"或"排序看谁最早"——很难。

表格有两个维度：**行（水平）** 和**列（垂直）**，数据对齐后对比一目了然。
:::

:::explain{title="表格的基本结构（三层嵌套）"}
HTML 表格的嵌套层级非常固定。从外到内，牢记这个顺序：

```
table > tr > td
表格  > 行  > 单元格
```

```html
<!-- table：整个表格的容器 -->
<table>
  <!-- tr：表格的一行（table row） -->
  <tr>
    <!-- td：表格数据单元格（table data）—— 一个格子 -->
    <td>张三</td>
    <td>巴洛克</td>
    <td>德国</td>
  </tr>
  <tr>
    <td>李四</td>
    <td>古典主义</td>
    <td>奥地利</td>
  </tr>
</table>
```

每一对 `<tr></tr>` 是一行，里面每个 `<td></td>` 是一个格子。行里的格子数量必须一致——否则表格对不齐。
:::

:::explain{title="th、thead、tbody — 表头与分区"}
`<th>` 代替 `<td>` 可以做**表头**——浏览器会自动加粗居中：

```html
<tr>
  <th>设计师</th>   <!-- 表头格：加粗居中 -->
  <th>时期</th>
  <th>国家</th>
</tr>
<tr>
  <td>张三</td>     <!-- 数据格：正常 -->
  <td>巴洛克</td>
  <td>德国</td>
</tr>
```

`<thead>` 和 `<tbody>` 把表头区和数据区分开——这有两个好处：
1. CSS 可以单独给表头和数据区设置不同样式
2. 打印时如果表格跨页，表头会自动重复打印在每一页顶部

```html
<table>
  <!-- thead：表头区域 -->
  <thead>
    <tr>
      <th>设计师</th>
      <th>时期</th>
      <th>国家</th>
    </tr>
  </thead>
  <!-- tbody：数据区域 -->
  <tbody>
    <tr>
      <td>张三</td>
      <td>巴洛克</td>
      <td>德国</td>
    </tr>
  </tbody>
</table>
```
:::

:::explain{title="colspan 和 rowspan — 合并单元格"}
有时一个格子需要跨越多列或多行——比如一个总标题横跨整张表：

```html
<!-- colspan：水平合并 —— 横跨 3 列 -->
<tr>
  <td colspan="3">更多设计师敬请期待</td>
</tr>

<!-- rowspan：垂直合并 —— 竖跨 2 行 -->
<tr>
  <td rowspan="2">张三</td>
  <td>赋格的艺术</td>
</tr>
<tr>
  <!-- 这行少写一个 <td>，因为上一行的 rowspan 占了位置 -->
  <td>哥德堡变奏曲</td>
</tr>
```

**常见错误：** `colspan` 或 `rowspan` 合并格子后，相邻行/列的格子数量没有相应减少——导致表格错位。合并了几个格，同位置就要少写几个 `<td>`。
:::

:::explain{title="表格的唯一正途：展示数据，不做布局"}
一个重要的原则：**表格只用来展示表格型数据**（数据表、价格对比、课表、排行榜）。

过去（2000 年代初期），网页开发者用 `<table>` 来给整个页面"排版"——左边菜单一列、右边内容一列，全用 `<table>` 来搭。这种做法在现代网页开发中已经被抛弃，原因是：
- 代码可读性极差——一个嵌套表格套另一个，层级深不可测
- 移动端适配几乎不可能——表格布局不会自动变一列
- 屏幕阅读器会把整个页面当表格读，障碍用户完全无法浏览

**现在做布局用 CSS（Flexbox、Grid）+ `<div>`，表格只做表格。**
:::

:::explain{title="现实中的表格"}
价格对比页（手机型号 vs 价格 vs 功能）、考试课表（星期 vs 节次 vs 科目）、财务报表（季度 vs 收入 vs 支出）、排行榜（排名 vs 名称 vs 分数）——这些都天然适合用表格。每当数据有两个维度需要"行列对齐"时，表格就是答案。
:::

:::example{title="看例子"}
下面的代码创建了一张设计师信息表，包含 `<thead>`、`<tbody>` 和表头：

```html
<!-- table：创建表格 -->
<table>
  <!-- thead：表头区域 —— 列标题 -->
  <thead>
    <tr>
      <!-- th：表头单元格，自动加粗居中 -->
      <th>设计师</th>
      <th>时期</th>
      <th>代表作</th>
    </tr>
  </thead>
  <!-- tbody：数据区域 —— 一行一个设计师 -->
  <tbody>
    <tr>
      <!-- td：数据单元格 -->
      <td>张三</td>
      <td>巴洛克</td>
      <td>赋格的艺术</td>
    </tr>
    <tr>
      <td>李四</td>
      <td>古典主义</td>
      <td>第40号交响曲</td>
    </tr>
  </tbody>
</table>
```

数据行列对齐，一眼就能对比所有设计师的信息。
:::

:::recap
这一节你学会了在网页上做表格——`<table>` 是整张表，`<tr>` 是每一行，`<th>` 是表头格（加粗居中），`<td>` 是数据格。用 `<thead>` 和 `<tbody>` 把表头和数据区分开，用 `colspan` 和 `rowspan` 合并格子。记住：表格只用来展示表格型数据（价格表、课表、排行榜），页面布局请用 `<div>` + CSS。现在你可以把任何二维数据整理成干净整齐的表格了。
:::
