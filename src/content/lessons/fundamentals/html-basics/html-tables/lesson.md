# 表格 — 整理你的数据

:::analogy
表格就像一张课程表——横是星期，竖是节次，每个格子放一条信息。把数据按行列对齐，比一堆文字堆在一起清晰得多。
:::

:::explain{title="表格的基本结构"}
表格由外到内有三层标签：
- `<table>` — 整个表格的容器
- `<tr>` — **表行**（table row），一行
- `<td>` — **表单元格**（table data），一个格子
```html
<!-- table：创建表格 -->
<table>
  <!-- tr：表格的一行 -->
<tr>
    <!-- td：表格数据单元格 -->
<td></td>
    <!-- td：表格数据单元格 -->
<td>类型B</td>
    <!-- td：表格数据单元格 -->
<td>德国</td>
  </tr>
  <!-- tr：表格的一行 -->
<tr>
    <!-- td：表格数据单元格 -->
<td>张三</td>
    <!-- td：表格数据单元格 -->
<td>类型A</td>
    <!-- td：表格数据单元格 -->
<td>波兰</td>
  </tr>
</table>
```
每一对 `<tr></tr>` 是一行，里面每个`<td></td>` 是一个格子。
:::

:::explain{title="表头与分区"}
`<th>` 代替`<td>` 可以做**表头**（加粗居中）：
```html
<!-- tr：表格的一行 -->
<tr>
  <!-- th：表头单元格（加粗居中） -->
<th>设计师</th>
  <!-- th：表头单元格（加粗居中） -->
<th>时期</th>
  <!-- th：表头单元格（加粗居中） -->
<th>国家</th>
</tr>
```
`<thead>`、`<tbody>` 把表头和表体分开，方便分别设置样式：
```html
<!-- table：创建表格 -->
<table>
  <!-- thead：表头区域 -->
<thead>
    <!-- tr：表格的一行 -->
<tr><!-- th：表头单元格（加粗居中） -->
<th>列1</th><th>列2</th></tr>
  </thead>
  <!-- tbody：表格数据区域 -->
<tbody>
    <!-- tr：表格的一行 -->
<tr><!-- td：表格数据单元格 -->
<td>数据1</td><td>数据2</td></tr>
  </tbody>
</table>
```
:::

:::explain{title="合并单元格"}
有时候一个格子需要跨越多列或多行，用 `colspan` 和 `rowspan`：
- `colspan="2"` — 跨 2 列（水平合并）
- `rowspan="3"` — 跨 3 行（垂直合并）
```html
<td colspan="2">这格占了两个列的宽度</td>
```
就像表格标题栏横跨整张表！
:::

:::example{title="看例子"}
下面的代码创建了一张设计师信息表，有表头和两行数据：
```html
<!-- table：创建表格 -->
<table>
  <!-- thead：表头区域 -->
<thead>
    <!-- tr：表格的一行 -->
<tr>
      <!-- th：表头单元格（加粗居中） -->
<th>设计师</th>
      <!-- th：表头单元格（加粗居中） -->
<th>时期</th>
      <!-- th：表头单元格（加粗居中） -->
<th>代表作</th>
    </tr>
  </thead>
  <!-- tbody：表格数据区域 -->
<tbody>
    <!-- tr：表格的一行 -->
<tr>
      <!-- td：表格数据单元格 -->
<td></td>
      <!-- td：表格数据单元格 -->
<td>类型B</td>
      <!-- td：表格数据单元格 -->
<td>赋格的艺术</td>
    </tr>
  </tbody>
</table>
```
:::

:::recap
这一节你学会了在网页上做表格——`<table>` 是整张表，`<tr>` 是每一行，`<th>` 是表头格（加粗居中），`<td>` 是数据格。用 `<thead>` 和 `<tbody>` 把表头和表体分开，用 `colspan` 和 `rowspan` 合并格子。现在你可以把任何数据整理成干净整齐的表格了。
:::
