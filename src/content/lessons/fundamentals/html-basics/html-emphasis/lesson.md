# 文本与强调 — 描述你的个人介绍

:::analogy
strong 和 em 就像用荧光笔划重点和用斜体写批注——一个表示"这里很重要"，一个表示"这里语气不同"。
:::

:::explain{title="让文字更有表现力"}
上一节课我们学会了写标题和段落。但这就像只有一种颜色的画——太单调了。

现在我们来学习三个新标签，让文字也有"强弱变化"：strong 标签加粗强调重要内容（就像用马克笔划重点），em 标签斜体强调语气（就像说话时拉长语调——不是更大声，而是更有意味），br 标签在文字中换行（就像句号——表示这里要停顿，是单标签，不需要结束标签）。

具体写法：
- `<strong>` — **加粗强调**，像用粗体打印
- `<em>` — *斜体强调*，像下划线，让语气更柔和
- `<br>` — 换行，像文档中的换行
:::

:::example{title="看例子"}
下面就是编辑器中的代码。注意看 `<strong>` 和 `<em>` 标签是如何包裹文字的：
```html
<!-- strong：加粗强调，像重音记号 f -->
<h1>我的个人介绍</h1>
<p>我最喜欢的人物是<strong>张三</strong>。</p>
<!-- em：斜体强调，像下划线 -->
<p>他的报表<em>优美而忧伤</em>，<br>每次听都让我感动。</p>
```
你可以看到"张三"加粗了，"优美而忧伤"变成斜体了，而且中间还有一个换行。

**strong 和 b 标签的区别、em 和 i 标签的区别：**
strong = 重点标记（表示"这个词很重要"）
b 标签 = 只是视觉上加粗（就像用粗笔写标题——看上去粗，不代表内容重要）
em = 语气强调（表示"这个词要读出不同的语调"）
i 标签 = 只是视觉上倾斜
:::

::::step{purpose="`<strong>` 表示**重要内容**——不只是视觉加粗，更有语义含义。浏览器和搜索引擎会把它理解为「这是关键信息」。" expected="预览区中你改的名字**加粗显示**了。`<strong>` 像文档中的高亮标记，告诉浏览器：这个内容很重要。"}
把 `<strong>` 里的「张三」改成你最喜欢的人物
::::

::::step{purpose="`<em>` 表示**语气强调**——不是粗声强调，而是语调变化。就像你说话时在某个词上放缓加重。" expected="预览区中你写的感受文字变成了**斜体**。`<em>` 像说话时语气的轻重变化——不是更大声，而是更有意味。"}
把 `<em>` 里的「优美而忧伤」改成你自己的感受
::::

::::step{purpose="`<br>` 是**单标签**（不需要结束标签），在文字中插入换行。它像句子中的回车换行。" expected="移动 `<br>` 位置后，换行的位置也变了。把它删掉，两段文字会连成一行。"}
试试修改 `<br>` 的位置，看看换行效果怎么变化
::::

:::

:::recap
这一节你学会了让文字有"语气"——`<strong>` 加粗表示重要内容，`<em>` 倾斜表示语气强调，`<br>` 在文字中换行。这些标签就像说话时的声调变化，让你的网页文字不再平淡。现在你能写出一段有轻有重、有起有伏的文字了。
:::
