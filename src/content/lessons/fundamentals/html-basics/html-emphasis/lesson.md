# 文本与强调 — 描述你的音乐故事

:::music-analogy
`<strong>` 标签像乐谱中的**强音记号（f）**，强调重要内容；`<em>` 像**连音线**，让文字更富感情。
:::

:::explain{title="让文字更有表现力"}
上一节课我们学会了写标题和段落。但这就像只有一种力度的音乐——太平淡了。

现在我们来学习三个新标签，让文字也有"强弱变化"：strong 标签加粗强调重要内容（就像重音记号 >），em 标签斜体强调语气（就像揉弦/颤音——不是更大声，而是更有韵味），br 标签在文字中换行（就像换气记号，是单标签，不需要结束标签）。

具体写法：
- `<strong>` — **加粗强调**，像强音记号 **f**
- `<em>` — *斜体强调*，像连音线，让语气更柔和
- `<br>` — 换行，像乐谱中的呼吸记号
:::

:::example{title="看例子"}
下面就是编辑器中的代码。注意看 `<strong>` 和 `<em>` 标签是如何包裹文字的：
```html
<!-- strong：加粗强调，像重音记号 f -->
<h1>我的音乐故事</h1>
<p>我最喜欢的作曲家是<strong>肖邦</strong>。</p>
<!-- em：斜体强调，像连音线 -->
<p>他的夜曲<em>优美而忧伤</em>，<br>每次听都让我感动。</p>
```
你可以看到"肖邦"加粗了，"优美而忧伤"变成斜体了，而且中间还有一个换行。

**strong 和 b 标签的区别、em 和 i 标签的区别：**
strong = 重音记号 `>`（表示"这个音要突出"）
b 标签 = 只是视觉上加粗（就像用粗笔写谱子——看上去粗，不代表要用力弹）
em = 揉弦/颤音（表示"这里要有表情"）
i 标签 = 只是视觉上倾斜
:::

::::step{purpose="`<strong>` 表示**重要内容**——不只是视觉加粗，更有语义含义。浏览器和搜索引擎会把它理解为「这是关键信息」。" expected="预览区中你改的名字**加粗显示**了。`<strong>` 像乐谱中的重音记号（>），告诉浏览器：这个内容很重要。"}
把 `<strong>` 里的「肖邦」改成你最喜欢的作曲家
::::

::::step{purpose="`<em>` 表示**语气强调**——不是粗声强调，而是语调变化。就像你说话时在某个词上放缓加重。" expected="预览区中你写的感受文字变成了**斜体**。`<em>` 像揉弦/颤音——不是更大声，而是更有韵味。"}
把 `<em>` 里的「优美而忧伤」改成你自己的感受
::::

::::step{purpose="`<br>` 是**单标签**（不需要结束标签），在文字中插入换行。它像乐谱中的换气记号。" expected="移动 `<br>` 位置后，换行的位置也变了。把它删掉，两段文字会连成一行。"}
试试修改 `<br>` 的位置，看看换行效果怎么变化
::::

:::

:::recap
这一节你学会了让文字有"语气"——`<strong>` 加粗表示重要内容，`<em>` 倾斜表示语气强调，`<br>` 在文字中换行。这些标签就像说话时的声调变化，让你的网页文字不再平淡。现在你能写出一段有轻有重、有起有伏的文字了。
:::
