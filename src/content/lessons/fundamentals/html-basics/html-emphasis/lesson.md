# 文本与强调 — 描述你的页面故事

:::analogy
`<strong>` 和 `<em>` 就像用荧光笔划重点和用斜体写批注——一个表示"这里很重要"，一个表示"这里语气不同"。而 `<b>` 和 `<i>` 只是换了个字体——别人看不出来你是强调意思还是随便换了个样式。
:::


:::prerequisite
**本节你需要知道这些词：**

- **标签（tag）**：用尖括号包裹的标记，如 `<h1>`、`<p>`——第一节"认识 HTML"中学过。
- **开始标签与结束标签**：`<h1>` 开始，`</h1>` 结束。`<br>` 和 `<hr>` 例外，它们是单标签，不需要结束。
- **HTML 文档结构**：`<head>` 放幕后信息，`<body>` 放可见内容——第二节"文档结构"中学过。
:::

:::explain{title="问题：纯标题和段落的文字太单调了"}
第一节课你学会了写标题和段落。但现实中的文字有轻有重、有起有伏——标题要醒目，重点要被看到，语气要有变化。如果你所有的文字都是普通段落 `<p>`，就像在纸上只有一种颜色的笔——读者看不出哪里重要、哪里是强调。

你需要知道：如何让你的文字"有语气"？
:::

:::explain{title="strong 和 em — 语义化的强调"}
HTML 提供了专门的标签来表达文字的不同"重量"：

```html
<p>我最喜欢的人物是<strong>张三</strong>。</p>
<p>他的报表<em>优美而忧伤</em>，每次听都让我感动。</p>
```

- `<strong>` — **重要强调**，文字加粗。表示"这个词很重要，不要错过"。搜索引擎和屏幕阅读器会识别它为关键信息。
- `<em>` — **语气强调**，文字倾斜。表示"这个词要读出不同的语调"，不是更大声，而是更有意味。
- `<br>` — 换行，单标签（不需要 `</br>`）。在文字中插入一个回车。
- `<hr>` — 水平分割线，单标签。在内容之间划一条分隔线，表示话题转换。
:::

:::explain{title="b vs strong、i vs em — 视觉 vs 语义"}
很多初学者会问：`<b>` 也加粗，`<i>` 也倾斜——为什么还要用 `<strong>` 和 `<em>`？

看这段代码：

```html
<!-- b：只是视觉上加粗，没有"重要"的含义 -->
<p>这位设计师叫<b>张三</b>，写了<b>1000</b>多首作品。</p>

<!-- strong：语义上是"重点信息" -->
<p>这位设计师叫<strong>张三</strong>，写了<strong>1000</strong>多首作品。</p>
```

两者的区别：

| 场景 | 用 `<b>` | 用 `<strong>` |
|------|----------|---------------|
| 搜索引擎理解 | 这只是加粗了 | 这是重要内容，优先索引 |
| 屏幕阅读器 | 无变化，正常语速读出 | 加重语气读出"张三" |
| 代码意思 | "我不小心把字弄粗了" | "这个名字是关键词" |

同样的，`<i>` 只是倾斜——比如书籍名、外来语、术语，这些用 `<em>` 不恰当。`<em>` 表示"这句话说出来的时候语调要变"。

**记忆口诀：** 如果只是装饰，用 `<b>` / `<i>`。如果这个词**真的重要**，用 `<strong>` / `<em>`。
:::

:::explain{title="br 和 hr — 单标签"}
`<br>` 和 `<hr>` 是 HTML 中的**单标签**（也叫"自闭合标签"），它们不需要结束标签：

```html
<!-- br：在文字中换行 -->
<p>第一行文字。<br>这是第二行。</p>

<!-- hr：在内容之间插入水平分割线 -->
<p>上一段内容。</p>
<hr>
<p>话题变了，下面是一段新内容。</p>
```

**常见错误：** 写成 `<br></br>` 或 `<hr></hr>`——这会创建两个换行或两条分割线，不是你要的效果。单标签就是单标签，不要硬给它加一个结束。
:::

:::explain{title="现实中的语义化强调"}
打开维基百科或任何新闻网站，F12 看源代码——几乎不会看到 `<b>` 和 `<i>`。专业的网页用 `<strong>` 标记关键人名、重要数据，用 `<em>` 标记文章中的语气强调。这不仅是"好看"，更是为了让搜索引擎能理解哪些词是你的核心内容，也让盲人用户用屏幕阅读器时能听到重点词的语调变化。
:::

:::example{title="看例子"}
下面就是编辑器中的代码。注意看 `<strong>` 和 `<em>` 标签是如何包裹文字的：

```html
<!-- h1：页面大标题 -->
<h1>我的个人介绍</h1>

<!-- strong：加粗表示"这个词很重要"，搜索引擎会识别 -->
<p>我最喜欢的人物是<strong>张三</strong>。</p>

<!-- em：斜体表示"这个词要读出不同的语调" -->
<!-- br：单标签换行，不需要 </br> -->
<p>他的报表<em>优美而忧伤</em>，<br>每次听都让我感动。</p>

<!-- hr：水平分割线，表示话题转换 -->
<hr>

<!-- i：只是视觉倾斜，没有"语气强调"的含义 -->
<p>他的代表作是<i>降E大调夜曲</i>（作品名用斜体是印刷惯例）。</p>
```

你可以看到"张三"加粗了，"优美而忧伤"变成斜体了，"降E大调夜曲"只是视觉倾斜。
:::

:::recap
这一节你学会了让文字有"语气"——`<strong>` 加粗表示重要内容，`<em>` 倾斜表示语气强调。它们的"表兄弟" `<b>` 和 `<i>` 只是换字体，没有语义。`<br>` 是单标签在文字中换行，`<hr>` 在内容之间画分割线。这些标签就像说话时的声调变化，让你的网页文字不再平淡。现在你能写出一段有轻有重、有起有伏的文字了。
:::
