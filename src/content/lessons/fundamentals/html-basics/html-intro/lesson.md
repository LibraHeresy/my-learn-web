# 认识 HTML — 你的第一行代码

:::analogy
HTML 就像盖房子的骨架和砖墙——先有墙，才知道房间在哪、门窗怎么开。没有 HTML，浏览器里什么都看不到，就像一片空地。建网页也是：先用 HTML 把内容结构搭好，后面再装修。
:::


:::prerequisite
**本节你需要知道这些词：**

**无需前置知识，这是 HTML 的第一课。** 你只需要知道浏览器是看网页用的，编辑器是写代码用的——就够了。
:::

:::explain{title="问题：你打开浏览器，里面有什么？"}
想一想：你每天刷的网页——新闻、朋友圈、视频——这些东西是怎么出现在屏幕上的？

答案就是 HTML。没有 HTML 的浏览器就是一张白纸，什么都没有。有了 HTML，文字、图片、链接才有了位置。

**网页的本质：** 你在浏览器里看到的一切，背后都是一行一行的 HTML 代码。浏览器读这些代码，然后把它"画"成你看到的页面。
:::

:::explain{title="HTML、CSS、JS — 网页的三件套"}
建一栋房子需要三样东西：

- `HTML` — 是砖墙和房间，搭出骨架，决定页面上"有什么"
- `CSS` — 是装修和粉刷，决定"长什么样"，什么颜色、多大字号
- `JavaScript` — 是水电开关，让房子"活"起来，能点击、能互动

你现在学的就是第一样：搭骨架。骨架搭好了，后面的一切才有地方放。
:::

:::explain{title="标签 — 搭骨架的积木块"}
HTML 使用**标签（tag）**来标记内容。每个标签用尖括号 `< >` 包裹，像一块积木：

- `<h1>` 是大标题，像报纸头版最醒目的那个字
- `<p>` 是段落，像书里的一段正文

```html
<h1>你好，世界！</h1>
<p>我开始了我的编程之旅。</p>
```

标签通常成对出现：`<h1>内容</h1>`，有开始就有结束。就像一封信——"开头"和"结尾"缺一个就不完整。

**常见错误：** 忘了写 `</h1>` 或 `</p>` 这样的结束标签。浏览器可能"猜测"你的意思勉强显示出来，但结构会乱——就像一封信写到一半突然没了落款。
:::

:::explain{title="现实中的 HTML"}
打开任何一个网页，右键点击空白处，选择"查看网页源代码"——你会看到满屏的 `<` 和 `>`。你看到的每一个标题、每一段文字、每一张图片，都对应着源代码里的一个标签。你马上就能自己写出这样的代码了。
:::

:::example{title="看例子"}
下面这段代码就是编辑器中你看到的。一个 `<h1>` 大标题加上一段 `<p>` 文字：

```html
<!-- 大标题：页面最醒目的文字 -->
<h1>你好，世界！</h1>
<!-- 段落：普通正文内容 -->
<p>我开始了我的编程之旅。</p>
```

预览区会实时显示这段代码的效果。这就是编程最激动人心的感觉——你写下一行字，屏幕上就多了一行字。你写下的不是"文字"，而是**能让浏览器听话的指令**。
:::

:::task{title="动手试试 ✨"}
::::step{purpose="让你体验**修改代码 → 立刻看到变化**的感觉。编程就是这样：写代码、看效果、再调整。未来每一节课都是这个循环。文件：编辑区中的 HTML 代码。" expected="预览区的标题会**立即变成你写的文字**。如果没变，检查 `<h1>` 和 `</h1>` 是否拼写正确。"}
把 `<h1>` 标签里的内容改成你自己的名字或任何你想写的内容
::::

::::step{purpose="巩固刚才的体验——标签不同，但操作方式完全一样。**所有 HTML 标签都是这样工作的**：改标签里的内容，页面就变。文件：编辑区中的 HTML 代码。" expected="预览区中 `<p>` 标签内的文字也**立即更新**为你写的新内容。你同时改变了标题和段落两处内容。"}
把 `<p>` 标签里的文字也改一改，写一句你想说的话
::::

::::step{purpose="让你自己**从零创建一个新元素**——不只是修改已有内容，而是真正动手写代码。这也是你第一次添加新标签。文件：编辑区中的 HTML 代码。" expected="预览区中**多出了一行新文字**，说明你成功创建了一个新的 HTML 元素。你已经会写网页了！"}
试试在 `<p>` 标签下面再加一行新的 `<p>...</p>`，写点别的内容
::::

::::step{purpose="对比浏览器中有 HTML 和没有 HTML 的差别：没有 HTML，浏览器就是空白。这让你理解 HTML 为什么是网页的基础——离了它，什么都没有。文件：编辑区中的 HTML 代码。" expected="被注释掉的内容从预览区消失。去掉 `<!--` 和 `-->`，内容又回来了。"}
挑战：用 `Ctrl + /` 注释掉所有代码（全部变成 `<!-- -->`），看看预览区还剩什么
::::

:::

:::recap
这一节你写出了人生第一段 HTML——用 `<h1>` 写大标题、用 `<p>` 写段落文字。HTML 标签就像积木块，用尖括号包起来，成对出现。你现在知道了：浏览器里看到的一切，背后都是 HTML 标签。你能改它、加它、删它，你已经会写网页了。
:::
