# 认识 HTML — 你的第一行代码

:::music-analogy
建房子第一步是搭骨架——砖墙、房间、门窗。HTML 就是网页的骨架，它决定了页面上有什么内容。先把骨架搭好，后面再装修和通电。
:::

:::explain{title="这一章你会学什么"}
这一章会带你认识网页最基础的组成部分：
- 标题、段落、图片、链接、表单
- 标签与嵌套
- 页面内容的层级关系

学完这一章，你就能独立写出一个结构清楚的静态页面。
:::

:::explain{title="为什么这章重要"}
HTML 决定的是“页面上到底有什么”。  
在工程语境里，我们会把这件事叫做 **页面结构**、**语义化标签**、**信息层级**。  
以后你学 CSS、JavaScript、Vue，都会建立在这层结构之上。
:::

:::hint{title="给刚开始转行的你"}
如果你觉得这节课“只是几个标签”，请不要低估它。  
很多前端问题的根子，不是样式不会写，也不是逻辑不会做，而是结构一开始就没搭好。  
你现在练的，是前端最底层的结构感。
:::

:::explain{title="什么是 HTML？"}
HTML 是网页的骨架。想象一下：**五线谱上有音符，网页上有内容。**
打开任何网页，你看到的所有文字、图片、链接，都是用 HTML 写出来的。就像作曲家把音符写在五线谱上，开发者把内容写在 HTML 里。
:::

:::explain{title="HTML、CSS、JS — 网页的三件套"}
建一栋房子需要三样东西：{{term:HTML}} 是砖墙和房间——搭出骨架，决定页面上有什么；{{term:CSS}} 是装修和粉刷——决定好不好看，什么颜色、多大字号；{{term:JavaScript}} 是水电开关——让房子"活"起来，能点击、能互动。你现在学的就是第一样：搭骨架。
:::

:::explain{title="标签 — 搭骨架的积木块"}
HTML 使用**标签（{{term:tag}}）**来标记内容。每个标签用尖括号 `< >` 包裹，像一块积木：

- `<h1>` 是大标题，像报纸头版最醒目的那个字
- `<p>` 是段落，像书里的一段正文

标签通常成对出现：`<h1>内容</h1>`，有开始就有结束。就像一封信——"开头"和"结尾"缺一个就不完整。
:::

:::example{title="看一个例子"}
下面这段代码就是编辑器中你看到的代码。一个 `<h1>` 大标题加上一段 `<p>` 文字：
```html
<!-- 大标题：页面最醒目的文字 -->
<h1>你好，音乐世界！</h1>
<!-- 段落：普通正文内容 -->
<p>我开始了我的编程之旅。</p>
```
预览区会实时显示这段代码的效果。
:::

:::task{title="动手试试 ✨"}
::::step{purpose="让你体验**修改代码 → 立刻看到变化**的感觉。编程就是这样：写代码、看效果、再调整。未来每一节课都是这个循环。" expected="预览区的标题会**立即变成你写的文字**。如果没变，检查 `<h1>` 和 `</h1>` 是否拼写正确。"}
把 `<h1>` 标签里的内容改成你自己的名字或任何你想写的内容
::::

::::step{purpose="巩固刚才的体验——标签不同，但操作方式完全一样。**所有 HTML 标签都是这样工作的**：改标签里的内容，页面就变。" expected="预览区中 `<p>` 标签内的文字也**立即更新**为你写的新内容。你同时改变了标题和段落两处内容。"}
把 `<p>` 标签里的文字也改一改，写一句你想说的话
::::

::::step{purpose="让你自己**从零创建一个新元素**——不只是修改已有内容，而是真正动手写代码。这也是你第一次添加新标签。" expected="预览区中**多出了一行新文字**，说明你成功创建了一个新的 HTML 元素。你已经会写网页了！"}
试试在 `<p>` 标签下面再加一行新的 `<p>...</p>`，写点别的内容
::::

:::

:::recap
这一节你学会了用 `<h1>` 写大标题、用 `<p>` 写段落文字。HTML 标签就像积木块，用尖括号包起来，成对出现。现在你可以自己创建一个包含标题和文字的网页了。
:::
