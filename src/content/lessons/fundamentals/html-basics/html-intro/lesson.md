# 认识 HTML — 你的第一行代码

:::music-analogy
HTML 就像五线谱，它决定了页面上有什么内容。五线谱告诉演奏者弹什么音，HTML 告诉浏览器显示什么内容。
:::

:::explain{title="什么是 HTML？"}
HTML 是网页的骨架。想象一下：**五线谱上有音符，网页上有内容。**
打开任何网页，你看到的所有文字、图片、链接，都是用 HTML 写出来的。就像作曲家把音符写在五线谱上，开发者把内容写在 HTML 里。
:::

:::explain{title="标签 — HTML 的\"音符\""}
每一首扬琴曲都写在一张乐谱上——音符告诉你要弹什么，指法告诉你用什么竹法。网页也一样：HTML 像乐谱的音符，告诉浏览器这里放什么内容；CSS 像演奏技法记号，告诉浏览器用什么颜色、多大字号；JavaScript 像你的双手，让网页动起来。

先从最简单的两个标签开始：h1 是页面最大的标题（就像扬琴谱上的大标题《春到清江》），p 标签是段落（就像一个乐句）。

HTML 使用**标签（tag）**来标记内容。每个标签用尖括号 `< >` 包裹：
- `<h1>` 是大标题，像乐章标题
- `<p>` 是段落，像乐谱中的乐句
标签通常成对出现：`<h1>内容</h1>`，就像乐谱的小节线一样，有开始就有结束。
:::

:::example{title="看一个例子"}
下面这段代码就是编辑器中你看到的代码。一个 `<h1>` 大标题加上一段 `<p>` 文字：
```html
<!-- 大标题：页面最醒目的文字 -->
<h1>你好，音乐世界！</h1>
<!-- 段落：普通正文内容 -->
<p>我开始了我的编程之旅。</p>
```右边预览区会实时显示这段代码的效果。
:::

:::task{title="动手试试 ✨"}
::::step{purpose="让你体验**修改代码 → 立刻看到变化**的感觉。编程就是这样：写代码、看效果、再调整。未来每一节课都是这个循环。" expected="右侧预览区的标题会**立即变成你写的文字**。如果没变，检查 `<h1>` 和 `</h1>` 是否拼写正确。"}
把 `<h1>` 标签里的内容改成你自己的名字或任何你想写的内容
::::

::::step{purpose="巩固刚才的体验——标签不同，但操作方式完全一样。**所有 HTML 标签都是这样工作的**：改标签里的内容，页面就变。" expected="预览区中 `<p>` 标签内的文字也**立即更新**为你写的新内容。你同时改变了标题和段落两处内容。"}
把 `<p>` 标签里的文字也改一改，写一句你想说的话
::::

::::step{purpose="让你自己**从零创建一个新元素**——不只是修改已有内容，而是真正动手写代码。这也是你第一次添加新标签。" expected="预览区中**多出了一行新文字**，说明你成功创建了一个新的 HTML 元素。你已经会写网页了！"}
试试在 `<p>` 标签下面再加一行新的 `<p>...</p>`，写点别的内容
::::

:::
