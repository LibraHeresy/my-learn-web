# 音频与视频 — 让网页发出声音

:::analogy
`<audio>` 和 `<video>` 就像给网页装上了音响和投影仪。加上 `controls` 属性就像在播放器上装了按钮——不装的话用户连"播放键"都找不到。
:::


:::prerequisite
**本节你需要知道这些词：**

- **单标签**：`<br>`、`<img>` 不需要结束标签——第三节、第五节中学过。它们的 `src` 属性指定资源地址。
- **属性（attribute）**：写在开始标签内的配置项，如 `src="地址"`、`alt="描述"`。
- **语义化标签**：`<header>`、`<main>`、`<footer>` 让页面结构清晰——第七节"语义化标签"中学过。
:::

:::explain{title="问题：网页只能'看'，能不能'听'和'看'视频？"}
到目前为止你的网页只有文字和图片——用户只能"读"。但现实中的网页不只有静态内容：音乐网站要播歌，视频网站要放视频，在线教育要插播教学录像。

HTML 内置了对音频和视频的支持——不需要装任何插件，直接用标签就能让网页发出声音、播放画面。

但有一个前提：你必须知道不同浏览器支持的格式不一样。一种格式打天下行不通——你需要"备胎"。
:::

:::explain{title="audio — 嵌入音频"}
`<audio>` 标签在网页中嵌入音频播放器：

```html
<!-- audio：嵌入音频播放器 -->
<audio controls src="音频文件地址">
  你的浏览器不支持音频播放
</audio>
```

- `controls` — **布尔属性**，写上就显示播放/暂停/音量控件。不写的话，用户看不到播放按钮——音频在播放但用户无法控制。
- `src` — 音频文件的地址（和 `<img>` 的 `src` 一样，指向资源文件）。
- `autoplay` — 自动播放（大多数浏览器会阻止自动播放，防止骚扰用户）。
- `loop` — 循环播放，播完自动从头再来。
- `muted` — 静音播放。

标签中间的文字（"你的浏览器不支持音频播放"）是**降级内容**——只在浏览器不支持 `<audio>` 标签时才显示。
:::

:::explain{title="source — 提供多种格式的备选方案"}
不同的浏览器支持不同的音频格式：MP3 通用但老，OGG 开放但 Safari 不支持。为了保证所有用户都能播放，用 `<source>` 标签提供多种格式：

```html
<audio controls>
  <!-- source：浏览器从上到下依次尝试，播放第一个支持的格式 -->
  <source src="music.mp3" type="audio/mpeg">
  <source src="music.ogg" type="audio/ogg">
  <!-- 如果所有格式都不支持，显示这行文字 -->
  你的浏览器不支持音频播放
</audio>
```

`type` 属性告诉浏览器这是什么格式——浏览器不用下载就知道自己能不能播，节省带宽。

**常见格式：**
- MP3（`audio/mpeg`）— 几乎所有浏览器都支持
- OGG（`audio/ogg`）— Firefox、Chrome 支持，Safari 不支持
- WAV（`audio/wav`）— 无损但文件大，一般不用于网页
:::

:::explain{title="video — 嵌入视频"}
`<video>` 标签的用法和 `<audio>` 几乎一模一样：

```html
<video controls width="640" height="360" src="视频地址">
  你的浏览器不支持视频播放
</video>
```

- `controls` — 显示播放控件（和 `<audio>` 一样）
- `width` / `height` — 设置播放器尺寸（像素）
- `poster` — 视频加载前显示的预览图（类似视频封面）
- `src` — 视频文件地址
- 同样支持 `<source>` 提供多种格式

**常见格式：**
- MP4（`video/mp4`）— 通用，几乎所有浏览器都支持
- WebM（`video/webm`）— Google 开源格式，Chrome/Firefox 支持
- OGG（`video/ogg`）— Firefox/Chrome 支持

**常见错误：** 写了 `<video>` 但没写 `controls`——视频加载了但用户没有播放按钮，什么都看不到。`controls` 大多数情况下都是必须的。
:::

:::explain{title="现实中的音频和视频"}
在线学习平台的每一段课程视频、播客网站的每一集音频、B站/YouTube 的每一个视频播放器——背后都是 `<audio>` 或 `<video>` 标签。结合后面的 JavaScript，你还能自己控制播放进度、切换曲目、做出一个简易音乐播放器。现在你已经有能力让网页"发声"了。
:::

:::example{title="看例子"}
下面的代码创建了一个音频播放器。注意 `<audio>` 的写法和 `<img>` 有明显的家族相似——都有 `src`，都是引用外部资源：

```html
<!-- audio：嵌入音频播放器 -->
<!-- controls：布尔属性，写上就显示播放/暂停/音量按钮（不写就没有） -->
<!-- src：音频文件地址 -->
<audio controls src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3">
  你的浏览器不支持音频播放
</audio>
```

预览区现在有了一个可以点击播放的音频播放器！这是你第一次让网页发出声音。
:::

:::hint{title="关于音频链接"}
免费可用的公网音频链接不太好找。文中使用的 SoundHelix 是一个提供免费示例音频的网站。你也可以搜索 "free mp3 sample url" 找其他公开测试音频。视频同理——找一个公网可访问的 MP4 链接来测试。
:::

:::recap
这一节你学会了让网页发出声音和播放视频——`<audio>` 嵌入音频播放器，`<video>` 嵌入视频播放器。加上 `controls` 属性就能显示播放按钮（不写用户就没办法控制）。用 `<source>` 提供多种格式可以兼容不同浏览器。`loop`（循环）、`autoplay`（自动播放）、`muted`（静音）都是布尔属性——写上就有，不写就没有。这两个标签用法几乎一样，学会一个就学会了另一个。现在你的网页可以像多媒体播放器一样工作了。
:::
