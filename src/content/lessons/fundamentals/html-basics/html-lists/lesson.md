# 列表 — 你喜欢的人物

:::analogy
列表就像购物清单——把东西一条一条列出来，有序的用数字编号，无序的用圆点标记。生活中的信息大部分都是列表。
:::

:::explain{title="用列表组织信息"}
当你想列出喜欢的人物、项目或工具时，就需要用到列表标签。ul 是无序列表（前面是圆点，先做哪项都行），ol 是有序列表（前面是数字，顺序不能乱），li 是列表项——每个 li 必须放在 ul 或 ol 里面，就像购物清单上的每一项必须属于某张单子。

具体写法：
- `<ul>` — **无序列表**（unordered list），前面是圆点
- `<ol>` — **有序列表**（ordered list），前面是数字
- `<li>` — **列表项**（list item），包在每个项目的外面
:::

:::example{title="看例子"}
下面就是编辑器中的代码。一个无序列表列出设计师，一个有序列表排出阅读顺序：
```html
<h1>我的音乐收藏</h1>
<p>这里是我喜欢的音乐作品：</p>
<h2>我喜欢的人物</h2>
<!-- 无序列表：圆点标记，顺序不重要 -->
<ul>
  <li></li>
  <li></li>
  <li>张三</li>
</ul>
<h2>我的阅读顺序</h2>
<!-- 有序列表：数字标记，顺序很重要 -->
<ol>
  <li>晨间阅读</li>
  <li>晚间笔记</li>
  <li>作品执行</li>
</ol>
```
注意： `<li>` 要放在 `<ul>` 或 `<ol>` 里面，不能单独使用哦。就像购物清单上的物品必须列在单子上一样！
:::

:::recap
这一节你学会了用列表整理信息——`<ul>` 是无序列表（前面是圆点），`<ol>` 是有序列表（前面是数字），每个 `<li>` 就是一个列表项。记住 `<li>` 必须放在 `<ul>` 或 `<ol>` 里面，不能单独出现。现在你可以把喜欢的人物、项目或任何清单整齐地排出来了。
:::
