# 列表 — 你喜欢的人物

:::analogy
列表就像购物清单——把东西一条一条列出来，有序的用数字编号，无序的用圆点标记。生活中的信息大部分都是列表：导航菜单是一列链接，菜谱是一列步骤，目录是一列章节名。
:::


:::prerequisite
**本节你需要知道这些词：**

- **标签（tag）**：用尖括号包裹的标记，成对出现——第一节"认识 HTML"中学过。
- **开始标签与结束标签**：`<h1>` 开始，`</h1>` 结束。开始和结束之间放内容。
- **strong 与 em**：`<strong>` 加粗表示重要，`<em>` 倾斜表示语气强调——第三节"文本与强调"中学过。
:::

:::explain{title="问题：很多条信息堆在一起，怎么看？"}
当你收集了 5 位设计师的名字、10 个想学的项目、3 个每日阅读步骤——你怎么在网页上展示？

如果全部写成一段 `<p>`，用逗号隔开：

```html
<p>张三、李四、王五、赵六、孙七</p>
```

能用，但难读。用户需要一眼看出：有几个项目？哪个先哪个后？有没有分类？

**现实需求：** 导航菜单是一组链接，每日阅读计划是一组有顺序的步骤，项目目录是一组结构分明的章节。这些在 HTML 里都叫"列表"。
:::

:::explain{title="三种列表：无序、有序、嵌套"}
HTML 提供了三种列表标签来对付不同的场景：

```html
<!-- 无序列表：圆点标记，顺序不重要 -->
<ul>
  <li>张三</li>
  <li>李四</li>
  <li>王五</li>
</ul>

<!-- 有序列表：数字标记，顺序很重要 -->
<ol>
  <li>晨间阅读</li>
  <li>晚间笔记</li>
  <li>作品执行</li>
</ol>
```

- `<ul>` — **无序列表**（unordered list），前面是圆点。适合：设计师名单、标签列表、导航链接——先看哪个都行。
- `<ol>` — **有序列表**（ordered list），前面是数字。适合：阅读步骤、排行榜、操作流程——顺序不能乱。
- `<li>` — **列表项**（list item），必须放在 `<ul>` 或 `<ol>` 里面。就像购物清单上的物品必须列在某张单子上。
:::

:::explain{title="嵌套列表 — 多层结构"}
列表里面可以再放列表——就像目录下的子目录：

```html
<!-- 外层 ul：大类 -->
<ul>
  <li>类型B时期
    <!-- 内层 ul：子类，自动缩进 -->
    <ul>
      <li>张三</li>
      <li>李四</li>
    </ul>
  </li>
  <li>20世纪
    <ul>
      <li>王五</li>
      <li>赵六</li>
    </ul>
  </li>
</ul>
```

内层列表会自动缩进，形成清晰的层级。这就是网页导航菜单、目录结构的底层机制。

**常见错误：** `<li>` 单独出现，没有放在 `<ul>` 或 `<ol>` 里面——浏览器可能显示，但结构不合法。另外，把 `<li>` 直接放在 `<li>` 里面作为子元素也不行——嵌套列表时，内层 `<ul>`/`<ol>` 必须放在外层 `<li>` 里面。
:::

:::explain{title="现实中的列表"}
你每天遇到的列表比你想象的多：
- **导航菜单**：网站顶部"首页 | 产品 | 关于 | 联系"——就是一个 `<ul>` 包着 `<li>`，每个 `<li>` 里放一个 `<a>` 链接。
- **菜谱步骤**："1. 备菜 2. 热油 3. 翻炒"——典型的 `<ol>`，顺序不能错。
- **文章目录**：章节 1 → 子节 1.1 → 子节 1.2 → 章节 2 ——嵌套列表。百度百科、维基百科的目录栏就是这么做的。
- **排行榜**：歌曲排行、游戏排行——`<ol>` 序号天然适合。
:::

:::example{title="看例子"}
下面的代码用无序列表列出设计师，用有序列表排出阅读顺序：

```html
<h1>我的音乐收藏</h1>
<p>这里是我喜欢的音乐作品：</p>

<h2>我喜欢的人物</h2>
<!-- ul：无序列表，圆点标记。设计师之间没有先后排位 -->
<ul>
  <li>张三</li>
  <li>李四</li>
  <li>王五</li>
</ul>

<h2>我的阅读顺序</h2>
<!-- ol：有序列表，数字标记。步骤顺序不能打乱 -->
<ol>
  <li>晨间阅读</li>
  <li>晚间笔记</li>
  <li>作品执行</li>
</ol>
```

注意：`<li>` 要放在 `<ul>` 或 `<ol>` 里面，不能单独使用。就像购物清单上的物品必须列在单子上一样！
:::

:::recap
这一节你学会了用列表整理信息——`<ul>` 是无序列表（前面是圆点），`<ol>` 是有序列表（前面是数字），每个 `<li>` 就是一个列表项。列表可以嵌套——外层放分类，内层放细节，自动缩进层层分明。记住 `<li>` 必须放在 `<ul>` 或 `<ol>` 里面，不能单独出现。你现在已经能做出网站导航菜单、菜谱步骤、文章目录了——这些全是用列表搭的。
:::
