# 列表 — 你喜欢的作曲家

:::music-analogy
列表就像**乐章目录**或**曲目单**——把信息有序地组织起来，让人一目了然。
:::

:::explain{title="用列表组织信息"}
当你想列出喜欢的作曲家、曲目或乐器时，就需要用到列表标签。ul 是无序列表（前面是圆点，先弹哪首都行），ol 是有序列表（前面是数字，顺序不能乱），li 是列表项——每个 li 必须放在 ul 或 ol 里面，就像节目单上的每一行必须属于某张单子。

具体写法：
- `<ul>` — **无序列表**（unordered list），前面是圆点
- `<ol>` — **有序列表**（ordered list），前面是数字
- `<li>` — **列表项**（list item），包在每个项目的外面
:::

:::example{title="看例子"}
下面就是编辑器中的代码。一个无序列表列出作曲家，一个有序列表排出练琴顺序：
```html
<h1>我的音乐收藏</h1>
<p>这里是我喜欢的音乐作品：</p>
<h2>我喜欢的作曲家</h2>
<!-- 无序列表：圆点标记，顺序不重要 -->
<ul>
  <li>巴赫</li>
  <li>莫扎特</li>
  <li>肖邦</li>
</ul>
<h2>我的练琴顺序</h2>
<!-- 有序列表：数字标记，顺序很重要 -->
<ol>
  <li>音阶练习</li>
  <li>练习曲</li>
  <li>乐曲演奏</li>
</ol>
```
注意： `<li>` 要放在 `<ul>` 或 `<ol>` 里面，不能单独使用哦。就像乐谱中的音符必须放在小节里一样！
:::

:::recap
这一节你学会了用列表整理信息——`<ul>` 是无序列表（前面是圆点），`<ol>` 是有序列表（前面是数字），每个 `<li>` 就是一个列表项。记住 `<li>` 必须放在 `<ul>` 或 `<ol>` 里面，不能单独出现。现在你可以把喜欢的作曲家、曲目或任何清单整齐地排出来了。
:::
