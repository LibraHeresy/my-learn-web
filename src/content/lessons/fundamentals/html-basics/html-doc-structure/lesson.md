# HTML 文档结构 — 了解网页的"设计图格式"

:::analogy
每个网页都有一个标准结构，就像每封信都有抬头、正文和落款——DOCTYPE 是"这是一封信"的声明，head 是信封信息，body 是信纸内容。
:::

:::explain{title="每个网页都有一副\"骨架\""}
就像写信有固定的格式——称呼写在最前面，然后是正文，最后是落款和日期。HTML 页面也有自己的骨架结构。

在认识骨架之前，先记住几个关键标签的名字和角色：DOCTYPE html 声明文档类型（告诉浏览器"这是 HTML5 页面"），html 是整个页面的根元素，head 存放幕后配置信息，body 存放所有可见内容。
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的页面标题</title>
</head>
<body>
  <h1>你好，世界！</h1>
  <p>这是页面上可见的内容。</p>
</body>
</html>
```
这就是一份"标准设计图"——每一部分都有固定的位置和意义。
:::

:::explain{title="逐行读懂这个结构"}
`<!DOCTYPE html>` — 声明"这是 HTML5 文档"。就像文件封面写着"版本2.0"，浏览器看到这行就知道用什么规则来解析页面。
`<html lang="zh-CN">` — 整个文档的根元素，`lang` 属性告诉浏览器页面是什么语言。
`<head>` — 页面"元信息"区**，不显示在页面上：
- `<meta charset="UTF-8">` — 声明字符编码（**必须写！**不然中文会乱码）
- `<meta name="viewport" ...>` — 告诉手机浏览器正确缩放（响应式必备）
- `<title>` — 浏览器标签页上显示的文字
`<body>` — 页面"正文"，你之前写的所有内容都放在这里面。
:::

:::explain{title="head 中的其他重要元素"}
`<head>` 区还可以包含：
```html
<head>
  <!-- 链接 CSS 样式文件 -->
  <link rel="stylesheet" href="style.css">
  <!-- 网站的图标（favicon） -->
  <link rel="icon" href="favicon.ico">
  <!-- SEO 描述 -->
  <meta name="description" content="一个学习编程的音乐主题网站">
</head>
```
虽然 `<head>` 里的内容不直接显示在页面上，但它像产品说明书上的规格标注一样——决定了页面如何被理解和渲染。
:::

:::example{title="看例子"}
现在你右侧编辑器中看到的代码，就是放在 `<body>` 里面的。但这个教学平台已经帮你写好了 `<head>` 和 `<body>` 的框架——这就是为什么你只需要写内容部分的代码。
当你未来自己创建一个 `.html` 文件时，记得要先写完整的文档结构！
```html
<!-- 你将来会这样开始一个网页 -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的音乐博客</title>
</head>
<body>
  <!-- 你的内容写在这里 -->
</body>
</html>
```
:::

:::explain{title="HTML 注释：给自己留便条"}
写代码时经常想给自己留个记号——这段是干什么的、为什么这样写——但又不想让它显示在页面上。
HTML 提供了**注释（Comment）**：
```html
<!-- 这是注释，不会显示在页面上 -->
<p>这行会正常显示</p>
```
注释以 `<!--` 开头，以 `-->` 结尾，中间的内容会被浏览器完全忽略。
**快捷键：** 选中要注释的代码，按 `Ctrl + /`（Mac: `Cmd + /`），编辑器会自动添加或移除注释。这个快捷键在 HTML、CSS、JS 中都通用。
**注释能做什么：**
- 📝 标记代码区块，方便以后维护（"这一段是导航栏"）
- 🙈 暂时隐藏某些内容（调试时很有用）
- 💬 给合作的队友留下说明
```html
<!-- 导航栏区域 -->
<nav>
  <a href="/">首页</a>
  <!-- 暂时隐藏"关于我们"，下个月上线
  <a href="/about">关于我们</a>
  -->
</nav>
```
`<!--` 和 `-->` 之间的内容不仅不会显示——它也不会执行。注释掉整段 `<p>` 标签，这段文字就从页面中消失了。
:::
