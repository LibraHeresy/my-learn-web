# div 与 span — 块级与内联元素

:::analogy
div 就像一个大纸箱，装下一整块内容区域，独占一行；span 就像一个透明塑料袋，包裹句子内部的一小段文字，不打断句子流动。
:::

:::explain{title="两种最基本的\"容器\""}
div 和 span 本身不添加任何样式，它们是用来把内容分组的——div 是块级元素——独占一行，像文章的一个段落；span 是内联元素——在文字流中不换行，像句子里的一个词。

class 属性可以给它们贴上分类标签（🌐全局属性——所有标签都能用）。class 就像给衣服分类——"这批是夏装""这批是冬装"，同一类衣服可以挂在不同的衣柜里。同一个 class 可以给多个元素用。

具体写法：
- `<div>` — **块级元素**（block），独占一行，像一整个段落
- `<span>` — **内联元素**（inline），在文字流内部，像句子中的标记
```html
<div>我是一个块，占满整行。</div>
<div>我是另一个块，自动换行。</div>
<p>文字中<span>这个部分</span>被span标记了。</p>
```
:::

:::explain{title="什么时候用 div？什么时候用 span？"}
用 `<div>` 当你要：
- 创建一个卡片、面板、区块
- 把一组元素包在一起
- 需要块级布局（独占一行）
用 `<span>` 当你要：
- 高亮句子中的某个词
- 给行内文字加特殊样式
- 不改动文字流的情况下标记内容
简单记忆：**div 管"块"，span 管"字"。**div 就像衣柜里的抽屉——一格一格各自分区；span 就像在书里用荧光笔画几个字做标记。
**class 和 id 的区别**（两个都是全局属性，但用法完全不同）：
- class = 衣服尺码（S/M/L）——多个元素可以共用同一个 class 名，CSS 用 .class名 选中
- id = 身份证号——整个页面同个 id 只能出现一次，CSS 用 #id名 选中

什么时候用 class？给一组相似元素统一样式（比如所有"设计师名字"都加金色）
什么时候用 id？给独一无二的元素特殊样式（比如页面唯一的"提交按钮"）
:::

:::example{title="看例子"}
下面的代码用 `<div>` 创建了三张卡片，用 `<span>` 在文字中高亮了设计师名字：
```html
<div class="card">
  <h2><span class="name"></span></h2>
  <p>时期：<span class="name">类型B</span></p>
</div>
```
注意：每个 `<div>` 独占一行，而 `<span>` 只是在行内标记文字。
:::

:::recap
这一节你学会了两种"容器"——`<div>` 独占一行，用来划分大块区域（像卡片、面板）；`<span>` 不换行，用来标记句子里的某几个字。你还学会了用 `class` 给元素贴标签，同一类元素可以有相同的样式。现在你可以把网页内容分门别类地组织起来了。
:::
