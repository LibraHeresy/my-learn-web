# div 与 span — 块级与内联元素

:::analogy
`<div>` 就像一个大纸箱，装下一整块内容区域，独占一行；`<span>` 就像一个透明塑料袋，包裹句子内部的一小段文字，不打断句子流动。网页布局就是靠"纸箱"分区和"塑料袋"标细节。
:::


:::prerequisite
**本节你需要知道这些词：**

- **标签（tag）**：用尖括号包裹的标记，成对出现——第一节"认识 HTML"中学过。
- **单标签**：`<br>`、`<img>` 不需要结束标签——第三节、第五节中学过。
- **列表**：`<ul>`（无序列表）、`<ol>`（有序列表）、`<li>`（列表项）——第四节"列表"中学过。
- **strong 与 em**：`<strong>` 加粗表示重要，`<em>` 倾斜表示语气强调——第三节"文本与强调"中学过。
:::

:::explain{title="问题：一堆标签平铺在一起，怎么分组？"}
你已经学会了很多标签：标题、段落、图片、链接、列表。把它们直接放在 `<body>` 里，从上到下排成一列——基本能用，但就像把家里所有东西堆在一个大房间里：床、餐桌、沙发、书柜，全挤在同一个空间。

真实的网页需要分区：导航栏是一个区，文章正文是一个区，评论区是一个区，页脚是一个区。如果不分组，CSS 没法给"导航栏"统一上色，JavaScript 没法给"评论区"批量更新内容。

你需要两个工具：`<div>` 管"一大块"，`<span>` 管"一小段"。
:::

:::explain{title="div 和 span — 块级 vs 内联"}
`<div>` 和 `<span>` 本身不添加任何样式。它们是**容器**——用来把内容分组：

```html
<!-- div：块级元素，独占一行，像一个大抽屉 -->
<div>我是一个块，占满整行。</div>
<div>我是另一个块，自动换到下一行。</div>

<!-- span：内联元素，在文字流中不换行，像荧光笔标记 -->
<p>文字中<span>这个部分</span>被 span 标记了。</p>
```

- `<div>` — **块级元素**（block）。特点：独占一行、宽度自动撑满父容器、前后自动换行。适合：卡片、面板、页面大区。
- `<span>` — **内联元素**（inline）。特点：不换行、宽度由内容决定、在文字流中"随波逐流"。适合：句子里的关键词高亮、行内标记。
:::

:::explain{title="class 和 id — 给元素贴标签"}
`class` 和 `id` 是**全局属性**——所有 HTML 标签都能用它们：

```html
<!-- class：分类标签，多个元素可以共用同一个 class 名 -->
<div class="card">
  <h2><span class="name">张三</span></h2>
  <p>时期：<span class="period">巴洛克</span></p>
</div>

<!-- id：唯一编号，整个页面同个 id 只能出现一次 -->
<button id="submit-btn">提交</button>
```

- `class` — **分类名**，可重复。像衣服的尺码标签（S/M/L）——多个元素可以共用同一个 class。CSS 用 `.class名` 选中所有同类元素。
- `id` — **唯一编号**，不可重复。像身份证号——整个页面只有一个人能用这个号。CSS 用 `#id名` 选中这个唯一元素。

**常见错误：** 在同一个页面中给两个元素写相同的 `id`。浏览器不会报错，但 JavaScript 用 `getElementById` 只会找到第一个，第二个就被忽略了。而 `class` 可以尽情重复——它就是用来"分组"的。
:::

:::explain{title="不分组 vs 分组 — 对比两种页面"}
想象一个"扁平"的页面——所有内容直接堆在 `<body>` 里：

```html
<!-- 没有分组的页面：一团乱麻 -->
<h1>我的网站</h1>
<a href="/">首页</a>
<a href="/about">关于</a>
<h2>文章标题</h2>
<p>文章内容第一段...</p>
<p>文章内容第二段...</p>
<h3>评论</h3>
<p>用户A：很好！</p>
<p>用户B：不错。</p>
<p>版权信息 2026</p>
```

浏览器能显示，但所有人——包括你、你的队友、搜索引擎——都看不出哪里是导航、哪里是文章、哪里是评论、哪里是页脚。

用 `<div>` 分组之后：

```html
<!-- 分组后的页面：结构分明 -->
<div class="header">
  <h1>我的网站</h1>
  <div class="nav">
    <a href="/">首页</a>
    <a href="/about">关于</a>
  </div>
</div>
<div class="main">
  <div class="article">
    <h2>文章标题</h2>
    <p>文章内容第一段...</p>
    <p>文章内容第二段...</p>
  </div>
  <div class="comments">
    <h3>评论</h3>
    <p>用户A：很好！</p>
    <p>用户B：不错。</p>
  </div>
</div>
<div class="footer">
  <p>版权信息 2026</p>
</div>
```

立刻就能看出：header 是头部区，nav 是导航，main 是主体，article 是文章，comments 是评论区，footer 是页脚。后面学 CSS 时，一条 `.header { background: #333; }` 就能给整个头部区统一上色。

**这不仅仅是"好看"——这是前端工程中最基础的"分而治之"思维。**
:::

:::explain{title="现实中的 div 和 span"}
打开任何一个网页，F12 看 Elements/元素 面板——你会看到密密麻麻的 `<div>` 和 `<span>`。网页的每一个视觉区块（导航栏、侧边栏、卡片列表、评论区）几乎都是以 `<div>` 为容器。`<span>` 则出现在任何需要"在行内区别对待某几个字"的场景。它们是前端工程师最常用的两个标签——因为它们什么都不做，所以什么都能做。
:::

:::example{title="看例子"}
下面的代码用 `<div>` 创建了三张设计师卡片，用 `<span>` 在文字中高亮了名字和时期：

```html
<!-- div.card：一张卡片容器，块级元素，每张卡片独占一行 -->
<div class="card">
  <!-- span.name：行内高亮设计师名字 -->
  <h2><span class="name">张三</span></h2>
  <p>时期：<span class="period">巴洛克</span></p>
</div>

<div class="card">
  <h2><span class="name">李四</span></h2>
  <p>时期：<span class="period">古典主义</span></p>
</div>

<div class="card">
  <h2><span class="name">王五</span></h2>
  <p>时期：<span class="period">浪漫主义</span></p>
</div>
```

注意：每个 `<div class="card">` 独占一行，而 `<span>` 只是在行内标记文字。三者结构完全一样，靠 `class` 区分角色。
:::

:::recap
这一节你学会了两种"容器"——`<div>` 独占一行，用来划分大块区域（像卡片、面板、页面分区）；`<span>` 不换行，用来标记句子里的某几个字。你还学会了用 `class` 给元素贴分类标签（可重复），用 `id` 给定唯一编号（不重复）。不分组时页面是一团乱麻，分组之后结构分明——现在你可以把网页内容分门别类地组织起来了。这为后面学 CSS 和 JavaScript 打下了布局基础。
:::
