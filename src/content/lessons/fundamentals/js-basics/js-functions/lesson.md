# 函数 — 封装你的代码逻辑

:::analogy
函数就像菜谱——把做一道菜的步骤写下来，取个名字。下次做同样的菜，喊"照这个菜谱做"就行，不需要每次重新写一遍步骤。
:::

:::explain{title="什么是函数？"}
函数是一段**有名字的代码块**，把一组操作封装起来，需要时调用：
```js
function sayHello() {
  alert("你好！");
}
sayHello();  // 调用函数
```
函数的好处：
- **避免重复**：同样的代码不用写很多遍
- **给代码起名字**：一看函数名就知道它做什么
- **可以传参数**：像给机器换不同的零件
:::

:::explain{title="带参数的函数"}
函数可以接收**参数**（输入），然后根据参数做不同的事：
```js
function introduce(composer, piece) {
  return `${composer}创作了《${piece}》。`;
}
let result1 = introduce("张三", "报表");
let result2 = introduce("", "文档E");
```
- `composer` 和 `piece` 是**参数**——像函数接收的输入
- `return` 把结果**返回**——像函数给出的输出
- 同样一个 `introduce` 函数，传入不同的设计师，得到不同的句子
> 💡 关于 `this`：在普通函数中，`this` 指向"谁调用了这个函数"。比如 `button.addEventListener("click", handleClick)` 中，`handleClick` 里的 `this` 指向被点击的 `button`。后面学到事件和对象时你会更深入地理解它。
:::

:::example{title="看例子"}
下面的代码定义了一个 `createCard` 函数，它接收设计师信息并返回 HTML 字符串：
```js
// function：定义一个函数，像"设计图模板"——给参数就能生成结果
function createCard(composer, period, piece) {
  return `                         // return：把结果"返回"给调用者
    <div class="card">
      <h2>${composer}</h2>
      <p>时期：${period}</p>
      <p>代表作：《${piece}》</p>
    </div>
  `;
}
// 调用函数：传入不同的参数，得到不同的卡片
let html = createCard("", "类型B", "赋格的艺术");
let html2 = createCard("德彪西", "印象派", "春天");
```
打开 JS 选项卡看看函数怎么生成页面的三张卡片。
:::

::::

:::recap
这一节你学会了用函数封装一段代码——`function` 定义一个函数（像设计图模板），传不同的参数进去就得到不同的结果，`return` 把结果送回来。函数的好处是写一次就能反复调用，不用复制粘贴。你可以把生成一张卡片的逻辑写成一个函数，每次传不同的设计师名字进去，自动生成不同的卡片。现在你的代码开始"模块化"了。
:::
