# 函数 — 封装你的音乐逻辑

:::music-analogy
函数就像**乐曲的主题动机**——一段可重复使用的旋律片段。贝多芬第五交响曲的"当当当当"动机在全曲中反复出现、变形、发展。函数也是：写好一次，到处调用。
:::

:::explain{title="什么是函数？"}
函数是一段**有名字的代码块**，把一组操作封装起来，需要时调用：
```js
function sayHello() {
  alert("你好！");
}
sayHello();  // 调用函数
```
函数的好处：
- **避免重复**：同样的代码不用写很多遍
- **给代码起名字**：一看函数名就知道它做什么
- **可以传参数**：像给动机配不同的乐器
:::

:::explain{title="带参数的函数"}
函数可以接收**参数**（输入），然后根据参数做不同的事：
```js
function introduce(composer, piece) {
  return `${composer}创作了《${piece}》。`;
}
let result1 = introduce("肖邦", "夜曲");
let result2 = introduce("莫扎特", "魔笛");
```
- `composer` 和 `piece` 是**参数**——像函数接收的输入
- `return` 把结果**返回**——像函数给出的输出
- 同样一个 `introduce` 函数，传入不同的作曲家，得到不同的句子
> 💡 关于 `this`：在普通函数中，`this` 指向"谁调用了这个函数"。比如 `button.addEventListener("click", handleClick)` 中，`handleClick` 里的 `this` 指向被点击的 `button`。后面学到事件和对象时你会更深入地理解它。
:::

:::example{title="看例子"}
下面的代码定义了一个 `createCard` 函数，它接收作曲家信息并返回 HTML 字符串：
```js
// function：定义一个函数，像"乐谱模板"——给参数就能生成结果
function createCard(composer, period, piece) {
  return `                         // return：把结果"返回"给调用者
    <div class="card">
      <h2>${composer}</h2>
      <p>时期：${period}</p>
      <p>代表作：《${piece}》</p>
    </div>
  `;
}
// 调用函数：传入不同的参数，得到不同的卡片
let html = createCard("巴赫", "巴洛克", "赋格的艺术");
let html2 = createCard("德彪西", "印象派", "月光");
```
打开 JS 选项卡看看函数怎么生成页面的三张卡片。
:::

::::step{purpose="让你理解函数调用的核心：同一个函数，传入不同的参数，产生不同的输出。就像同一个旋律动机，用钢琴弹和用提琴拉，效果不同但结构一样——这就是函数的复用之美。" expected="页面上对应卡片的名字、时期、代表作都变成了你新输入的作曲家信息，其他两张卡片保持不变。函数本身一行都没改，只是换了个「参数」。"}
修改已有的 `createCard()` 调用，把作曲家名字换成你喜欢的作曲家（如把「巴赫」改成「拉赫玛尼诺夫」），同时更新时期和代表作参数
::::

::::step{purpose="让你体验「调用一次函数就多一张卡片」的便利——不需要重新写整段 HTML 拼接逻辑，只需一行函数调用。这正是函数的核心价值：封装重复逻辑，一处定义，处处使用。" expected="页面上从 3 张卡片变成 4 张，新增的卡片和其他卡片样式完全一致，说明函数正确生成了 HTML 结构。你创造了一张全新的卡片！"}
新增一行 `createCard()` 调用，创建第四张卡片。比如：`html += createCard("舒伯特", "浪漫主义", "未完成交响曲");`，注意用 `+=` 追加到 html 变量中
::::

::::step{purpose="练习修改函数定义——增加参数意味着函数的能力增强了。就像给一段旋律加一个变奏：原有的结构不变，但增加了新的表现力。理解「改一处定义，所有调用点都受益」这个设计思想。" expected="所有卡片都会多出一行国籍信息，而你只需要改函数的定义和调用参数——这就是函数作为「单一真相来源」的力量。"}
挑战：给 `createCard` 函数增加一个 `country` 参数。先在函数定义的模板字符串中添加一行 `<p>国籍：${country}</p>`，然后在每次调用时传入国籍参数（如 `"德国"`、`"奥地利"`、`"法国"`）
::::

:::

:::recap
这一节你学会了用函数封装一段代码——`function` 定义一个函数（像乐谱模板），传不同的参数进去就得到不同的结果，`return` 把结果送回来。函数的好处是写一次就能反复调用，不用复制粘贴。你可以把生成一张卡片的逻辑写成一个函数，每次传不同的作曲家名字进去，自动生成不同的卡片。现在你的代码开始"模块化"了。
:::
