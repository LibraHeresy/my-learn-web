# 认识 JavaScript — 给页面注入生命

:::music-analogy
如果 HTML 是乐谱、CSS 是演奏法记号，那么 JavaScript 就是**指挥家**——它让静态的乐谱动起来，控制演奏的节奏、顺序和互动。
:::

:::explain{title="什么是 JavaScript？"}
HTML 决定了页面上"有什么"，CSS 决定了"长什么样"，而 JavaScript（简称 JS）决定了"能做什么"。
有了 JavaScript，网页可以：
- 响应用户的点击和输入
- 动态改变内容和样式
- 播放音乐和动画
- 记住用户的操作
就像一个指挥家让乐团从静止的乐器变成流动的音乐！
:::

:::explain{title="JS 注释：给自己留备忘"}
代码越写越多以后，你需要给代码加一些说明——这段在做什么、为什么要这样写。JS 有**两种注释**：
**单行注释** `//`：
```js
// 这是一条注释，浏览器会忽略它
alert("你好！"); // 行末也可以加注释
```
**多行注释** `/* */`：
```js
/*
 * 这里可以写
 * 多行注释内容
 */
alert("你好！");
```
注释不会被浏览器执行——它们只给"人类"看，包括未来的你自己。
**快捷键：** 选中代码按 `Ctrl + /`（Mac: `Cmd + /`），编辑器自动添加或移除 `//` 注释。这个快捷键在 HTML、CSS、JS 中都通用。
:::

:::explain{title="第一行 JavaScript"}
JavaScript 写在 `<script>` 标签中。先看一个最简单的方法——`alert()`，它会弹出一个提示框：
```html
<script>
  alert("你好，音乐世界！");
</script>
```
打开 JS 选项卡，你可以看到编辑器中已经有了这段代码。预览区会在页面加载时弹出问候。
:::

:::explain{title="console.log — 开发者的耳朵"}
`console.log()` 是 JS 中最常用的调试方法。它会在浏览器的**控制台**（Console）中输出信息：
```js
console.log("这段文字会出现在控制台");
```
就像指挥家用耳朵听排练效果，开发者用 `console.log` 查看代码运行情况。
打开预览区，然后按 `F12` 打开开发者工具，切换到"Console"标签页，你就能看到输出了！
:::

:::example{title="看例子"}
下面的代码就是编辑器中你看到的。一个 `alert` 欢迎你，一个 `console.log` 输出信息：
```js
// alert()：弹出提示框，让页面和用户"说话"
alert("欢迎来到音乐编程之旅！");

// console.log()：在控制台输出信息，只有开发者能看到
console.log("页面加载完成，准备就绪！");
```
试试修改 `alert` 和 `console.log` 中的文字。
:::

:::recap
这一节你开始学习 JavaScript——让网页"活起来"的语言。`alert()` 弹出提示框跟用户对话，`console.log()` 在控制台输出信息（只有开发者能看到），你学会了按 F12 打开控制台来观察代码运行结果。HTML 决定了"有什么"，CSS 决定了"长什么样"，现在你有了第三种能力：JavaScript 决定了"能做什么"。
:::
