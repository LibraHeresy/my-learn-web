# 条件判断 — 代码的分岔路口

:::analogy
if/else 就是人生的分岔路口——如果下雨，带伞；否则，不带。代码根据条件决定走哪条路，这就是程序的判断力。
:::

:::explain{title="if 语句 — 代码的\"如果\""}
if/else 条件判断让代码在不同情况下执行不同操作——就像做饭时"如果盐放多了就加点水，否则继续炒"。比较运算符：=== 等于、!== 不等于、> 大于、< 小于、>= 大于等于、<= 小于等于。
```js
let score = 85;
if (score >= 80) {
  console.log("优秀！");
}
```
就像评委打分：分数 ≥ 80 才算优秀。
:::

:::explain{title="else 与 else if — 多分岔路"}
`else` 处理"否则"的情况，`else if` 添加更多分岔：
```js
let score = 75;
if (score >= 90) {
  console.log("金奖！🥇");
} else if (score >= 80) {
  console.log("银奖！🥈");
} else if (score >= 60) {
  console.log("铜奖🥉");
} else {
  console.log("继续努力！");
}
```
逻辑运算符：
- `&&` — 并且（两个条件都成立）
- `||` — 或者（任意一个成立）
```js
if (score >= 80 && score < 90) {
  console.log("优秀但未达金奖");
}
```
:::

:::example{title="看例子"}
下面的代码是一个设计师答题器。输入答案后点击提交，JS 判断你的答案是否正确：
```js
// 获取输入框里用户写的内容
let answer = document.querySelector("#answer").value;

// if/else：条件判断——"如果...就...否则..."
if (answer === "张三") {                              // === 比较是否相等
  display.textContent = "✓ 回答正确！";              // 条件成立走这里
} else {
  display.textContent = "✗ 再想想？提示：他是波兰人"; // 条件不成立走这里
}
```
打开 JS 选项卡，看 submit 按钮的点击事件中完整的 if/else 逻辑。
:::

::::step{purpose="`&&`（逻辑与）让你把多个条件「绑在一起」——全部满足才通过。就像「只有既是20世纪、又是德国设计师」才归入某个分类。`&&` 和 `||` 是构建复杂判断的核心工具。" expected="只有当两个条件都满足时，才执行该分支的代码。如果只满足一个，则跳过这个分支走到下一个判断——逻辑运算符就像层层安检，一道不通过就不放行。"}

::::

挑战：在已有的 if-else if-else 链中增加一个新分支，判断是否输入了「李四」。给出区别于正确答案的特殊提示，如「李四也是一位伟大的设计师，但标准答案是张三」
::::

:::recap
这一节你学会了让代码做判断——`if` 表示"如果条件成立就执行"，`else` 表示"否则执行另一段"，`else if` 表示"再试一个条件"。用 `&&`（并且）和 `||`（或者）可以把多个条件组合在一起。就像考试评分——根据分数高低给出不同的等级。现在你的代码不再是死板地从上跑到下，而是会看情况做不同的事了。
:::
