# 综合项目 — 交互式名片生成器

:::analogy
这节综合课把前11节课的知识融合在一起——用 HTML 搭骨架、CSS 做装修、JS 实现互动。就像终于盖好一栋完整的房子：有结构、有装修、有水电。
:::


:::prerequisite
**本节你需要知道这些词：**

- **变量与类型**：用 `let`/`const` 存储数据，理解 string、number、boolean
- **函数**：定义和调用函数，理解参数和返回值
- **事件**：用 `addEventListener` 监听点击、输入等用户操作
- **条件判断**：用 `if`/`else` 做分支逻辑
- **数组**：创建数组、遍历元素、使用数组方法
- **循环**：用 `for` 重复执行代码
- **DOM 操作**：选取元素、修改内容和样式、动态创建元素
- **对象**：创建和访问对象的属性和方法
- **定时器**：用 `setInterval`/`setTimeout` 控制代码执行时机
:::

:::task{title="逐步构建 ✨"}
::::step{purpose="读懂现有代码是编程中的必修课——就像拿到一份设计图先理解主题、布局和标注。理解了数据流向（composers → filter → showGallery → innerHTML），你才能胸有成竹地添加新功能。" expected="你能用自己的话描述：「composers 数组存了什么数据」「showGallery 函数做了什么」「按下一个筛选按钮后数据经历了怎样的流程」。"}
阅读 JS 标签页中的代码，理解三个核心部分：`composers` 对象数组的数据结构、`showGallery(list)` 函数如何用 `forEach` 渲染卡片、`setActive(btn)` 如何切换按钮的高亮状态
::::

::::step{purpose="综合运用对象属性访问（`c.period`）+ 数组 filter 方法 + DOM 事件绑定。三个筛选按钮共享同一个模式（获取数据 → 筛选 → 渲染），这就是可复用的设计模式。" expected="点击不同按钮，画廊中的卡片随筛选条件变化。点击「全部」显示所有人，点击「浪漫主义」只显示肖邦和舒曼，点击「古典主义」只显示莫扎特和贝多芬。"}
完成筛选功能：`全部`按钮显示所有作曲家，`浪漫主义`按钮用 `.filter()` 筛选 `period === "浪漫主义"` 的作曲家。挑战：新增一个「印象派」按钮，筛选印象派时期的作曲家
::::

::::step{purpose="动态数据操作是前端应用的核心——数据变化后重新渲染，用户立刻看到结果。这和之前学过的数组 push + DOM 刷新是一个模式，只是数据更复杂（对象而非字符串）。" expected="点击「随机添加」按钮，画廊中多出一位新作曲家（柴可夫斯基、海顿或拉威尔）。每次点击增加一位，直到预设数据池用完。筛选功能对新添加的数据同样有效。"}
完善「随机添加」按钮的功能：点击按钮时，从预设的 `pool` 数组中取出下一位作曲家对象，用 `.push()` 添加到 `composers` 数组，然后调用 `showGallery(composers)` 刷新画廊
::::

::::
