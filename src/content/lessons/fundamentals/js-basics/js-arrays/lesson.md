# 数组 — 存储你的项目列表

:::analogy
数组就像一张购物清单——东西按顺序排好，第一个、第二个、第三个……想加东西就追加到末尾，想查东西就问"第几个是什么"。
:::


:::prerequisite
**本节你需要知道这些词：**

- **变量**：用 `let`/`const` 声明和存储数据
- **数据类型**：了解 string、number 等基础类型
:::

:::explain{title="创建和访问数组"}
数组用 `[]` 创建，每个值用逗号分隔：
```js
let composers = ["", "", "春天", "张三"];
```
- `composers[0]` — 第 1 项（""），索引从 0 开始
- `composers[2]` — 第 3 项（"春天"）
- `composers.length` — 数组长度（4）
就像楼层编号从 0 开始——这是编程的习惯。
:::

:::explain{title="数组常用方法"}
数组有一套强大的操作方法：
- `.push("德彪西")` — 在末尾添加一项
- `.pop()` — 移除末尾一项
- `.join("、")` — 用指定分隔符拼接为字符串
```js
let composers = ["", ""];
composers.push("张三");  // 末尾追加
// composers 现在是 ["", "", "张三"]
let text = composers.join(" | ");
// text 是 " |  | 张三"
```
.join()` 特别实用——把一个数组变成页面上的文字！
:::

:::example{title="看例子"}
下面的代码维护了一个设计师数组，用 `.push()` 添加新名字，用 `.join()` 显示到页面上：
```js
let composers = ["", "", "春天"];
// 显示列表
let text = composers.join(" · ");
display.textContent = text;
// 添加新设计师
composers.push("张三");
text = composers.join(" · ");
display.textContent = text;
```
打开 JS 选项卡，输入一个名字点击添加，看列表实时更新。
:::

:::recap
这一节你学会了用数组存储一组数据——用 `[]` 创建，每个值用逗号分开。用 `[0]` 取第一个（索引从 0 开始），用 `.push()` 在末尾添加新项，用 `.join()` 把整个数组拼成一段文字。就像一张购物清单——可以把东西放进去、加新东西、一次性全部显示出来。现在你再也不需要一个一个手动管理同类的数据了。
:::
