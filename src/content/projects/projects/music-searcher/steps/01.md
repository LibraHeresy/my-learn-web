# 步骤 1：前置准备 —— 开始之前你需要掌握什么

## 本步骤目标

确认你已经掌握了构建"音乐搜索器"所需要的全部前置知识，并理解这个项目在整个学习路径中的位置。

## 为什么这一步很重要

在实际工作中，接到一个新需求时，你首先需要判断自己是否具备完成它的能力——哪些技术你已经会了，哪些需要现学。这一步就是在训练你这个判断能力。跳过前置检查直接写代码，就像没看地图就出发，大概率会在半路卡住。

## 你需要已经掌握的知识

在开始本项目之前，请逐条确认你已经理解以下内容：

### JavaScript 异步基础（必须）

| 知识点 | 自检问题 | 如果不确定，先去学 |
|--------|---------|-------------------|
| Promise | 你能解释 `new Promise((resolve, reject) => {...})` 的三个状态吗？ | 《Promise》章节 |
| async/await | 为什么 `await` 只能在 `async` 函数里用？`await` 后面的代码什么时候执行？ | 《async/await》章节 |
| try/catch | 你能用 try/catch 捕获 async 函数里的错误，而不是让 Promise 进入 unhandled rejection 吗？ | 《async/await》章节中的错误处理部分 |
| 事件循环 | 解释这段代码的输出顺序：`console.log(1); setTimeout(() => console.log(2), 0); Promise.resolve().then(() => console.log(3)); console.log(4);` | 《事件循环》章节 |

### 网络请求基础（必须）

| 知识点 | 自检问题 | 如果不确定，先去学 |
|--------|---------|-------------------|
| fetch API | `fetch(url)` 返回的是什么？为什么需要两次 `await`（一次 `await fetch()`，一次 `await response.json()`）？ | 《fetch 网络请求》章节 |
| HTTP 状态码 | `response.ok` 为 true 表示什么？200 和 404 的区别？ | 《fetch 网络请求》章节 |

| URL 编码 | 为什么 URL 中的中文会变成 `%E8%B4%9D...` 这样的字符串？ | 《fetch 网络请求》章节或查 MDN 的 `encodeURIComponent` |

### DOM 操作基础（必须）

## 这个项目在整个学习路径中的位置

```
你在这里：异步篇 --> 音乐搜索器（本项目）--> 音乐收藏库 Vue 版（下一站）
```

- **之前**：你在异步篇中学了 Promise、async/await、fetch、防抖——这些是零散的"招式"。
- **现在**：音乐搜索器是把这些招式组合成一套完整的"套路"——你会第一次从零搭建一个和真实 API 交互的应用。
- **之后**：音乐收藏库 Vue 版会用 Vue 框架重构同样的功能——让你对比原生 JS 和框架的思维差异。

## 这个项目能证明什么

完成音乐搜索器后，你可以自信地说：

1. **我能和真实 API 交互** —— 不只是 console.log 数据，而是把 API 返回的数据渲染成用户可用的界面
2. **我能处理异步的各种边界情况** —— 加载中、空结果、网络错误，每种情况都有对应的 UI 反馈
3. **我能优化请求频率** —— 用防抖避免无效请求，这是真实产品中的必备技能
4. **我能独立完成一个完整的功能闭环** —— 从 API 调研、到代码实现、到状态管理、到错误处理

## 项目文件准备

在正式开始之前，请创建项目目录和基础文件：

```
music-searcher/
  index.html      -- 页面结构
  style.css       -- 样式（可选，可以直接写在 HTML 的 <style> 里）
  app.js          -- 核心 JS 逻辑（用 <script src="app.js"> 引入）
```

> **提示**：本项目不需要构建工具。用最简单的 HTML + CSS + JS 三件套即可。你甚至可以把所有代码写在一个 HTML 文件里——用 `<script>` 标签写在页面底部。

## 常见疑问

**Q: 我能不能跳过防抖，直接用按钮搜索？**
A: 可以。步骤 3 就是按钮搜索的基础版。步骤 4 再做防抖改造。建议按顺序来，先跑通基础流程，再加优化。

**Q: 异步篇我学完了但还是不太会用 async/await，怎么办？**
A: 没关系，这个项目就是让你在实际场景中反复使用 async/await。跟着代码写，卡住了就回去看对应章节，然后用项目里的场景重新理解——"学"和"做"交替进行效果最好。

**Q: 我需要会 Node.js 或 Webpack 吗？**
A: 不需要。本项目只需要浏览器和文本编辑器。所有代码在浏览器中直接运行。
