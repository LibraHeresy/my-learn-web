对照一份完整的验收清单，逐项确认你的音乐搜索器功能正常、边界情况处理到位。然后明确下一步的学习方向。

## 为什么这一步很重要

在实际工作中，功能开发完成后的验收测试（QA）是发布前的最后一道防线。一个好的开发者会在交给 QA 之前自己先跑一遍完整测试——这叫"自测"。这一步就是在训练你的自测能力和"测试思维"——把自己当成用户，去发现用正常操作发现不了的问题。

## 验收时的调试技巧

**Network 面板是你的好朋友：**

1. 打开 DevTools（F12）-> Network 标签
2. 勾选 "Disable cache"（禁用缓存，确保每次请求都是真实的）
3. 搜索后观察：
   - 出现了几个 `search` 请求？（防抖是否生效）
   - 请求的 URL 中 `term=` 参数是否正确编码？
   - 响应状态码是 200 吗？
   - 点开响应，`resultCount` 和页面展示的数量一致吗？

**模拟慢网络测试竞态条件：**

在 Network 面板中找到 "No throttling" 下拉菜单，选择 "Slow 3G"。这样每个请求都需要好几秒才能返回——给你足够的时间在请求返回前输入新的关键词，验证竞态条件处理是否正确。

**模拟离线测试错误状态：**

在 Network 面板中勾选 "Offline"。此时所有网络请求都会失败，验证你的 ERROR 状态是否正常展示。

## 常见问题排查

| 症状 | 最先检查什么 | 常见原因 |
|------|-------------|---------|
| 搜索没反应 | 控制台（Console）有没有报错？ | JS 语法错误、元素 ID 写错、DOM 还没加载完 |
| 不显示封面图 | Network 面板中图片请求的状态 | artworkUrl100 为空字符串；跨域问题 |
| 防抖没生效 | Network 面板中 search 请求的数量 | 确认绑定的是 `debouncedSearch` 而不是 `doSearch` |
| 旧结果覆盖新结果 | 慢网速下逐字输入测试 | 竞态条件检查代码没写或者写错位置 |
| 加载动画一直转 | Network 面板中请求是否 pending | Promise 没有 resolve；或者请求发出去了但没回来（检查是否是 Offline 模式） |

## 如果卡住了怎么办

按以下顺序排查（从最简单到最复杂）：

1. **检查控制台错误**：Console 中的红色报错信息是最直接的问题线索
2. **检查 Network 请求**：看请求是否发出、状态码是什么、响应内容是什么
3. **回到前面步骤，逐段验证**：
   - 步骤 2：在浏览器地址栏直接访问 API URL，确认 API 可用
   - 步骤 3：确认按钮搜索的基本流程能跑通
   - 步骤 4：确认防抖函数本身是否正确（输出 console.log 验证）
   - 步骤 5：确认状态切换逻辑（在每个 `currentStatus =` 后面加 console.log 看状态变化）
4. **最小化复现**：把代码删到最少能跑的程度，然后逐步加回来，找到出问题的那一步
5. **对比参考代码**：如果项目提供了参考实现，把你的代码和参考代码做 diff 比较

## 下一步：项目完成后做什么

### 路线 A：继续原生 JavaScript 路线 -> `music-collection-v1`

如果你想继续巩固原生 JS 能力：
- 下一个项目会扩展为音乐收藏库：搜索结果可以收藏、分类、本地存储
- 涉及 localStorage、更复杂的状态管理、数组操作（增删改查）

### 路线 B：迁移到 Vue 框架 -> `music-collection-v2`

如果你想开始学框架（推荐！）：
- 用 Vue 3 重构音乐搜索器
- 你会对比发现：
  - `ref()` 替代了手动 DOM 选择
  - `v-for` 替代了 `map().join()`
  - `watch` 替代了手动 `input` 事件 + 防抖
  - `v-if/v-else` 替代了 `switch` 状态判断
  - `onMounted` 替代了页面初始化逻辑
- 核心的异步思维（fetch、async/await、Promise）完全不变——你已经在原生 JS 中搞懂了，迁移到框架只是换了一套表达方式

### 路线 C：自己玩（探索式学习）

在你现在的代码基础上，自己尝试：
- 加一个"点击封面播放 30 秒试听"的功能（用 `previewUrl` 字段 + `<audio>` 标签）
- 加一个"搜索历史"列表（localStorage）
- 把页面改成两栏布局：左边是搜索结果列表，右边是当前选中歌曲的详情
- 加一个"随机发现"按钮：随机搜索一个音乐类型的关键词（"classical"、"jazz"、"rock"）
