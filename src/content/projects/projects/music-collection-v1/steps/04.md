# 步骤 3：CSS 样式——让页面"穿正装"

---

## 这一步在做什么

用 CSS 为筛选按钮、卡片（虽然现在还没有卡片内容，但先写好样式）、表单和整体布局添加美观的样式。这一步会大量使用你学过的 CSS 属性，并引入 CSS Grid 做卡片网格布局。

---

## 为什么这一步很重要

CSS 是用户对页面的**第一印象**。一个功能完整但样式丑陋的应用，用户会用得很勉强；一个精心设计过的应用，用户会愿意多试几次。

在实际工作中，"把设计稿翻译成 CSS 代码"是前端开发者的核心日常工作之一。这一步练的就是这种翻译能力：看到设计效果，在脑子里拆分成不同区域，为每个区域写对应的 CSS 规则。

另外，这一步我们会学习 **CSS Grid**——这是现代网页布局中最强大的工具之一。理解了 Grid，你就能轻松做出任何卡片排列效果。

---

## 具体操作

### 1. 打开 `style.css`

在 VS Code 中打开你在步骤 1 中创建的 `style.css`。这个文件中已经有基础重置样式和标题样式。我们将在它们下面添加更多样式。

### 2. 添加 CSS 变量（颜色系统）

在文件顶部、基础重置样式之后，添加 CSS 变量。这让我们后面修改颜色时只需要改一个地方：

```css
/* ====== 颜色变量（方便统一调整配色） ====== */
:root {
  --color-bg:       #F5F0EB;    /* 页面背景色 */
  --color-card:     #FFFFFF;    /* 卡片背景色 */
  --color-primary:  #8B7355;    /* 主色——用于按钮、强调 */
  --color-primary-hover: #6B5640;   /* 主色深色版——鼠标悬停 */
  --color-text:     #3D3226;    /* 正文文字色 */
  --color-text-light: #7A6E64;  /* 次要文字色 */
  --color-border:   #E0D5C7;    /* 边框色 */
  --color-accent:   #D4A574;    /* 强调色——用于标签、徽章 */
  --shadow-card:    0 2px 12px rgba(0, 0, 0, 0.06);   /* 卡片阴影 */
  --shadow-card-hover: 0 4px 20px rgba(0, 0, 0, 0.10); /* 悬停阴影 */
  --radius:         12px;       /* 统一圆角值 */
}
```

> **CSS 变量是什么？** `:root` 中定义的变量（以 `--` 开头）可以在任何 CSS 规则中用 `var(--变量名)` 来引用。这样当你想要统一换配色时，只需要改这一处的值，不用在整个 CSS 文件中逐个查找替换。

### 3. 筛选按钮样式

在 CSS 变量定义之后添加：

```css
/* ====== 筛选按钮区 ====== */
.filter-section {
  display: flex;               /* 弹性布局——按钮排成一行 */
  justify-content: center;     /* 水平居中 */
  gap: 10px;                   /* 按钮之间的间距 */
  margin-bottom: 30px;         /* 和下方卡片区域的距离 */
  flex-wrap: wrap;             /* 如果一行放不下，自动换行 */
}

.filter-btn {
  padding: 8px 20px;           /* 按钮内边距 */
  border: 2px solid var(--color-border);
  background: var(--color-card);
  color: var(--color-text);
  border-radius: 24px;         /* 大圆角——做成"胶囊"形状 */
  font-size: 14px;
  cursor: pointer;             /* 鼠标悬停时变成手型 */
  transition: all 0.2s ease;   /* 过渡动画——颜色变化更平滑 */
}

.filter-btn:hover {
  border-color: var(--color-primary);
  color: var(--color-primary);
}

/* 当前激活的按钮样式 */
.filter-btn.active {
  background: var(--color-primary);
  color: #FFFFFF;
  border-color: var(--color-primary);
}
```

**效果说明：**
- 默认状态下，按钮是白色背景、浅棕边框
- 鼠标悬停时，边框和文字变成主色
- `.active` 类对应的按钮（默认是"全部"按钮）会有实心棕色背景 + 白色文字——视觉上区分"当前选中"

### 4. 卡片网格布局

```css
/* ====== 卡片网格 ====== */
.card-grid {
  display: grid;
  /* Grid 布局的核心：auto-fill + minmax 实现响应式网格 */
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;                   /* 卡片之间的间距 */
  margin-bottom: 40px;
}
```

**Grid 核心语法解释：**

`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));`

这是 CSS Grid 最强大的一行。把它拆开理解：

| 部分 | 含义 |
|------|------|
| `repeat()` | 重复生成列 |
| `auto-fill` | 自动计算能放多少列——根据容器宽度和每列最小宽度计算 |
| `minmax(280px, 1fr)` | 每列最小 280px，最大等分剩余空间 |

效果：屏幕宽时自动多列，屏幕窄时自动少列——不用写任何媒体查询就能实现响应式布局。

### 5. 单张卡片样式

```css
/* ====== 单张音乐卡片 ====== */
.music-card {
  background: var(--color-card);
  border-radius: var(--radius);
  box-shadow: var(--shadow-card);
  overflow: hidden;            /* 让圆角对图片也生效 */
  transition: transform 0.2s ease, box-shadow 0.2s ease;
  /* 卡片内部使用 flex 纵向排列 */
  display: flex;
  flex-direction: column;
}

.music-card:hover {
  transform: translateY(-4px); /* 鼠标悬停——卡片向上浮4px */
  box-shadow: var(--shadow-card-hover);
}

/* ====== 卡片封面图片 ====== */
.card-cover {
  width: 100%;                 /* 宽度撑满卡片 */
  height: 180px;               /* 固定高度 */
  object-fit: cover;           /* 图片裁剪填充，不变形 */
  background: #E8D5C4;         /* 图片加载失败时的备用背景色 */
}

/* ====== 卡片信息区 ====== */
.card-info {
  padding: 16px;
  flex: 1;                     /* 自动撑满剩余空间 */
  display: flex;
  flex-direction: column;
  gap: 6px;                    /* 子元素之间间距（Flex 中的 gap） */
}

.card-info h3 {
  font-size: 18px;
  color: var(--color-text);
  margin: 0;
}

.card-info .composer {
  font-size: 14px;
  color: var(--color-text-light);
  margin: 0;
}

.card-info .tag {
  display: inline-block;       /* 像按钮一样，但不独占一行 */
  align-self: flex-start;      /* 不让它被拉伸 */
  padding: 4px 12px;
  background: #FBF7F0;
  color: var(--color-accent);
  border-radius: 12px;         /* 小胶囊形状 */
  font-size: 12px;
  margin-top: 4px;
}
```

## 这一步的常见错误

### 错误 1：Grid 没有响应——卡片始终只有一列
**原因**：可能把 `auto-fill` 写成了 `auto-fit`（虽然两者在不同场景下各有用途），或者容器宽度不够放两列。
**解决**：确认写的是 `repeat(auto-fill, minmax(280px, 1fr))`。如果屏幕宽度小于 280px + 间距，确实只能显示一列——这是正常的。

### 错误 2：鼠标悬停时卡片向上浮动，但卡片下面的元素也会跟着动
**原因**：`translateY(-4px)` 会改变元素位置但不改变布局流，但如果用了 `margin-top: -4px` 就会影响布局。
**解决**：确认用的是 `transform: translateY(-4px)` 而不是 `margin-top`。`transform` 不会影响其他元素的位置。

### 错误 3：CSS 变量不生效
**原因**：可能不小心把变量定义在了某个具体的选择器下面（如 `body {}`），而不是 `:root {}` 中。
**解决**：CSS 变量的作用域遵循 CSS 层叠规则。定义在 `:root` 中的变量是全局的，可以在任何地方使用。定义在某个选择器中的变量只能在该选择器及其子元素中使用。

### 错误 4：输入框聚焦时边框不变化
**原因**：浏览器的默认 `outline` 可能覆盖了你的 `border-color` 变化。
**解决**：确认写了 `outline: none` 在 `:focus` 状态中。
