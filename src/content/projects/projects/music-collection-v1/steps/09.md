# 步骤 8：数据持久化与最终完善

---

## 这一步在做什么

让数据"活过"页面刷新——用 `localStorage` 保存数据，让用户下次打开页面时，之前添加和删除的收藏都还在。然后做最终的代码审查和改进。

---

## 为什么这一步很重要

现在你的应用存在一个大问题：**刷新页面后，所有修改都丢了**。用户花时间添加了几首曲目、删掉了一些不想要的——一刷新，又回到了最初的 6 首预设数据。这显然不是一个"能用的"应用。

`localStorage` 是浏览器提供的一个简单存储机制。它可以把数据以字符串的形式保存在用户的浏览器中。即使关闭浏览器、重启电脑，数据依然在。

这一步还教你：**如何在不增加太多复杂度的情况下让应用变得更完整**。很多初学者会在项目快完成时陷入"再加一个功能...再加一个..."的循环。知道什么时候停下来，确保现有功能是稳定可用的，也是重要的能力。

## 具体操作

### 1. 打开 `script.js`

在 VS Code 中打开 `script.js`。

### 2. 理解 localStorage 的基本用法

在开始写代码之前，先在浏览器控制台（F12 → Console）中手动试一下 localStorage：

```javascript
// 存储数据（只能存字符串）
localStorage.setItem("test", "Hello World");

// 读取数据
localStorage.getItem("test");    // 返回 "Hello World"

// 删除数据
localStorage.removeItem("test");

// 清空所有数据
localStorage.clear();
```

对于我们的项目，需要存储的是**一个包含多个对象的数组**。但 localStorage 只能存字符串，所以我们需要用 `JSON.stringify()`（对象转字符串）和 `JSON.parse()`（字符串转对象）。

### 3. 写保存函数

在 `script.js` 的合适位置（建议放在工具函数区，靠近 `getNextId` 的地方），添加：

```javascript
// ====== localStorage：保存数据 ======
function saveToStorage() {
  // JSON.stringify 把数组/对象转换成字符串
  const jsonString = JSON.stringify(musicData);
  localStorage.setItem("musicCollection", jsonString);
}
```

### 4. 写读取函数

```javascript
// ====== localStorage：读取数据 ======
function loadFromStorage() {
  const jsonString = localStorage.getItem("musicCollection");

  // 如果 localStorage 中没有数据（第一次打开页面），返回 null
  if (jsonString === null) {
    return null;
  }

  // JSON.parse 把字符串还原成数组/对象
  return JSON.parse(jsonString);
}
```

### 5. 在"添加"和"删除"操作后调用保存

找到 `addForm.addEventListener` 的处理函数，在 `musicData.push(newItem)` 之后、`renderFilteredCards()` 之前添加：

```javascript
// ... musicData.push(newItem) 之后 ...
saveToStorage();                // ← 新增：持久化保存
renderFilteredCards();
```

同样，找到 `deleteMusic` 函数，在 `musicData.splice(index, 1)` 之后、`renderFilteredCards()` 之前添加：

```javascript
// ... musicData.splice(index, 1) 之后 ...
saveToStorage();                // ← 新增：持久化保存
renderFilteredCards();
```

### 6. 修改页面初始化逻辑

找到 `script.js` 末尾的初始化代码：

```javascript
// ====== 旧的初始化代码（替换掉它） ======
// renderCards(musicData);
// setupFilters();

// ====== 新的初始化代码 ======
function init() {
  // 步骤1：尝试从 localStorage 加载数据
  const storedData = loadFromStorage();

  if (storedData !== null) {
    // 如果 localStorage 中有数据，用它覆盖默认数据
    // 注意：这里不能写 musicData = storedData，因为 musicData 是 const
    // 我们需要把 storedData 的元素一个一个转移到 musicData 中
    musicData.length = 0;                   // 清空数组
    storedData.forEach(function(item) {
      musicData.push(item);                 // 把存储的数据放进去
    });
    console.log(`📂 从本地存储加载了 ${musicData.length} 首曲目`);
  } else {
    // 如果 localStorage 中没有数据，保存默认数据
    saveToStorage();
    console.log("📦 首次使用，已保存默认曲目");
  }

  // 步骤2：渲染页面
  renderCards(musicData);

  // 步骤3：初始化筛选功能
  setupFilters();
}

// 启动
init();
```

**关键解释：**

为什么用 `musicData.length = 0` + `forEach` + `push` 而不是直接 `musicData = storedData`？

因为 `musicData` 是用 `const` 声明的。`const` 不能重新赋值，但可以修改数组的内容（添加、删除元素）。所以我们需要清空原数组，然后把存储的数据逐个放进去。这是一个常见的 JavaScript 技巧。

## 你学到了什么

### 1. 数据驱动视图
你不再在 HTML 中手写每一张卡片。数据存在 JS 数组中，页面是数据的"投影"。改数据 → 重渲染 → 页面更新。这个模式是 React、Vue 等现代框架的核心理念。

### 2. 事件驱动的交互
用户的每个操作（点击按钮、提交表单）都会触发一个事件。你的代码监听这些事件，做出响应。这就是"交互"的本质。

### 3. CRUD 的完整实现
你的应用实现了：
- **C**reate（创建）—— 添加新曲目
- **R**ead（读取）—— 从 localStorage 加载并渲染
- **D**elete（删除）—— 移除曲目
- 虽然没有 Update（编辑），但你已经理解了数据操作的核心流程

### 4. 数据持久化
`localStorage` 让数据"活过"页面刷新。虽然它只是一个简单的键值存储，但它代表了一个重要的概念：**前端也可以有"存储"能力**。

### 5. 代码组织
HTML 管结构、CSS 管样式、JS 管逻辑——三权分立。当你需要改颜色时，你知道去 `style.css` 找。当你需要改添加逻辑时，你知道去 `script.js` 找。
