# 项目介绍：音乐收藏库 · 纯手工版

欢迎来到你的**第一个完整的 Web 应用程序**！如果说上一个项目（音乐家名片页）是一张静态海报，这个项目就是一个真正"能动"的工具——你可以添加、筛选、删除音乐收藏，数据会保存在浏览器里，刷新页面也不会丢失。

---

## 你将构建什么

一个**音乐收藏管理器**，功能包括：

- 以卡片网格形式**展示**多首音乐收藏（曲名、作曲家、封面图片、风格标签）
- 通过**表单输入**添加新的收藏曲目
- 点击**删除按钮**移除不需要的收藏
- 使用**筛选按钮**按音乐风格分类查看（巴洛克、古典、浪漫等）
- 数据保存在 **localStorage** 中，刷新页面或关闭浏览器后数据依然存在

这已经是一个具备完整"增删查"（Create、Read、Delete + Filter）功能的小型应用了。

---

## 为什么这个项目很重要

这是你第一次把 **HTML、CSS、JavaScript 三者缝合在一起**工作：

| 技术 | 在这个项目中的角色 |
|------|-------------------|
| **HTML** | 提供页面骨架：卡片容器、表单、筛选按钮 |
| **CSS** | 控制视觉呈现：卡片样式、网格布局、颜色体系 |
| **JavaScript** | 让页面"活起来"：渲染卡片、响应用户操作、管理数据 |

这三者的协作正是**前端开发的全部本质**。之后的任何项目——无论用 React、Vue 还是其他框架——本质上都是在做同样的事：用 HTML 定义结构，用 CSS 定义样式，用 JS 处理逻辑。你在这个项目中用手工方式理解了核心原理，后面学框架时才知道框架在帮你做什么。

## 建议的前置学习

在开始之前，建议你已完成以下课程或具备等同能力：

1. **《认识 HTML》**——能熟练使用 `div`、`h2`、`p`、`img`、`span`、`form`、`input`、`button` 等标签
2. **《CSS 入门》+《Flexbox 入门》**——理解 CSS 选择器、盒模型、Grid 或 Flex 布局
3. **《认识 JavaScript》**——了解变量、数组、对象、函数
4. **《点击事件》**——知道 `addEventListener` 的基本用法
5. **DOM 操作基础**——了解 `document.querySelector`、`document.createElement`、`appendChild`
6. **《综合项目》**（可选但推荐）——做过完整的课程练习会让你更有信心

> 如果你还没完全掌握以上内容，没关系——每个步骤会告诉你"这里需要用到之前学过的哪个知识点"。边做边查、边做边学是完全正常的。

## 三级完成线

**说明**：下面的完成线都对应本项目的实际步骤：卡片渲染在步骤 4，添加功能在步骤 5，删除功能在步骤 6，筛选功能在步骤 7，数据持久化在步骤 8（见上方"项目步骤总览"）。删除按钮和 localStorage 并不是额外承诺的功能，它们就在标准流程里。

### 第一级：最低完成线（必须达到）
- 页面上有**至少 4 张预设的音乐收藏卡片**，由 JavaScript 动态渲染（步骤 4）
- 有**筛选按钮**，点击后能按风格过滤卡片（步骤 7）
- 有**添加表单**，填写后能将新卡片添加到网格中（步骤 5）
- 所有交互功能都能正常工作

### 第二级：标准版（推荐目标）
- 满足最低完成线的所有要求
- 每张卡片有**删除按钮**，点击后卡片从页面和数据中移除（步骤 6）
- **localStorage 数据持久化**：关闭浏览器再打开，之前添加的收藏还在（步骤 8）
- 表单有**输入验证**：空字段不允许提交（步骤 5）
- 样式统一、布局整齐（步骤 3）

### 第三级：挑战版（学有余力）
- 满足标准版的所有要求
- 添加**搜索框**：可以按曲名或作曲家搜索
- 添加**编辑功能**：可以修改已有收藏的信息
- 卡片有**过渡动画**（添加/删除时平滑过渡）
- 做了基本的**响应式适配**——手机和桌面都有良好体验

## 项目步骤总览

| 步骤 | 内容 | 涉及核心技术 |
|------|------|-------------|
| 步骤 1 | 项目搭建——创建文件、搭建骨架 | 文件组织、HTML5 模板 |
| 步骤 2 | HTML 结构——写出页面所有元素 | 语义化标签、表单元素 |
| 步骤 3 | CSS 样式——卡片、网格、配色 | Grid 布局、盒模型、变量 |
| 步骤 4 | JS 数据与渲染——数组驱动页面 | 数组、对象、DOM 创建 |
| 步骤 5 | 添加功能——表单收集数据 | 事件监听、表单处理 |
| 步骤 6 | 删除功能——移除不需要的收藏 | 数组删除、DOM 移除 |
| 步骤 7 | 筛选功能——按风格分类查看 | 数组过滤、显示/隐藏 |
| 步骤 8 | 数据持久化与最终完善 | localStorage、代码整理 |

## 开始前的准备

你需要：

1. **VS Code 编辑器**（或任何你习惯的代码编辑器）
2. **Chrome / Edge 浏览器**（需要用到开发者工具 F12）
3. 在你的电脑上创建一个**空白文件夹**，命名为 `music-collection`
4. 准备几张你喜欢的音乐专辑或曲目的封面图片（可选——可以用占位图）
