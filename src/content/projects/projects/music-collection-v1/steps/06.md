# 步骤 5：添加功能——让用户创建新收藏

---

## 这一步在做什么

让页面上的表单"真的能用"——用户填写曲名、作曲家、图片链接、风格后，点击"添加到收藏"按钮，一张新卡片就会出现在网格中。

---

## 为什么这一步很重要

表单是 Web 应用中最常见的交互模式。几乎每个网站都有表单——登录、注册、搜索、评论、设置。表单的核心流程是固定的：

1. 用户在输入框中填写信息
2. 用户触发提交（点击按钮或按回车）
3. JavaScript 读取输入框的值
4. 用这些值做点什么（发送给服务器、添加到列表、更新页面...）
5. 清空表单，准备下一次输入

掌握这个流程，你就掌握了 Web 交互的"半壁江山"。

## 具体操作

### 1. 打开 `script.js`

在 VS Code 中打开 `script.js`。我们在上面已经有了数据数组、`createCard` 函数和 `renderCards` 函数。现在添加表单处理逻辑。

### 2. 获取表单元素

在 `renderCards(musicData)` 这行之前，添加以下代码来获取表单相关的 DOM 元素：

```javascript
// ====== 获取表单相关元素 ======
const addForm = document.getElementById("addForm");
const titleInput = document.getElementById("title");
const composerInput = document.getElementById("composer");
const coverInput = document.getElementById("cover");
const periodSelect = document.getElementById("period");
```

### 3. 生成新 ID 的工具函数

每次添加新卡片时，我们需要一个不重复的 ID。在表单获取代码之后添加：

```javascript
// ====== 工具函数：生成新的唯一 ID ======
function getNextId() {
  // 如果数组为空，返回 1
  if (musicData.length === 0) {
    return 1;
  }
  // 找到数组中最大的 id，然后 +1
  const maxId = Math.max(...musicData.map(item => item.id));
  return maxId + 1;
}
```

**代码解释：**

| 表达式 | 含义 |
|--------|------|
| `musicData.map(item => item.id)` | 把 `musicData` 数组中每个对象的 `id` 取出来，组成一个新数组。例如 `[1, 2, 3, 4, 5, 6]` |
| `Math.max(...)` | 找到数组中的最大值。`...` 是展开运算符——把数组展开成一串独立的参数传给 `Math.max` |
| `Math.max(...[1,2,3])` | 等价于 `Math.max(1, 2, 3)` → 返回 `3` |

### 4. 表单提交事件处理

这是核心逻辑。在 `getNextId` 函数下面添加：

```javascript
// ====== 表单提交事件：添加新曲目 ======
addForm.addEventListener("submit", function(event) {
  // 步骤1：阻止表单的默认提交行为（默认会刷新页面）
  event.preventDefault();

  // 步骤2：读取用户输入的值
  const title = titleInput.value.trim();
  const composer = composerInput.value.trim();
  const cover = coverInput.value.trim();
  const period = periodSelect.value;

  // 步骤3：验证——曲名和作曲家不能为空
  if (title === "" || composer === "") {
    alert("请至少填写曲名和作曲家！");
    return;  // 终止函数，不继续执行
  }

  // 步骤4：构造新数据对象
  const newItem = {
    id: getNextId(),           // 自动生成不重复的 ID
    title: title,
    composer: composer,
    cover: cover || "https://picsum.photos/seed/default/400/300",
    // 如果没有填写图片链接，使用默认占位图
    period: period
  };

  // 步骤5：添加到数据数组
  musicData.push(newItem);
  // push() 是数组的方法，在数组末尾追加一个新元素

  // 步骤6：重新渲染整个卡片网格
  // 注意：这里用的是 musicData（包含所有数据），不是 [newItem]
  renderCards(musicData);

  // 步骤7：清空表单，准备下一次输入
  addForm.reset();

  // 步骤8：给用户一个反馈
  console.log(`✅ 已添加：《${title}》—— ${composer}`);
});
```

**逐行解释：**

| 代码 | 作用 |
|------|------|
| `event.preventDefault()` | 最关键的 1 行！没有它，浏览器会按照 `<form>` 的默认行为处理——刷新页面或跳转。这会丢失所有 JS 状态 |
| `.value` | 获取输入框/下拉框的当前值 |
| `.trim()` | 去掉字符串前后的空白（空格、换行等）。用户可能不小心在曲名后面打了空格 |
| `if (title === "" \|\| composer === "")` | 输入验证。空数据不应该进入数据数组 |
| `cover \|\| "..."` | 给空值一个默认值。如果 `cover` 是空字符串，就用右边的默认链接 |
| `musicData.push(newItem)` | 把新对象追加到数组末尾 |
| `renderCards(musicData)` | 重新渲染全部卡片。注意这里传的是**整个数组**，不是只传新加的那一项。`renderCards` 内部会先清空容器，所以结果是"删除所有旧卡片，重新生成所有卡片" |
| `addForm.reset()` | 清空表单所有输入字段 |

## 这一步的常见错误

### 错误 1：点击添加按钮后页面刷新了，新卡片没出现
**原因**：忘记写 `event.preventDefault()` 或者这行代码的位置不对。
**解决**：确认 `event.preventDefault()` 是 `addEventListener` 回调函数中的**第一行代码**。如果它后面还有代码报错，`preventDefault` 已经执行了——但如果回调函数本身没执行到（比如前面的代码报错了），表单仍会默认提交。

### 错误 2：添加新卡片后，旧卡片消失了
**原因**：`renderCards(dataArray)` 调用时传的是 `[newItem]` 而不是整个 `musicData`。
**解决**：`renderCards` 内部会先执行 `grid.innerHTML = ""` 清空容器，然后遍历传入的数组创建卡片。如果你传的是 `[newItem]`（只包含新加的那一项），旧数据就没了。正确答案是传 `musicData`（全部数据）。

### 错误 3：连续添加两首曲子，第二首覆盖了第一首
**原因**：没有把新数据 `push` 到数组中。
**解决**：确认有 `musicData.push(newItem)` 这行。`push` 是追加到末尾；如果你用的是赋值（如 `musicData = [newItem]`），就会覆盖整个数组。

### 错误 4：`trim()` 没有去掉所有空格
**原因**：`trim()` 只去掉字符串前后的空格，不去掉中间的空格。
**解决**：对于"去掉中间空格"的需求，可以使用 `.replace(/\s+/g, "")`。但对于这个项目，`trim()` 就足够了——我们只需要防止用户只输入空格就提交。

### 错误 5：`addForm.reset()` 没有清空表单
**原因**：可能 `addForm` 变量获取的不是 `<form>` 元素，而是其他元素。
**解决**：`reset()` 是 HTML 表单元素的原生方法。确认 `addForm` 是通过 `document.getElementById("addForm")` 获取的，且 HTML 中 `<form id="addForm">` 存在。
