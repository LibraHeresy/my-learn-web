# 步骤 2：HTML 结构——搭建页面骨架

---

## 这一步在做什么

用 HTML 写出页面的所有"占位元素"：筛选按钮区、卡片展示区、添加表单区。这一步不写样式，不写 JS，只关心"页面上有哪些东西"。

---

## 为什么这一步很重要

很多初学者会急着写 CSS 让页面变好看，或者急着写 JS 让页面动起来。但专业流程是：**先搭骨架，再穿衣服，最后教它动**。

这就像盖房子——你不会在打完地基之前就开始刷墙。HTML 就是地基和框架。如果把样式和逻辑混在一起写，你会发现很难定位问题："这个按钮为什么不显示？是 HTML 没写，还是 CSS 把它藏起来了？"

先让 HTML 干干净净地展示所有元素（哪怕很丑），然后用 CSS 美化，最后用 JS 赋予交互——这是可维护代码的基础思维。

---

## 具体操作

### 1. 打开 `index.html`

在 VS Code 中打开你的 `index.html`。我们在上一节已经写好了骨架，现在需要填充 `<main>` 标签内部的内容。

### 2. 写入筛选按钮区

在 `<main>` 标签内，首先写入筛选按钮区域。替换掉 `<!-- 筛选按钮区域 -->` 这行注释：

```html
<main>
  <!-- ====== 筛选按钮区 ====== -->
  <section class="filter-section">
    <button class="filter-btn active" data-filter="all">全部</button>
    <button class="filter-btn" data-filter="巴洛克">🎻 巴洛克</button>
    <button class="filter-btn" data-filter="古典">🎼 古典</button>
    <button class="filter-btn" data-filter="浪漫">🎹 浪漫</button>
    <button class="filter-btn" data-filter="现代">🎧 现代</button>
  </section>
</main>
```

**关键点解释：**

| 属性/内容 | 用途 |
|-----------|------|
| `class="filter-btn active"` | `filter-btn` 是所有筛选按钮的通用样式类，`active` 表示当前选中的按钮（默认"全部"被选中） |
| `data-filter="all"` | 这是**自定义数据属性**（`data-*`）。JS 会读取这个值来判断"点击了这个按钮后要筛选哪个风格"。这是 HTML 和 JS 之间传递数据的一种方式 |

### 3. 写入卡片展示区

在筛选按钮区下面，写入卡片网格容器。替换掉 `<!-- 卡片网格区域 -->` 注释：

```html
  <!-- ====== 卡片展示区 ====== -->
  <section class="card-grid" id="cardGrid">
    <!-- 卡片会由 JavaScript 动态生成并插入这里 -->
    <!-- 目前是空的——下一步 CSS 会设置网格布局，JS 会填充内容 -->
  </section>
```

**关键点解释：**

| 属性 | 用途 |
|------|------|
| `class="card-grid"` | 用于 CSS 设置网格布局 |
| `id="cardGrid"` | 用于 JS 定位这个容器——`document.getElementById('cardGrid')` 或 `document.querySelector('#cardGrid')` |

> 这里用了 `id` 而不是 `class`。因为卡片容器在页面中是**唯一的**（只有一个卡片展示区），用 `id` 更合适。而筛选按钮有多个，用 `class` 更合适。这是选择 `id` 和 `class` 的基本原则：唯一的用它，多个的用它。

### 4. 写入添加表单区

在卡片展示区下面，写入表单。替换掉 `<!-- 添加表单区域 -->` 注释：

```html
  <!-- ====== 添加新曲目表单 ====== -->
  <section class="add-section">
    <h2>添加新曲目</h2>

    <form id="addForm">
      <!-- 曲名输入框 -->
      <div class="form-group">
        <label for="title">曲名</label>
        <input type="text" id="title" placeholder="例如：四季·春" required>
      </div>

      <!-- 作曲家输入框 -->
      <div class="form-group">
        <label for="composer">作曲家</label>
        <input type="text" id="composer" placeholder="例如：安东尼奥·维瓦尔第" required>
      </div>

      <!-- 封面图片链接输入框 -->
      <div class="form-group">
        <label for="cover">封面图片链接</label>
        <input type="url" id="cover" placeholder="https://...">
      </div>

      <!-- 音乐风格选择 -->
      <div class="form-group">
        <label for="period">音乐风格</label>
        <select id="period" required>
          <option value="">请选择风格</option>
          <option value="巴洛克">巴洛克</option>
          <option value="古典">古典</option>
          <option value="浪漫">浪漫</option>
          <option value="现代">现代</option>
        </select>
      </div>

      <!-- 提交按钮 -->
      <button type="submit" id="addBtn">➕ 添加到收藏</button>
    </form>
  </section>
```

**逐行解释：**

| 元素 | 作用 |
|------|------|
| `<form id="addForm">` | 表单容器。`id` 让 JS 能找到它并监听提交事件 |
| `<label for="title">` | 标签。`for` 属性和对应 `<input>` 的 `id` 匹配——点击标签文字会自动聚焦到输入框 |
| `<input type="text">` | 文本输入框。`type="text"` 用于普通文字，`type="url"` 用于链接（浏览器会做基本的 URL 格式校验） |
| `placeholder` | 输入框内的提示文字——用户看到就知道该填什么 |
| `required` | HTML5 表单验证属性——如果用户不填就直接提交，浏览器会弹出提示 |
| `<select>` | 下拉选择框。对于"风格"这种有固定选项的字段，下拉框比文本输入框更合适——用户不会拼错，数据更干净 |
| `<button type="submit">` | 提交按钮。`type="submit"` 表示点击后会触发表单的 `submit` 事件 |

### 5. 保存并查看

按 `Ctrl+S` 保存。在浏览器中刷新页面。

## 你应该看到什么

页面现在看起来应该包含：
- 顶部标题"🎵 我的音乐收藏库"
- 一排五个按钮（全部、巴洛克、古典、浪漫、现代）
- 按钮下方有一片空白区域（卡片网格，等待 JS 填充）
- 空白区域下方是"添加新曲目"表单，包含四个输入字段和一个提交按钮

整体还很朴素——按钮是默认的灰色方形，表单字段是默认的浏览器样式，间距也不太舒服。这完全正常——下一步我们用 CSS 来美化。

## 这一步的常见错误

### 错误 1：`label` 的 `for` 和 `input` 的 `id` 不匹配
**现象**：点击 label 文字不会自动聚焦到输入框。
**原因**：`for="title"` 必须和 `id="title"` 完全一致。
**解决**：检查每个 `label` 的 `for` 属性和对应 `input`/`select` 的 `id` 属性是否一致。

### 错误 2：忘记写 `required` 属性
**现象**：用户可以不填曲名就直接提交，导致后面 JS 处理时出现空数据。
**解决**：在必须填写的字段上加上 `required` 属性。浏览器会自动拦截空提交。

### 错误 3：`option` 的 `value=""` 写成 `value="请选择风格"`
**现象**：`required` 验证会失效——"请选择风格"被当作了一个有效值。
**解决**：第一个 `<option>` 的 `value` 必须是空字符串 `""`，这样浏览器会判定"用户没有做有效选择"。

### 错误 4：`data-filter` 值和筛选逻辑不一致
**现象**：点击筛选按钮后，某些卡片应该显示却没显示。
**原因**：筛选按钮的 `data-filter` 值（如 `"巴洛克"`）必须和后面 JS 中每首曲子的风格字段值完全一致。
**解决**：统一风格标签的写法。比如都用"巴洛克"而不是有的写"巴洛克"有的写"Baroque"。
