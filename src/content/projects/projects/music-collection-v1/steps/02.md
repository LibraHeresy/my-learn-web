# 步骤 1：项目搭建

---

## 这一步在做什么

创建项目文件夹和三个核心文件（`index.html`、`style.css`、`script.js`），并在 HTML 中建立它们之间的关联。这是从"在线编辑器写代码"到"本地开发环境写代码"的第一步。

---

## 为什么这一步很重要

之前的课程你可能一直在在线编辑器（如 CodePen、课程的在线练习区）中写代码。那很方便，但**真正的开发工作是在本地进行的**。

就像一个音乐家从练习室走上舞台——工具变了（不再是课程内置的编辑器，而是 VS Code），但你的技能不变。这一步确保你的"舞台"已经搭好，灯光音响（CSS 链接、JS 链接）都接通了，后面的步骤就能专注在创作本身。

另外，把 HTML、CSS、JS 分成三个文件是**前端工程化的起点**：
- 结构（HTML）和样式（CSS）分离——改颜色不用在 HTML 里翻
- 逻辑（JS）独立——改功能不会不小心改坏样式
- 代码复用更容易——以后开新项目，CSS 和 JS 的写法可以借鉴

---

## 具体操作

### 1. 创建项目文件夹

在你的电脑上找一个合适的位置（比如桌面或文档文件夹），创建一个新文件夹，命名为：

```
music-collection
```

> 文件夹名称建议用英文和连字符，避免中文和空格——这是行业惯例，也能避免一些工具链的兼容问题。

### 2. 用 VS Code 打开项目文件夹

打开 VS Code → 点击菜单栏 `文件` → `打开文件夹`（或 `Open Folder`）→ 选择你刚创建的 `music-collection` 文件夹。

打开后，VS Code 的左侧资源管理器会显示这个文件夹（目前是空的）。这个文件夹就是你的"工作区"。

### 3. 创建三个文件

在 VS Code 左侧资源管理器中，点击"新建文件"图标（或右键空白处 → `新建文件`），依次创建以下三个文件：

```
index.html
style.css
script.js
```

创建后你的文件夹结构应该是：

```
music-collection/
├── index.html
├── style.css
└── script.js
```

### 4. 写入 HTML5 骨架

打开 `index.html`，写入以下内容。在 VS Code 中，你可以输入一个 `!`（英文感叹号）然后按 `Tab` 键，它会自动帮你补全 HTML5 骨架。然后修改成以下内容：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>🎵 音乐收藏库</title>

  <!-- 关联 CSS 文件 -->
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <!-- 页面顶部标题 -->
  <header>
    <h1>🎵 我的音乐收藏库</h1>
  </header>

  <!-- 页面主体内容——后面步骤中会填充 -->
  <main>
    <!-- 筛选按钮区域 -->
    <!-- 卡片网格区域 -->
    <!-- 添加表单区域 -->
  </main>

  <!-- 关联 JavaScript 文件 -->
  <!-- 放在 body 末尾，确保 HTML 元素先加载完再执行 JS -->
  <script src="script.js"></script>
</body>
</html>
```

**逐行解释：**

| 代码行 | 作用 |
|--------|------|
| `lang="zh-CN"` | 声明页面语言是中文，有助于浏览器和搜索引擎理解 |
| `<meta charset="UTF-8">` | 字符编码声明——让中文正常显示，不乱码 |
| `<meta name="viewport" ...>` | 移动端适配基础——让页面在手机上不缩放异常 |
| `<link rel="stylesheet" href="style.css">` | **关键行**——把 CSS 文件关联到 HTML。浏览器读到这行就会去加载 `style.css` 中的样式 |
| `<script src="script.js"></script>` | **关键行**——把 JS 文件关联到 HTML。放在 `</body>` 前面，确保页面元素已加载 |
| `<header>` / `<main>` | 语义化标签——`header` 是页头，`main` 是主体内容 |

> **为什么 `<script>` 要放在 `</body>` 前面？** 浏览器是按顺序执行代码的。如果 `<script>` 放在 `<head>` 里，JS 代码执行时页面的 HTML 元素（如按钮、卡片容器）可能还没加载出来，导致 `document.querySelector` 找不到元素而报错。放在 `</body>` 前面，保证了 JS 执行时所有 HTML 元素都已经在页面上了。

### 5. 在 CSS 文件中写入基础样式

打开 `style.css`，写入以下基础重置样式：

```css
/* ====== 基础重置 ====== */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
  background: #F5F0EB;       /* 温暖的米灰色背景 */
  color: #3D3226;            /* 深棕色文字 */
  min-height: 100vh;         /* 最小高度撑满屏幕 */
  padding: 20px;
}

/* ====== 页面标题 ====== */
header {
  text-align: center;
  margin-bottom: 30px;
}

header h1 {
  font-size: 28px;
  color: #5D4E37;
}
```

### 6. 在 JS 文件中写入一行测试代码

打开 `script.js`，写入一行代码来确认 JS 文件已经被正确关联：

```javascript
// 测试 JS 是否正确加载——打开浏览器控制台（F12）应该能看到这句
console.log("🎵 音乐收藏库 JS 已加载！");
```

### 7. 在浏览器中打开并验证

在 VS Code 中右键点击 `index.html`，选择 `Open with Live Server`（如果你安装了 Live Server 插件）。如果没有 Live Server 插件，直接在文件资源管理器中找到 `index.html` 双击用浏览器打开。

打开后：
1. 你应该看到页面顶部有"我的音乐收藏库"标题
2. 背景是温暖的米灰色
3. 按下 `F12` 打开开发者工具，切换到 Console（控制台）标签
4. 你应该看到一行绿色文字：`🎵 音乐收藏库 JS 已加载！`

---

## 你应该看到什么

- 浏览器标签页显示"🎵 音乐收藏库"
- 页面有米灰色背景，顶部居中显示标题
- 按 F12 → Console 标签，能看到测试日志
- 如果以上都正常，说明三个文件都正确关联了

## 这一步的常见错误

### 错误 1：CSS 不生效（页面没有背景色）
**原因 1**：`<link>` 标签中的 `href` 写错了。比如文件叫 `style.css` 但写成了 `styles.css`。
**解决**：确认文件名和 `href` 中的名称完全一致（包括大小写）。

**原因 2**：`<link>` 标签放在了 `<body>` 中。
**解决**：`<link>` 必须放在 `<head>` 标签内。

### 错误 2：Console 里没有日志输出
**原因 1**：`<script>` 标签的 `src` 路径写错了。
**解决**：确认 `script.js` 和 `index.html` 在同一个文件夹里。

**原因 2**：Console 标签被过滤了。在开发者工具 Console 标签中，确认左上角的"默认级别"包含了 `Verbose/Info`（或点击齿轮图标，确认没有过滤掉 `console.log`）。

### 错误 3：打开页面后 VS Code 报"Live Server 未安装"
**原因**：Live Server 是 VS Code 的一个扩展插件，需要单独安装。
**解决**：两种方式：
- **方式一（推荐）**：在 VS Code 左侧点击扩展图标（四个方块），搜索 `Live Server`，安装后重启 VS Code。
- **方式二**：直接用浏览器打开 `index.html` 文件（双击或拖拽到浏览器窗口）。这对于纯 HTML/CSS/JS 项目完全够用。

### 错误 4：中文文件名导致路径问题
如果你创建的文件名包含中文（如 `样式.css`），某些操作系统或服务器可能无法正确识别。
**解决方案**：所有项目文件使用英文命名。这是行业标准做法。
