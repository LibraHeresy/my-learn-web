# 步骤 2：CSS 基础美化

---

## 这一步在做什么

给名片穿上"正装"——用 CSS 为卡片添加配色、圆角、阴影和内边距，让它从一段普通文字变成一张真正的"名片"。

---

## 为什么这一步很重要

如果说 HTML 是房子的骨架，CSS 就是室内设计师。它控制着：

- **颜色**决定氛围（温暖的米色？冷静的深蓝？）
- **间距**决定阅读舒适度（文字贴边会让人喘不过气）
- **阴影与圆角**决定"质感"（平的 vs. 浮起来的卡片）

在实际工作中，前端开发者拿到设计稿后做的第一件事，就是把设计稿翻译成 CSS 代码。这一步就是让你体验从"设计想法"到"CSS 代码"的翻译过程。

---

## 具体操作

### 1. 在 HTML 中添加 `<style>` 标签

打开你的 `index.html`，在 `</head>` 之前（也就是 `<head>` 标签的末尾）添加 `<style>` 标签：

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>音乐家名片</title>

  <style>
    /* 所有 CSS 样式写在这里 */
  </style>
</head>
```

> 为什么不单独建一个 CSS 文件？对于单个页面的小项目，把样式写在 `<style>` 标签里是最简单的方式。后面的项目会教你把 CSS 拆到独立文件。

### 2. 书写卡片主体的样式

在 `<style>` 标签内部，写入以下代码：

```css
/* ====== 卡片主体 ====== */
.composer-card {
  /* 尺寸控制 */
  max-width: 400px;          /* 限制最大宽度，让它像一张真实名片 */
  margin: 40px auto;         /* 上下留40px空白，左右自动居中 */

  /* 内边距——让内容不要贴在卡片边缘 */
  padding: 30px 24px;        /* 上下30px，左右24px */

  /* 背景色——选择一个温暖的颜色 */
  background: #FFF8F0;       /* 淡淡的米黄色，像复古纸张 */

  /* 圆角——让四个角变成弧形 */
  border-radius: 16px;       /* 16像素的圆弧 */

  /* 阴影——让卡片有"浮起来"的立体感 */
  box-shadow: 0 4px 20px rgba(0, 0, 0, 0.10);
  /* 解释：水平偏移0，垂直偏移4px，模糊20px，黑色10%透明度 */

  /* 文字居中 */
  text-align: center;

  /* 字体 */
  font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
}
```

**逐行解释：**

| 属性 | 作用 | 如果不写会怎样 |
|------|------|----------------|
| `max-width: 400px` | 卡片不会超过 400px 宽 | 卡片会撑满整个浏览器宽度，不像名片 |
| `margin: 40px auto` | 上下留白 + 左右自动居中 | 卡片会贴在浏览器左上角 |
| `padding: 30px 24px` | 内容与卡片边缘保持距离 | 文字会贴在卡片边缘，很难看 |
| `background: #FFF8F0` | 卡片背景色 | 白色背景，没有温暖感 |
| `border-radius: 16px` | 四个角变圆 | 方角，显得生硬 |
| `box-shadow: ...` | 卡片下方加阴影 | 卡片和背景融为一体，没有层次感 |
| `text-align: center` | 文字水平居中 | 文字靠左排列 |
| `font-family` | 设置中文字体 | 使用浏览器默认字体 |

### 3. 书写图片的样式

继续在 `<style>` 标签中，卡片样式之后添加：

```css
/* ====== 音乐家照片 ====== */
.composer-photo {
  width: 180px;              /* 设置一个固定宽度 */
  height: 180px;             /* 高度和宽度一样，保证是正方形 */
  object-fit: cover;         /* 图片按比例裁剪填充，不会变形 */
  border-radius: 50%;        /* 50% = 圆形！不是圆角，是完全的圆 */
  border: 4px solid #E8D5C4; /* 加一圈浅棕色的边框 */
  margin-bottom: 16px;       /* 照片和下方名字之间的间距 */
}
```

**逐行解释：**

| 属性 | 作用 |
|------|------|
| `width: 180px; height: 180px` | 把照片限制在 180x180 的正方形区域内 |
| `object-fit: cover` | 图片可能会被裁剪，但保证填满且不变形。这是处理图片的关键属性 |
| `border-radius: 50%` | 把小正方形变成圆形。50% 的意思是圆角半径等于元素尺寸的一半 |
| `border` | 给圆形照片外面加一圈装饰边框 |
| `margin-bottom` | 照片下方留出空白，不和名字贴在一起 |

### 4. 书写简介文字的样式

```css
/* ====== 简介文字 ====== */
.composer-bio {
  color: #5D4E37;            /* 深棕色文字，比纯黑更柔和 */
  line-height: 1.8;          /* 行高1.8倍，文字之间不会太挤 */
  font-size: 15px;           /* 字号稍小一点，和标题形成对比 */
  margin: 12px 0 20px 0;     /* 上12px，左右0，下20px */
}
```

### 5. 保存并查看效果

按 `Ctrl+S` 保存文件。切换到浏览器，**刷新页面**（按 `F5` 或点击刷新按钮）。

---

## 你应该看到什么

刷新后，页面发生了显著变化：

- 卡片不再撑满整个屏幕，而是**居中显示**，宽度约 400px
- 卡片有了**温暖的米黄色背景**
- 卡片四个角变成**圆弧形**
- 卡片下方有**淡淡的阴影**，像是浮在页面上
- 贝多芬的照片变成了**圆形**，外圈有浅棕色边框
- 文字不再贴边，有了舒适的**呼吸空间**
- 所有文字**居中排列**

如果看起来不太对，回到代码中逐一检查每个属性的拼写是否正确。

## 这一步的常见错误

### 错误 1：写了样式但页面没有任何变化
**原因 1**：CSS 选择器写错了。比如 HTML 里是 `class="composer-card"`，CSS 里却写成了 `.composerCard` 或 `#composer-card`。
**解决**：点号 `.` 表示 class 选择器，井号 `#` 表示 id 选择器。确认 HTML 中的 class 名称和 CSS 选择器中的名称完全一致。

**原因 2**：`<style>` 标签放在了 `<body>` 里。
**解决**：`<style>` 应该放在 `<head>` 中。

### 错误 2：图片变形了
**原因**：没有写 `object-fit: cover`，或者 `width` 和 `height` 不相等。
**解决**：确保 `width` 和 `height` 设置成相同的值，并加上 `object-fit: cover`。

### 错误 3：阴影看不到
**原因**：`box-shadow` 的值写错了，或者背景色和阴影颜色太接近。
**解决**：检查 `box-shadow` 格式：`box-shadow: 水平偏移 垂直偏移 模糊半径 颜色;`。四个值用空格分隔，顺序不能乱。

### 错误 4：卡片没有居中
**原因**：`margin: 40px auto` 只有在元素设置了 `max-width` 或 `width` 时才生效。
**解决**：确认 `max-width` 的值已经设置。没有宽度限制的元素默认是 100% 宽的，`auto` 没有空间去居中。
