# 步骤 1：搭建 HTML 结构

---

## 这一步在做什么

用 HTML 标签写出音乐家名片的**全部内容**：姓名、简介、代表作列表和照片。这一步不看样式，只管内容——就像先搭好房子的骨架，后面再装修。

---

## 为什么这一步很重要

在真正的开发工作中，**结构永远先于样式**。如果你一上来就写 CSS，很容易陷入"边写边调"的混乱状态。先把内容用正确的 HTML 标签组织好，再统一写样式——这是专业前端工程师的工作习惯。

HTML 标签不是随便选的：`h1` 表示"这是最重要的标题"、`p` 表示"这是一个段落"、`ul` 表示"这是一个列表"。浏览器会根据这些标签理解你页面的含义，搜索引擎和屏幕阅读器也会依赖它们。

---

## 具体操作

### 1. 打开你的文件

用 VS Code 打开你在上一节创建的 `index.html` 文件。

### 2. 写入 HTML 骨架

在文件中输入以下内容（如果你用的是 VS Code，可以输入 `!` 然后按 `Tab` 键，它会自动帮你补全 HTML5 骨架）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>音乐家名片</title>
</head>
<body>

  <!-- 在这里写我们的名片内容 -->

</body>
</html>
```

**逐行解释：**

| 代码 | 作用 |
|------|------|
| `<!DOCTYPE html>` | 告诉浏览器"这是一个 HTML5 页面" |
| `<html lang="zh-CN">` | 页面根元素，`lang="zh-CN"` 表示页面内容是中文 |
| `<meta charset="UTF-8">` | 确保中文字符能正常显示 |
| `<meta name="viewport" ...>` | 让页面在手机上也能正常缩放 |
| `<title>` | 浏览器标签页上显示的文字 |
| `<body>` | 页面上所有可见内容都放在这里 |

### 3. 在 `<body>` 中写入名片内容

在 `<body>` 标签内部（替换掉 `<!-- 在这里写我们的名片内容 -->`），写入以下代码：

```html
<div class="composer-card">
  <!-- 音乐家照片 -->
  <img
    src="https://upload.wikimedia.org/wikipedia/commons/6/6f/Beethoven.jpg"
    alt="路德维希·凡·贝多芬"
    class="composer-photo"
  >

  <!-- 音乐家姓名 -->
  <h1>路德维希·凡·贝多芬</h1>

  <!-- 简介 -->
  <p class="composer-bio">
    德国作曲家、钢琴家。他是古典音乐史上最伟大的作曲家之一，
    也是古典主义与浪漫主义之间的桥梁人物。
  </p>

  <!-- 代表作品 -->
  <div class="works-section">
    <h2>代表作品</h2>
    <ul>
      <li>第五交响曲「命运」</li>
      <li>第九交响曲「合唱」</li>
      <li>第十四钢琴奏鸣曲「月光」</li>
      <li>钢琴曲「致爱丽丝」</li>
      <li>D大调小提琴协奏曲</li>
    </ul>
  </div>
</div>
```

**逐行解释：**

| 代码 | 作用 |
|------|------|
| `<div class="composer-card">` | 用一个容器把所有内容包在一起，`class` 是后面写 CSS 时用来选中它的 |
| `<img src="..." alt="...">` | 显示音乐家照片，`src` 是图片链接，`alt` 是图片无法显示时的替代文字 |
| `<h1>` | 页面最重要的标题——音乐家的名字 |
| `<p class="composer-bio">` | 一个段落，写音乐家的简介 |
| `<div class="works-section">` | 把"代表作品"这块内容单独包起来，方便后面单独美化 |
| `<h2>` | 二级标题——比 `h1` 低一级，表示"代表作品"是名字之下的子标题 |
| `<ul>` 和 `<li>` | 无序列表——每首作品是一个列表项 |

### 4. 保存并在浏览器中查看

在 VS Code 中按 `Ctrl+S` 保存文件。然后在文件资源管理器中找到你的 `index.html`，双击用浏览器打开。

---

## 你应该看到什么

浏览器中会显示：

- 一张贝多芬的照片（如果图片链接失效，会看到 `alt` 中的替代文字"路德维希·凡·贝多芬"）
- 大大的"路德维希·凡·贝多芬"标题
- 一段简介文字
- "代表作品"小标题，下面是一个带圆点的列表

此时页面看起来还很"朴素"——没有颜色、没有间距控制、没有卡片感。这是正常的！下一步我们会用 CSS 让它变漂亮。

---

## 这一步的常见错误

### 错误 1：图片不显示
**原因**：图片链接可能失效或网络不通。
**解决**：换一张图片。你可以在网上搜索"贝多芬"，右键复制图片地址，替换 `src` 的值。或者使用你自己的图片——把图片文件放在和 `index.html` 同一个文件夹里，然后 `src` 直接写文件名，如 `src="beethoven.jpg"`。

### 错误 2：中文在浏览器中显示乱码
**原因**：缺少 `<meta charset="UTF-8">` 或者它不在 `<head>` 的最前面。
**解决**：确认 `<meta charset="UTF-8">` 在 `<head>` 的第一行（`<title>` 之前）。

### 错误 3：标签没有闭合
**原因**：比如写了 `<div>` 但忘记写 `</div>`。
**解决**：在 VS Code 中，点击一个标签，它会自动高亮对应的闭合标签。养成每写一个开标签就立刻写闭标签的习惯。

### 错误 4：代码写在了错误的位置
**原因**：把内容写在了 `<head>` 里而不是 `<body>` 里。
**解决**：所有页面可见内容（文字、图片、按钮等）都必须在 `<body>` 和 `</body>` 之间。`<head>` 里只放元信息（标题、编码、样式链接等）。
