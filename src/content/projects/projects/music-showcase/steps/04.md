# 步骤 3：排版细节打磨

---

## 这一步在做什么

现在卡片的大框架已经很好看了，但"代表作品"列表区域还比较普通。这一步我们来精细打磨——给列表区域增加视觉区分、调整列表样式、让每个细节都经得起细看。

---

## 为什么这一步很重要

一句话概括：**普通开发者和优秀开发者的区别，往往就在细节上。**

如果你打开任何一款精美的 App 或网页，仔细观察会发现，它好看的原因往往不是用了什么炫酷的技术，而是：间距恰到好处、颜色层次分明、每个区块的视觉权重主次清晰。

这一步你要练习的，就是这种"把已经能用的东西打磨到好看"的能力。

---

## 具体操作

### 1. 美化代表作品区域

在 `<style>` 标签中，添加以下样式：

```css
/* ====== 代表作品区域 ====== */
.works-section {
  /* 给作品区域一个和卡片主体不同的背景色 */
  background: #FBF7F0;       /* 比卡片主体再淡一点 */

  /* 圆角 */
  border-radius: 12px;

  /* 内边距——让列表不要贴在区域边缘 */
  padding: 16px 20px;

  /* 文字靠左——列表通常靠左更好读 */
  text-align: left;

  /* 上方留出间距，和简介分开 */
  margin-top: 24px;
}

.works-section h2 {
  /* 小标题样式 */
  font-size: 16px;           /* 比卡片主标题小 */
  color: #8B7355;            /* 柔和的棕色 */
  margin-top: 0;             /* 去掉默认的上边距 */
  margin-bottom: 12px;       /* 和下方面列表保持距离 */
  text-align: center;        /* 小标题居中 */
}
```

### 2. 美化列表和列表项

继续添加：

```css
/* ====== 列表样式 ====== */
.works-section ul {
  /* 去掉默认样式 */
  list-style: none;          /* 去掉默认的黑色圆点 */
  padding-left: 0;           /* 去掉默认的左内边距 */
  margin: 0;
}

.works-section li {
  /* 每个列表项的样式 */
  padding: 8px 0;            /* 上下各8px的内边距 */
  color: #5D4E37;            /* 文字颜色 */
  font-size: 15px;

  /* 下划线分隔——让每首曲子有清晰的分隔 */
  border-bottom: 1px dashed #E8D5C4;
  /* dashed = 虚线，solid = 实线，dotted = 点线 */
}

.works-section li:last-child {
  /* 最后一个列表项不需要下划线 */
  border-bottom: none;
}
```

### 3. 用音乐符号替换列表标记

默认的 `<li>` 前面没有任何标记了（因为我们在上一步用了 `list-style: none`）。现在我们用 CSS 的 `::before` 伪元素来添加音乐符号：

```css
.works-section li::before {
  /* ::before 会在每个 li 的内容前面插入东西 */
  content: "♪  ";            /* 插入音乐符号和空格 */
  color: #C9A87C;            /* 金色 */
  font-size: 14px;
}
```

> **伪元素是什么？** `::before` 和 `::after` 是 CSS 的"虚拟元素"——它们不需要在 HTML 中写任何东西，就能在指定元素的前面或后面插入内容。这里我们用 `::before` 在每个列表项前面放一个音符符号。

### 4. 添加一个小小的悬停效果（可选）

鼠标划过列表项时，让它微微变化，给页面增加一点互动感：

```css
.works-section li:hover {
  /* 鼠标悬停时的效果 */
  background: #FFF8F0;       /* 背景微微变亮 */
  padding-left: 8px;         /* 文字微微右移 */
  transition: all 0.2s ease; /* 让变化过程平滑过渡，0.2秒完成 */
}
```

> `transition` 属性的作用：让 CSS 属性的变化不是瞬间发生的，而是在指定时间内平滑过渡。这里 `0.2s` 表示 0.2 秒，`ease` 表示先快后慢的缓动效果。

### 5. 完整样式总览

到这里，你的 `<style>` 标签内应该有完整的样式代码。全部合在一起大致如下：

```css
.composer-card {
  max-width: 400px;
  margin: 40px auto;
  padding: 30px 24px;
  background: #FFF8F0;
  border-radius: 16px;
  box-shadow: 0 4px 20px rgba(0, 0, 0, 0.10);
  text-align: center;
  font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
}

.composer-photo {
  width: 180px;
  height: 180px;
  object-fit: cover;
  border-radius: 50%;
  border: 4px solid #E8D5C4;
  margin-bottom: 16px;
}

.composer-bio {
  color: #5D4E37;
  line-height: 1.8;
  font-size: 15px;
  margin: 12px 0 20px 0;
}

.works-section {
  background: #FBF7F0;
  border-radius: 12px;
  padding: 16px 20px;
  text-align: left;
  margin-top: 24px;
}

.works-section h2 {
  font-size: 16px;
  color: #8B7355;
  margin-top: 0;
  margin-bottom: 12px;
  text-align: center;
}

.works-section ul {
  list-style: none;
  padding-left: 0;
  margin: 0;
}

.works-section li {
  padding: 8px 0;
  color: #5D4E37;
  font-size: 15px;
  border-bottom: 1px dashed #E8D5C4;
}

.works-section li:last-child {
  border-bottom: none;
}

.works-section li::before {
  content: "♪  ";
  color: #C9A87C;
  font-size: 14px;
}

.works-section li:hover {
  background: #FFF8F0;
  padding-left: 8px;
  transition: all 0.2s ease;
}
```

### 6. 保存并刷新查看

按 `Ctrl+S` 保存，切换到浏览器刷新（`F5`）。

---

## 你应该看到什么

- 代表作品区域有了**独立的淡色背景**，和卡片主体有清晰的视觉区分
- 列表项之间有**虚线分隔**
- 每行前面有**音乐符号** ♪
- 鼠标划过列表项时，背景微微变亮，文字微微右移（过渡平滑）
- 整体页面看起来更像一张精心设计的**节目单内页**

## 这一步的常见错误

### 错误 1：音乐符号不显示
**原因**：`::before` 写成了 `:before`（虽然大多数浏览器两种都支持，但标准的写法是双冒号），或者 `content` 属性被遗漏。
**解决**：确认写的是 `::before`，并且有 `content` 属性。没有 `content` 的伪元素不会显示任何东西。

### 错误 2：悬停效果不流畅
**原因**：忘记写 `transition` 属性。
**解决**：`transition` 不是必须的，但没有它，悬停变化是瞬间完成的，看起来会"跳"一下。加上 `transition: all 0.2s ease;` 就能平滑过渡。

### 错误 3：最后一个列表项仍然有下划线
**原因**：没写 `:last-child` 选择器，或者选择器的优先级被覆盖了。
**解决**：确认 `.works-section li:last-child` 写在了 `.works-section li` 的**后面**。CSS 的规则是：选择器优先级相同时，后写的覆盖先写的。

### 错误 4：列表项左边空出了大片空白
**原因**：浏览器的默认样式给 `<ul>` 加了 `padding-left: 40px`，如果你没有写 `padding-left: 0` 但写了 `list-style: none`，列表标记被隐藏了但缩进还在。
**解决**：同时设置 `list-style: none` 和 `padding-left: 0`。
