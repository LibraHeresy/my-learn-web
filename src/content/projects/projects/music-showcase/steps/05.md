# 步骤 4：个性化定制

---

## 这一步在做什么

把贝多芬换成**你自己喜欢的音乐家**（或其他任何你想展示的人），然后自由调整颜色、布局和内容，让这张名片真正成为**你的作品**。

---

## 为什么这一步很重要

到现在为止，你一直在跟着教程写代码。这一步，角色转变了——**你从"照着做"变成"自己决定"**。

实际工作中，没有哪个前端开发者是"把所有代码背下来然后默写"的。真正的能力是：**知道改哪里能达到什么效果，然后去试**。这一步就是在训练这种"尝试-观察-调整"的能力。

而且，当名片上是你真正喜欢的人时，你会更有动力把它做好——你是在为自己工作，不是在为作业工作。

---

## 具体操作

### 1. 换一个人

在 HTML 中，修改以下内容：

**（1）换照片**

在 `index.html` 中找到 `<img>` 标签的 `src` 属性。把贝多芬的图片链接换掉：

```html
<!-- 方法一：使用网络图片 -->
<img src="你找的新图片链接" alt="你选的音乐家名字" class="composer-photo">

<!-- 方法二：使用本地图片 -->
<!-- 先把图片放到和 index.html 同一个文件夹里，然后： -->
<img src="mozart.jpg" alt="沃尔夫冈·阿马德乌斯·莫扎特" class="composer-photo">
```

**去哪里找图片？**
- 在百度或 Google 图片搜索"[音乐家名字] portrait"
- 右键图片 → 复制图片地址
- 粘贴到 `src` 属性中
- 或者把图片下载下来，放在和 `index.html` 同一个文件夹里，`src` 直接写文件名

**（2）换名字**

找到 `<h1>` 标签，把"路德维希·凡·贝多芬"改成你选的人：

```html
<h1>沃尔夫冈·阿马德乌斯·莫扎特</h1>
```

**（3）换简介**

找到 `<p class="composer-bio">` 标签，改写成这个人的简介：

```html
<p class="composer-bio">
  奥地利作曲家，古典主义时期的代表人物。他5岁开始作曲，
  一生创作了600多部作品，涵盖了交响曲、歌剧、协奏曲等多种体裁。
</p>
```

**（4）换代表作品**

找到 `<ul>` 里的每一个 `<li>`，换成这个人的作品：

```html
<ul>
  <li>g小调第40号交响曲</li>
  <li>歌剧「费加罗的婚礼」</li>
  <li>歌剧「魔笛」</li>
  <li>C大调第21号钢琴协奏曲</li>
  <li>安魂曲 K.626</li>
</ul>
```

### 2. 换配色方案

在 `<style>` 标签中，找到颜色相关的属性，改成你喜欢的搭配。以下是一些可参考的方案：

**方案 A：优雅深蓝（适合古典、沉静的感觉）**

```css
.composer-card {
  background: #F0F4F8;       /* 淡蓝灰色背景 */
}
.composer-photo {
  border: 4px solid #BCCCDC; /* 浅蓝灰边框 */
}
.works-section {
  background: #F7FAFC;       /* 更淡的蓝灰 */
}
.works-section h2 {
  color: #4A5568;            /* 深灰蓝 */
}
```

**方案 B：温暖复古（适合浪漫主义音乐家）**

```css
.composer-card {
  background: #FDF6EE;       /* 奶油色 */
}
.composer-photo {
  border: 4px solid #D4A574; /* 暖棕色 */
}
.works-section {
  background: #FFF8F0;
}
.works-section h2 {
  color: #A0522D;            /* 赭色 */
}
```

**方案 C：简约黑白（现代感）**

```css
.composer-card {
  background: #FFFFFF;
  box-shadow: 0 2px 12px rgba(0, 0, 0, 0.08);  /* 更轻的阴影 */
}
.composer-photo {
  border: 4px solid #E2E8F0;
}
.works-section {
  background: #F7FAFC;
}
.works-section h2 {
  color: #2D3748;
}
```

> 你的配色不一定是以上方案之一——大胆尝试！改了颜色 → 刷新 → 看看效果 → 不满意再改。这就是 CSS 的乐趣所在。

### 3. 调整布局参数（可选练习）

试着修改以下数值，观察页面的变化：

| 修改什么 | 在哪里改 | 试试改成 | 观察效果 |
|----------|---------|----------|---------|
| 卡片宽度 | `.composer-card` 的 `max-width` | `500px` | 卡片变宽了 |
| 圆角大小 | `.composer-card` 的 `border-radius` | `4px` | 角变得很方 |
| 圆角大小 | `.composer-card` 的 `border-radius` | `30px` | 角变得很圆 |
| 照片大小 | `.composer-photo` 的 `width/height` | `120px` | 照片变小了 |
| 卡片边距 | `.composer-card` 的 `margin` | `20px auto` | 卡片离顶部更近 |
| 阴影深浅 | `box-shadow` 最后的透明度 | `0.25` | 阴影变深了 |

### 4. 添加更多内容（挑战任务）

如果你想让名片更丰富，可以在 HTML 中添加更多信息区块。以下是一些思路：

**添加生卒年份：**

```html
<p class="composer-dates">1756 年 — 1791 年</p>
```

在 CSS 中给它样式：

```css
.composer-dates {
  color: #A09080;
  font-size: 14px;
  margin: 0 0 8px 0;
}
```

**添加外部链接：**

```html
<a href="https://zh.wikipedia.org/wiki/莫扎特" target="_blank" class="more-link">
  了解更多 →
</a>
```

```css
.more-link {
  display: inline-block;
  margin-top: 16px;
  color: #8B7355;
  text-decoration: none;
  border-bottom: 1px solid #D4C4B0;
  padding-bottom: 2px;
}
.more-link:hover {
  color: #5D4E37;
  border-bottom-color: #5D4E37;
}
```

## 你应该看到什么

- 贝多芬被替换成了你选择的人物
- 照片、名字、简介、作品列表全部更新
- 配色方案发生了变化（如果你改过颜色）
- 页面的整体感觉已经和教程示例完全不同——它现在是**你的**作品了

## 这一步的常见错误

### 错误 1：换了图片链接但图片不显示
**原因 1**：图片链接本身失效或需要登录才能访问。
**解决**：在浏览器地址栏中直接打开图片链接，确认能访问。百度图片的链接有时会失效，推荐去 Wikipedia 或 Unsplash 找图。

**原因 2**：本地图片，但文件名或路径写错了。
**解决**：确认图片文件和 `index.html` 在同一个文件夹里。Windows 默认隐藏文件扩展名——你的图片可能叫 `mozart.jpg`，但文件名里其实写的是 `mozart`，需要确认扩展名是否一致（`.jpg`、`.png`、`.webp` 等）。

### 错误 2：改了 CSS 但颜色看起来没变化
**原因**：可能改错了选择器，或者改的属性和其他地方的属性冲突了。
**解决**：在浏览器中按 `F12` 打开开发者工具 → 点击"元素"（Elements）标签 → 找到你的卡片元素 → 右侧会显示它当前应用了哪些 CSS 规则。检查你写的规则是否被列出来，是否被别的规则覆盖了（覆盖的规则会有一条删除线）。

### 错误 3：添加了新的 HTML 内容但没有样式
**原因**：新内容没有对应的 CSS 规则。
**解决**：给新内容加上 `class`，然后在 `<style>` 中写对应的样式规则。记住：每个你想美化的元素都需要一个 CSS 选择器来"选中"它。
