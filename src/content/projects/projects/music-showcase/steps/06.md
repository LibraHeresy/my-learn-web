# 步骤 5：收尾与测试

---

## 这一步在做什么

用最后一点时间检查页面在不同情况下的表现——浏览器宽度变化时会不会坏掉？图片加载失败时有没有备选方案？有没有什么小细节可以再打磨一下？

---

## 为什么这一步很重要

专业的前端开发者不会只在自己的电脑上、用全屏浏览器看自己的页面。他们会模拟各种情况：

- 屏幕小了怎么办？（手机用户、分屏工作的人）
- 图片加载不出来怎么办？（网络慢、链接失效）
- 代码干净吗？（自己能看懂、别人也能看懂）

这一步花 10 分钟做检查，比未来某天发现"我的页面在别人电脑上看是坏的"要好得多。

---

## 具体操作

### 1. 测试不同浏览器宽度

在浏览器中打开你的页面，然后**手动调整浏览器窗口的宽度**——把窗口从宽拖到窄，观察卡片的表现：

**你应该看到的：**
- 因为卡片设置了 `max-width: 400px`（或你改成的其他值），当窗口宽度大于这个值时，卡片保持固定宽度居中
- 当窗口宽度小于这个值时（比如窗口缩到 350px），卡片会自动缩小以适应窗口
- 图片会自动等比例缩小

**如果卡片在小窗口下溢出或变形：**
- 检查 `<head>` 中是否有 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`——这一行是让移动端浏览器正确缩放的关键
- 如果没有这行，加上它

### 2. 测试图片加载失败的情况

**临时模拟图片加载失败：** 暂时把你 `<img>` 标签的 `src` 改成一个不存在的文件名，比如 `src="nothing.jpg"`。刷新页面观察：

**你应该看到的：**
- 照片位置不应该是一片空白——浏览器应该显示一个占位图标或 `alt` 属性中的文字
- 如果 `alt` 文字没有完全显示，考虑调整一下图片容器的样式

**修复方案：** 给 `.composer-photo` 添加备用样式，让它在图片加载失败时也不难看：

```css
.composer-photo {
  /* ...原有样式保持不变... */

  /* 图片加载失败时的备用背景 */
  background: #E8D5C4;
  /* 当图片无法显示时，会露出这个背景色，不会是一片空白 */

  /* 如果图片加载失败，让 alt 文字稍微可见 */
  display: block;
}
```

测试完记得把 `src` 改回正确的图片链接。

### 3. 检查代码整洁度

从头到尾快速浏览一遍你的代码，检查以下几点：

**HTML 检查清单：**
- [ ] 每个开标签都有对应的闭标签（如 `<div>` 有 `</div>`）
- [ ] 属性值都用引号包裹（如 `class="composer-card"` 不是 `class=composer-card`）
- [ ] `<img>` 标签有 `alt` 属性
- [ ] 缩进大致一致（VS Code 可以按 `Shift+Alt+F` 自动格式化）

**CSS 检查清单：**
- [ ] 每个 CSS 规则的花括号 `{ }` 是成对出现的
- [ ] 每个属性后面有分号 `;`
- [ ] 颜色值 `#` 后面是 6 位或 3 位字符（如 `#FFF8F0` 或 `#FFF`）
- [ ] 选择器名称和 HTML 中的 class 完全一致

### 4. 用浏览器开发者工具检查（可选但推荐）

在浏览器中按 `F12` 打开开发者工具，然后：

**（1）检查元素：**
- 点击开发者工具左上角的"选择元素"图标（或按 `Ctrl+Shift+C`）
- 把鼠标移到页面上的不同元素上
- 左侧面板会高亮显示对应的 HTML 代码
- 右侧面板会显示该元素应用的所有 CSS 规则

**（2）检查布局：**
- 在右侧面板中找到"计算后样式"（Computed）标签
- 可以看到每个 CSS 属性的最终值

**（3）模拟手机：**
- 点击开发者工具中的"切换设备工具栏"图标（或按 `Ctrl+Shift+M`）
- 选择一种手机型号（如 iPhone 12）
- 查看页面在手机上的显示效果

> 开发者工具是前端工程师最常用的工具之一。现在你不需要完全掌握它，但知道怎么打开它、怎么看元素的样式，会在你遇到"为什么这个样式没生效"的问题时帮大忙。

### 5. 可选增强：添加页面标题图标（favicon）

在 `<head>` 中添加一行，让浏览器标签页上显示一个小图标：

```html
<link rel="icon" href="data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 100 100'><text y='.9em' font-size='90'>🎵</text></svg>">
```

这行代码用了一个小技巧：直接在 HTML 中内嵌了一个 SVG 图标（音乐符号 🎵），不需要单独的图标文件。刷新后看看浏览器标签页——音乐符号出现在标题前面了。

---

## 你应该看到什么

- 页面在窄窗口下能正常显示，内容不会溢出或被截断
- 即使图片加载失败，照片位置也有一个背景色占位
- 代码整洁、缩进一致
- 所有 CSS 规则都正确生效

---

## 这一步的常见错误

### 错误 1：缩窄窗口后页面出现横向滚动条
**原因**：某个元素的宽度超过了窗口宽度。
**解决**：检查是否有元素设置了固定的 `width`（如 `width: 500px`）而没有用 `max-width`。在小项目中，推荐使用 `max-width` 而不是 `width`——前者是"不超过"，后者是"固定"。

### 错误 2：自动格式化后代码还是乱
**原因**：VS Code 可能没有识别到文件类型。
**解决**：确认文件后缀是 `.html`。点击 VS Code 右下角的"纯文本"或"Plain Text"，在弹出的语言选择中选"HTML"。

### 错误 3：开发者工具里看到的样式和文件里写的不一样
**原因**：浏览器缓存了旧版本的 CSS。
**解决**：在开发者工具打开的情况下，右键点击刷新按钮，选择"清空缓存并硬性重新加载"（Chrome/Edge），或者在刷新时按住 `Ctrl+Shift+R`。
