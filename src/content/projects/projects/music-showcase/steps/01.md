# 项目介绍：音乐家名片页

欢迎来到你的第一个网页项目！从这里开始，你不再只是做练习，而是开始构建一件真正可以展示给他人的完整作品。

---

## 你将构建什么

一张**音乐家个人名片页**——就像你在音乐会节目单上看到的作曲家介绍。页面包含：

- 音乐家的**照片**
- 音乐家的**姓名**（大标题）
- 一段**简介文字**
- 一份**代表作品列表**
- 精美的**卡片式布局**——配色、圆角、阴影

最终效果是一张可以独立打开的 HTML 页面，你可以把它分享给任何人，他们只需用浏览器打开就能看到。

---

## 为什么这个项目很重要

这是你学习前端开发的**第一个里程碑**。它把你在课程中学到的零散知识点——HTML 标签、CSS 样式、图片和链接——缝合成了一个整体。

具体来说，你将练习：

| 能力 | 在这个项目中的体现 |
|------|-------------------|
| **信息组织** | 把标题、简介、图片、列表组织成有层级的页面结构 |
| **视觉设计** | 通过颜色、留白、圆角、阴影让页面"像那么回事" |
| **代码与效果的对应** | 每写一行 CSS，立刻在浏览器看到变化 |
| **独立完成** | 从空白文件开始，不依赖在线编辑器，一步步构建 |

---

## 建议的前置学习

在开始这个项目之前，建议你已经完成了以下课程内容（不是强制要求，但会让你更顺利）：

1. **《认识 HTML》**——知道 `h1`、`p`、`ul`、`li`、`div`、`img` 这些基本标签的用法
2. **《图片与链接》**——知道如何用 `img` 标签引入图片，了解 `src` 和 `alt` 属性
3. **《CSS 入门》**——了解选择器、属性、值的基本概念，知道怎么写 `style` 标签
4. **《Flexbox 入门》**（可选）——虽然不是本项目的核心，但理解弹性布局对后续项目有帮助

> 如果你还没学完这些内容也没关系——你可以一边做项目，一边回去查课程内容。这是完全正常的开发流程：遇到不会的就去查。

- **如果你边做边学**：可能需要 1-2 小时（这完全正常！）

## 三级完成线

我们不要求每个人都做到一样的程度。根据自己的情况选择目标：

### 第一级：最低完成线（必须达到）
- 页面包含**姓名、简介、照片、代表作列表**四块内容
- 内容有基本的 CSS 样式（不再是默认的浏览器样式）
- 页面可以在浏览器中正常打开和查看

### 第二级：标准版（推荐目标）
- 卡片有**配色方案**（背景色、字体色搭配协调）
- 有**圆角和阴影**，卡片有"浮起来"的视觉效果
- 代表作列表排版整齐，与卡片主体有视觉区分
- 换成了**你自己喜欢的音乐家**（不再用示例人物）

### 第三级：挑战版（学有余力）
- 使用了语义化标签（如 `<main>`、`<section>`、`<article>`）
- 添加了更多信息区块（如生卒年份、国籍、著名乐章推荐）
- 添加了外部链接（如维基百科或音乐平台链接）
- 在手机宽度下也能正常显示（响应式）

## 项目步骤总览

| 步骤 | 内容 |
|------|------|
| 步骤 1 | 搭建 HTML 结构——写出卡片的所有内容 |
| 步骤 2 | CSS 基础美化——配色、圆角、阴影 |
| 步骤 3 | 排版细节打磨——列表样式、留白调整 |
| 步骤 4 | 个性化定制——换成你自己的音乐家 |
| 步骤 5 | 收尾与测试——检查兼容性、添加细节 |
| 步骤 6 | 最终回顾——自查清单与下一步 |

---

## 开始前的准备

你只需要：

1. **一个代码编辑器**——推荐 [VS Code](https://code.visualstudio.com/)（免费）
2. **一个浏览器**——Chrome、Edge 或 Firefox 都可以
3. **一个空白文件夹**——在你的电脑上创建一个文件夹，比如叫 `music-showcase`
4. **在这个文件夹里新建一个文件**，命名为 `index.html`

准备好了吗？前往步骤 1，开始构建你的第一张网页名片！
