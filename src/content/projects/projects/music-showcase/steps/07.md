## 这个项目中你学到的最重要的三件事

### 1. 信息结构
你学会了用 HTML 标签把不同性质的内容（标题、简介、图片、列表）组织成有层级的结构。`h1` > `h2` > `p` > `li`，这种层级关系不是随意的——它告诉浏览器"这是什么"，也告诉阅读你代码的人"这是什么"。

### 2. 视觉判断
你开始为了可读性和风格统一去控制颜色、留白和卡片感，而不是只把内容堆上去。CSS 不是玄学——每一个属性都有明确的作用，改一个值就有一个对应的视觉变化。你练习了"改了 → 刷新 → 看效果 → 再调"这个循环，这就是前端开发者的核心工作模式。

### 3. 个人表达
你已经不只是照着例子写页面，而是在用自己真正关心的对象做展示。从"教程让我写贝多芬"到"我选择展示莫扎特/肖邦/周杰伦/我自己喜欢的人"——这就是从练习到作品的跨越。

## 如果卡住了

如果你自查后发现某些项目没通过，回到对应的步骤重新检查：

| 问题 | 回去看 |
|------|--------|
| HTML 结构不完整 | 步骤 1 |
| 样式不生效或效果不对 | 步骤 2 和步骤 3 |
| 想换内容但不知道改哪里 | 步骤 4 |
| 小窗口下页面坏了 | 步骤 5 |

最常见的问题来源（按频率排序）：
1. **class 名称不一致**——HTML 中的 `class="xxx"` 和 CSS 中的 `.xxx` 是否完全一致（包括大小写、连字符）？
2. **分号遗漏**——CSS 属性后面是否都有 `;`？
3. **标签没闭合**——`<div>` 是否有对应的 `</div>`？
4. **选择器写错**——`.classname`（类选择器）和 `#idname`（ID 选择器）是否混淆？

诊断方法：在浏览器中按 `F12` → Elements 标签 → 点击你的卡片元素 → 看右侧 Styles 面板。如果某条 CSS 规则被划了删除线，说明它被其他规则覆盖了。如果某条规则根本没出现，说明选择器没匹配上。
