你的项目在本地已经管理得很好了——现在是时候把它发表到 GitHub 上，让世界看到你的作品。
**第一步：在 GitHub 创建远程仓库**
1. 打开 [github.com](https://github.com)，登录你的账号
2. 点击右上角 ➕ → "New repository"
3. 仓库名：`music-collection`
4. 描述：🎵 我的音乐收藏 — 从 HTML/CSS/JS 到 Vue 组件化的学习之旅
5. 设置为 **Public**
6. **不要勾选** "Add a README file"（因为本地已有项目）
7. 点击 "Create repository"
**第二步：关联并推送**
GitHub 会显示一段命令，复制并在终端中运行：
```bash
git remote add origin https://github.com/你的用户名/music-collection.git
git branch -M main
git push -u origin main
```解释：
- `git remote add origin <URL>` — 告诉 Git"远程仓库的地址"，起名 `origin`
- `git branch -M main` — 确保分支名是 `main`
- `git push -u origin main` — 把本地的所有 commit 推送到 GitHub
刷新 GitHub 页面——你的代码出现了！README 会自动渲染，目录结构清晰可见。
之后每次 commit 后，只需 `git push` 即可同步。
> 🌐 你的代码现在有了一个公开的"家"。GitHub 主页就是程序员的技术名片。
