在继续开发之前，先把 v2 的代码用 Git 管理起来。
打开 VS Code 终端（在项目根目录）：
```bash
# 初始化 Git 仓库
git init
# 查看哪些文件会被追踪
git status
```你会看到一列红色的文件——这些是"未追踪"的文件。
在暂存之前，先创建 `.gitignore` 文件，告诉 Git 哪些不需要管理：
```# .gitignore
node_modules/
dist/
.DS_Store
*.local
````node_modules/` 有几万个文件，绝对不能提交到 Git——别人可以通过 `npm install` 重新下载。
现在做第一次提交：
```bash
git add .
git commit -m "初始化音乐收藏 Vue 项目"
git log --oneline
```你会看到一条 commit 记录，前面有一个哈希值（如 `a1b2c3d`）。这是这次快照的"身份证号"。
> 🎯 每一次 commit 都是一次"存档"。好的 commit 消息就像乐章标题，让你知道这一段写了什么。
