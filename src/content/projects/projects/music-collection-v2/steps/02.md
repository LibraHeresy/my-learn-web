从零开始，用 Vite 脚手架创建一个 Vue 3 项目。
打开终端，运行：
```bash
npm create vite@latest music-collection-vue -- --template vue
cd music-collection-vue
npm install
npm run dev
```你会看到一个熟悉的浏览器页面——和之前「创建第一个 Vue 项目 — Vite 登场」一节讲的完全一样。
现在打开 VS Code，看看 Vite 给你生成了什么：
```music-collection-vue/
├── index.html          # 入口 HTML
├── package.json        # 项目配置和依赖
├── vite.config.js      # Vite 构建配置
├── src/
│   ├── App.vue         # 根组件（你从这里开始改）
│   ├── main.js         # 应用入口
│   ├── components/     # 放组件的文件夹
│   └── assets/         # 放图片等静态资源
``` 🎻 这个脚手架就像一个"空白总谱"——纸张和五线谱已经准备好了，等你来谱写乐章。
