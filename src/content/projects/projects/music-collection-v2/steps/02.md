# 第 2 步：创建 Vue 项目脚手架

## 你要做什么

用 Vite 创建一个全新的 Vue 3 项目，理解生成的每个文件和文件夹是干什么的，然后把项目跑起来。

## 为什么这一步重要

每个 Vue 项目都是从这一步开始的。Vite 生成的项目结构是 Vue 生态的标准约定——理解每个文件夹的作用，后面写代码时你就知道文件该放哪。更重要的是，这一步如果没跑通，后面所有步骤都无法进行。

## 动手操作

### 1. 打开终端

在 VS Code 中按 `` Ctrl+` ``（反引号，在 Tab 键上方），打开内置终端。

你也可以用系统自带的**命令提示符**（CMD）或 **PowerShell**。下面所有命令在这些终端中都能运行。

### 2. 创建项目

一行命令创建项目：

```bash
npm create vite@latest music-collection-vue -- --template vue
```

这条命令拆解如下：

- `npm create vite@latest` — 用 Vite 脚手架创建新项目，"@latest"确保用最新版
- `music-collection-vue` — 项目文件夹名字，你可以改成你喜欢的名字
- `-- --template vue` — 使用 Vue 模板（Vite 也支持 React、Svelte 等）
  - 注意是**两个横线** `--`：第一个 `--` 是 npm 的参数分隔符，`--template vue` 才是传给 Vite 的参数

### 3. 进入项目并安装依赖

```bash
cd music-collection-vue      # 进入项目文件夹
npm install                   # 安装所有依赖包
```

`cd` 命令是 "change directory"（切换目录）的缩写。**这是新手最常忘记的一步**——创建完项目后，你的终端还在上一层目录，必须先 `cd` 进去才能执行后续命令。

`npm install` 会读取 `package.json` 中列出的所有依赖包，从 npm 仓库下载到 `node_modules/` 文件夹。这个文件夹会下载几百个包，这是正常的。

### 4. 启动开发服务器

```bash
npm run dev
```

终端会输出类似这样的信息：

```
VITE v5.x.x  ready in 300 ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

按住 `Ctrl` 点击 `http://localhost:5173/` 这个链接（或者在浏览器地址栏手动输入），你应该能看到一个 Vue 的欢迎页面，上面有 Vue 的 logo 和一些链接。

**如果看到了这个页面——恭喜，项目创建成功！**

### 5. 理解项目结构

现在打开 VS Code，看看 Vite 生成了什么。在左侧文件列表中找到 `music-collection-vue` 文件夹。没有就不用管。每个文件和文件夹都在我们即将用到的时候再做说明。

```
music-collection-vue/
├── index.html              # 入口 HTML 文件
├── package.json            # 项目配置：名字、版本、依赖、脚本命令
├── vite.config.js          # Vite 构建工具的配置文件
├── src/                    # 所有源代码都在这里
│   ├── main.js             # 应用的 JS 入口文件
│   ├── App.vue             # 根组件（从这里开始改）
│   ├── components/         # 放 Vue 组件的文件夹
│   └── assets/             # 放图片、字体等静态资源
```

你现在需要知道的重点：

| 文件/文件夹 | 你接下来会做什么 | 现在不用管 |
|------------|----------------|-----------|
| `src/App.vue` | **下一步就要改它**——这是整个应用的起点 | - |
| `src/components/` | 你的 MusicCard、FilterBar、AddForm 都放这 | - |
| `src/main.js` | 应用的启动文件，**本期不需要改** | 它负责创建 Vue 应用并挂载到页面 |
| `index.html` | 入口 HTML | **不要改它**——Vite 会自动处理 |
| `vite.config.js` | Vite 构建配置 | 暂时不改，部署时才需要配 |
| `package.json` | 项目元信息 | 了解就好，不要随意删改 |

**注意**：不要着急去修改 `index.html` 或 `main.js`——整个 v2 项目的开发都在 `src/` 文件夹内进行，Vite 已经帮你配好了入口文件。

### 6. 清理模板内容（为下一步做准备）

打开 `src/App.vue`，你会看到模板自动生成的欢迎页面代码。**把它们全部删掉**，替换成最简结构，这样下一步我们好开始写自己的代码：

```vue
<script setup>
// 第 3 步开始在这里写代码
</script>

<template>
  <div class="app">
    <h1>🎵 我的音乐收藏</h1>
    <!-- 第 3 步开始在这里添加组件 -->
  </div>
</template>

<style>
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

.app {
  max-width: 1200px;
  margin: 0 auto;
  padding: 20px;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
}

h1 {
  text-align: center;
  margin-bottom: 30px;
  color: #333;
}
</style>
```

保存文件（`Ctrl+S`），回到浏览器 `http://localhost:5173/`，你应该看到：一个居中的标题"🎵 我的音乐收藏"，下面什么都没有（暂时）。这就是你接下来要往里面填内容的画布。

**如果浏览器页面没有自动更新**：检查 Vite 开发服务器是否还在运行（终端里有没有报错）。如果停了，再运行一次 `npm run dev`。

## 预期结果

- 浏览器打开 `http://localhost:5173/`，显示"🎵 我的音乐收藏"标题
- VS Code 中 `src/App.vue` 的内容是你刚替换的最简结构
- 终端中 Vite 开发服务器正在运行，没有报错

## 常见错误

- **错误**：创建项目后忘了 `cd music-collection-vue` 就直接 `npm install`。**后果**：在错误的目录安装依赖，项目目录里没有 `node_modules/`，`npm run dev` 会报错 `missing script: dev`。**解决**：先用 `ls`（Unix）或 `dir`（Windows）确认当前目录下有没有 `package.json` 文件。
- **错误**：忘写 `--` 双横线，写成 `npm create vite@latest my-app --template vue`（单横线）。**后果**：npm 可能把 `--template vue` 当成自己的参数而非传给 Vite，导致创建失败。**解决**：复制命令时注意是两个短横 `--`。
- **错误**：`npm install` 中途因为网络问题中断。**后果**：`node_modules/` 不完整，`npm run dev` 报错说找不到某个包。**解决**：删掉 `node_modules/` 文件夹，重新运行 `npm install`。如果网络始终不行，可以换成国内镜像：`npm config set registry https://registry.npmmirror.com` 再重试。
- **错误**：改了 `App.vue` 但浏览器没变化。**可能原因 1**：文件没保存（VS Code 文件名旁边有个白点表示未保存）。**可能原因 2**：开发服务器挂了（终端里有报错）。**解决**：按 `Ctrl+S` 保存，再到终端看 Vite 是否还在跑。
