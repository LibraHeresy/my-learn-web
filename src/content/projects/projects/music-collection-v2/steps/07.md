现在来到最关键的一步——在 App.vue 中把所有组件组装起来，让它们协同工作。
App.vue 扮演"指挥"的角色：
1. **拥有所有数据**——`pieces` 数组（ref）和 `selectedPeriod` 状态（ref）
2. **用 computed 做筛选**——根据 `selectedPeriod` 从 `pieces` 中筛出要显示的曲目
3. **用 v-for 渲染卡片**——遍历筛选结果，给每个 MusicCard 传 props
4. **处理子组件的事件**——`@add`、`@toggle-like`、`@delete`

```vue
<script setup>
import { ref, computed } from 'vue'
```

注意 `periods` 这个 computed：它从 pieces 中**自动提取**所有不重复的时期——以后添加了新时期的曲目，筛选按钮会自动出现。这就是"数据驱动"的威力。
