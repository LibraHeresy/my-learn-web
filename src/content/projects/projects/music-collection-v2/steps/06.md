# 第 6 步：添加表单组件 —— v-model 与事件

## 你要做什么

创建 AddForm 组件，让用户可以通过表单输入新曲目的信息。用 `v-model` 实现双向数据绑定，用 emit 把新数据发给父组件。

## 为什么这一步重要

`v-model` 是 Vue 中使用频率最高的指令之一。它把"读取输入框的值"和"把值写回输入框"两件事合并到一个指令里。对比 v1 中你需要 `document.getElementById('xxx').value` 来手动取值，`v-model` 让表单处理变得极其简洁。这一步也是你第一次让子组件"往上传数据"——添加功能是子组件发出数据、父组件接收并处理，这个模式和后面的删除/收藏完全一致。

## 动手操作

### 1. 创建 AddForm.vue

在 `src/components/` 文件夹中新建 `AddForm.vue`：

```vue
<script setup>
import { ref } from 'vue'

const emit = defineEmits(['add'])

// 四个表单字段
const name = ref('')
const composer = ref('')
const image = ref('')
const period = ref('')

// 可选的时期列表（和筛选用的同一套，方便用户选择）
const periodOptions = ['巴洛克', '古典主义', '浪漫主义', '现代主义']

function handleSubmit() {
  // 简单验证：曲名和作曲家不能为空
  if (!name.value.trim()) {
    alert('请输入曲名')
    return
  }
  if (!composer.value.trim()) {
    alert('请输入作曲家')
    return
  }

  // 组装新曲目对象
  const newPiece = {
    id: Date.now(),                    // 用时间戳生成唯一 ID
    name: name.value.trim(),
    composer: composer.value.trim(),
    image: image.value.trim() || 'https://picsum.photos/seed/default/200/200',  // 没填图片就用默认图
    period: period.value || '古典主义', // 没选时期就默认古典主义
    liked: false                       // 新添加的曲目默认未收藏
  }

  // 把新数据发给父组件
  emit('add', newPiece)

  // 清空表单
  name.value = ''
  composer.value = ''
  image.value = ''
  period.value = ''
}
</script>

<template>
  <div class="add-form">
    <h2>➕ 添加新曲目</h2>

    <form @submit.prevent="handleSubmit">
      <!-- 曲名 -->
      <div class="form-group">
        <label for="name">曲名 <span class="required">*</span></label>
        <input
          id="name"
          v-model="name"
          type="text"
          placeholder="例如：G大调第一无伴奏大提琴组曲"
        />
      </div>

      <!-- 作曲家 -->
      <div class="form-group">
        <label for="composer">作曲家 <span class="required">*</span></label>
        <input
          id="composer"
          v-model="composer"
          type="text"
          placeholder="例如：巴赫"
        />
      </div>

      <!-- 封面图片 -->
      <div class="form-group">
        <label for="image">封面图片 URL</label>
        <input
          id="image"
          v-model="image"
          type="text"
          placeholder="https://...（留空则使用默认图片）"
        />
      </div>

      <!-- 时期 -->
      <div class="form-group">
        <label for="period">时期 / 风格</label>
        <select id="period" v-model="period">
          <option value="">-- 请选择时期 --</option>
          <option v-for="opt in periodOptions" :key="opt" :value="opt">
            {{ opt }}
          </option>
        </select>
      </div>

      <button type="submit" class="btn-submit">添加曲目</button>
    </form>
  </div>
</template>
```

### 逐行理解——重点关注

**`v-model="name"`** —— vue 的双向绑定：
- 数据 → 视图：`name.value` 是什么，输入框就显示什么
- 视图 → 数据：用户输入内容，`name.value` 自动更新
- 对比 v1：你需要 `const input = document.getElementById('name'); const value = input.value; input.value = '';` 三行代码。现在一行 `v-model` 全部搞定。

**`@submit.prevent="handleSubmit"`** —— `.prevent` 是事件修饰符，等价于 `event.preventDefault()`，阻止表单的默认提交行为（否则页面会刷新）。Vue 提供了一系列事件修饰符：`.stop`（阻止冒泡）、`.once`（只触发一次）、`.enter`（回车键触发）等。

**`id: Date.now()`** —— 为什么用时间戳当 ID？因为添加操作可能在同一毫秒内发生多次（可能性极低但理论上存在），更严谨的做法是用 `crypto.randomUUID()` 或类似 `nanoid` 的库。但对于学习项目，`Date.now()` 足够了。**千万不要用数组长度当 ID**——删除元素后长度会变，导致 ID 重复。

**`emit('add', newPiece)`** —— 把新曲目对象发给父组件。AddForm 不负责把这个对象加到列表里——它只负责"收集数据"和"发送"。加列表是 App.vue 的事。这是**单一职责原则**：每个组件只做一件事。

**清空表单** —— 提交成功后把四个 ref 重置为空字符串。注意：清空发生在 `emit` 之后，不影响发出的数据。

### 2. 在 App.vue 中使用 AddForm

打开 `src/App.vue`，在 `<script setup>` 中添加导入和处理函数：

```vue
<script setup>
import { ref, computed } from 'vue'
import MusicCard from './components/MusicCard.vue'
import FilterBar from './components/FilterBar.vue'
import AddForm from './components/AddForm.vue'

// ... pieces、selectedPeriod、periods、filteredPieces 保持不变

// 处理添加
function addPiece(newPiece) {
  pieces.value.push(newPiece)
}
</script>
```

在 `<template>` 中添加 AddForm 组件（放在 FilterBar 上面）：

```vue
<template>
  <div class="app">
    <h1>🎵 我的音乐收藏</h1>

    <!-- 添加表单 -->
    <AddForm @add="addPiece" />

    <!-- 筛选栏 -->
    <FilterBar
      :periods="periods"
      :active="selectedPeriod"
      @update:active="selectPeriod"
    />

    <!-- 音乐卡片列表 -->
    <div class="card-grid">
      <MusicCard
        v-for="piece in filteredPieces"
        :key="piece.id"
        :id="piece.id"
        :name="piece.name"
        :composer="piece.composer"
        :image="piece.image"
        :period="piece.period"
        :liked="piece.liked"
      />
    </div>
  </div>
</template>
```

**理解数据流**：`AddForm` → emit `add` 事件 → `App.vue` 的 `addPiece` 函数 → `pieces.value.push(newPiece)` → `pieces` 变化 → `filteredPieces` 自动重新计算 → 列表自动更新。

这就是 Vue 的响应式数据流：**数据变了，一切自动跟着变**。

还有一个你不需要手动做的事情：假设你添加了一首"现代主义"的曲目。`periods` 这个 computed 会自动检测到新时期的出现——筛选栏里会自动多出一个"现代主义"按钮。这就是 `computed` 的威力，它让你的 UI 始终保持和数据同步。

## 常见错误

- **错误**：`@submit.prevent` 写成了 `@submit`（少了 `.prevent`）。**后果**：点击提交按钮后页面会刷新（浏览器的默认表单行为），添加的数据丢失。**解决**：始终给表单的 submit 事件加 `.prevent`。
- **错误**：`emit` 的事件名在父子组件中不一致。比如子组件 `emit('add', data)` 但父组件写的是 `@add-piece="handler"`。**后果**：事件发出去了但没人监听，点击按钮后什么都没发生。**解决**：emit 的事件名和 @事件名 必须完全一致（Vue 会自动做驼峰/短横线的转换，但最好保持一致）。
- **错误**：在 `v-model` 绑定的 ref 上忘了在 script 中 `.value`（写成 `name = ''` 而不是 `name.value = ''`）。**后果**：`name` 这个变量本身被替换成了空字符串，不再是一个 ref 对象，表单的双向绑定就断了——之后输入内容不会更新到数据里。**解决**：script 中操作 ref 永远加 `.value`。
- **错误**：用数组长度作为新曲目的 ID（`id: pieces.value.length + 1`）。**后果**：删除中间某条数据后，新添加的曲目 ID 可能与已存在的重复，导致 `:key` 不唯一。**解决**：用 `Date.now()` 或自增计数器。
