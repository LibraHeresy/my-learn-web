# 第 3 步：创建第一个组件 —— MusicCard

## 你要做什么

把 v1 中一张音乐卡片的 HTML 结构转换为一个独立的 Vue 单文件组件（SFC），用 **Props** 从父组件接收数据。

## 为什么这一步重要

这是你写的第一个 Vue 组件。Props 是组件通信的基础——几乎所有 Vue 项目都靠它传递数据。如果 Props 没搞明白，后面的列表渲染、事件通信都会出问题。一张卡片写对了，一百张卡片只是 `v-for` 的事。

## 动手操作

### 1. 创建组件文件

在 `src/components/` 文件夹中新建一个文件 `MusicCard.vue`。

**操作**：在 VS Code 左侧文件列表中，右键点击 `components` 文件夹 → "新建文件" → 输入 `MusicCard.vue`。

### 2. 写模板（Template）

`MusicCard.vue` 的完整内容如下。**不要复制粘贴整段**，跟着下面的说明逐块理解后再写：

```vue
<script setup>
// 定义 Props：从父组件接收的数据
defineProps({
  id: {
    type: Number,
    required: true
  },
  name: {
    type: String,
    required: true
  },
  composer: {
    type: String,
    required: true
  },
  image: {
    type: String,
    required: true
  },
  period: {
    type: String,
    required: true
  },
  liked: {
    type: Boolean,
    default: false
  }
})

// 定义 Emits：通知父组件的事件
const emit = defineEmits(['toggle-like', 'delete'])
</script>

<template>
  <div class="music-card" :class="{ liked: liked }">
    <!-- 封面图 -->
    <div class="card-image">
      <img :src="image" :alt="name" />
    </div>

    <!-- 信息区 -->
    <div class="card-info">
      <h3 class="card-name">{{ name }}</h3>
      <p class="card-composer">{{ composer }}</p>
      <span class="card-period">{{ period }}</span>
    </div>

    <!-- 操作按钮 -->
    <div class="card-actions">
      <button
        class="btn-like"
        :class="{ active: liked }"
        @click="emit('toggle-like', id)"
      >
        {{ liked ? '❤️' : '🤍' }}
      </button>
      <button
        class="btn-delete"
        @click="emit('delete', id)"
      >
        🗑️
      </button>
    </div>
  </div>
</template>
```

### 逐行理解（重要——不要跳过）

**defineProps({...})** —— 声明这个组件需要从外面接收哪些数据：

- `type: Number` / `type: String` —— 规定数据类型。如果父组件传了错误的类型，Vue 会在控制台打印警告，帮你提前发现 bug
- `required: true` —— 这个属性必须传，否则 Vue 也会警告
- `default: false` —— 如果没传，就用默认值。`liked` 是可选的，没传就默认 `false`

**defineEmits(['toggle-like', 'delete'])** —— 声明这个组件会发出哪些事件。这个名字列表有两个作用：
1. 给开发工具（Vue DevTools）提供信息
2. 你自己看代码时一眼就知道这个组件有哪些交互

**@click="emit('toggle-like', id)"** —— 点了收藏按钮后：
- `emit('toggle-like', id)` 的意思是"向父组件发出一个叫 `toggle-like` 的事件，并附带这个卡片的 id"
- 父组件（App.vue）需要监听这个事件并处理——我们现在还没写父组件的处理逻辑，**点击按钮暂时不会有实际效果**，这是正常的。第 7 步会补上

**<style scoped>** —— 注意这个 `scoped` 属性。它让这些 CSS 只作用于当前组件，不会影响其他组件。没有 `scoped` 的话，你给 `.music-card` 写的样式可能会影响其他组件中同样 class 的元素。

**:class="{ liked: liked }"** —— 动态 class 的写法：
- `liked: liked` 左边是 class 名，右边是判断条件
- 当 `liked` 为 `true` 时，给元素加上 `.liked` 这个 class

### 3. 在 App.vue 中使用组件

打开 `src/App.vue`，在 `<script setup>` 中导入组件，在 `<template>` 中使用它：

```vue
<script setup>
import MusicCard from './components/MusicCard.vue'
</script>

<template>
  <div class="app">
    <h1>🎵 我的音乐收藏</h1>

    <!-- 先硬编码一张卡片测试 -->
    <MusicCard
      :id="1"
      name="G大调第一无伴奏大提琴组曲"
      composer="巴赫"
      image="https://picsum.photos/seed/cello/200/200"
      period="巴洛克"
      :liked="true"
    />
  </div>
</template>
```

**关键**：注意 `:id="1"` 和 `:liked="true"` 前面的**冒号** `:`。冒号是 `v-bind:` 的简写，意思是"把引号里的内容当作 JavaScript 表达式来求值"。

- 没有冒号：`name="巴赫"` → 传给组件的是**字符串** "巴赫"
- 有冒号：`:id="1"` → 传给组件的是**数字** 1
- 有冒号：`:liked="true"` → 传给组件的是**布尔值** true

如果写成 `id="1"`（没加冒号），`1` 会被当作字符串 `"1"` 传进去，而你在 `defineProps` 中定义的类型是 `Number`——Vue 会报警告。

### 4. 验证效果

保存 `MusicCard.vue` 和 `App.vue`，回到浏览器 `http://localhost:5173/`。

你应该看到一张完整的音乐卡片：左边是封面图，中间是曲名、作曲家和时期标签，右边是收藏按钮（红色爱心）和删除按钮。

**如果看不到卡片**：按 `F12` 打开浏览器开发者工具，看 Console 面板有没有红色报错。常见原因：
- 组件文件路径写错了（`./components/MusicCard.vue` 少了个 `s` 或多打了个字母）
- 组件内容有语法错误（少了括号、引号不匹配等）
- 图片链接无法访问（Picsum 的链接需要联网）

## 预期结果

- 浏览器中显示一张音乐卡片，包含封面图、曲名、作曲家、时期标签、两个操作按钮
- 点击按钮暂时无反应（正常——事件处理逻辑在第 7 步才写）

## 常见错误

- **错误**：传数字或布尔值时忘了加冒号（`id="1"` 而不是 `:id="1"`）。**后果**：`1` 被当作字符串 `"1"`，Vue 控制台报 "Invalid prop type" 警告。**解决**：所有非字符串类型的 prop 前面必须加 `:`。
- **错误**：在 `<style>` 中忘了加 `scoped`。**后果**：这个组件的样式"泄露"到全局，其他组件也可能被影响，而且你排查时很难发现原因。**解决**：养成习惯，每个组件样式都加 `scoped`。
- **错误**：emit 的事件名用驼峰命名（`toggleLike`），但在父组件中用短横线监听（`@toggle-like`）。Vue 会自动转换，所以两边都能用，但团队协作时最好统一——**推荐在模板中始终使用短横线命名**（kebab-case）：`emit('toggle-like', id)` 对应 `@toggle-like="处理函数"`。
- **错误**：图片链接用了相对路径（如 `image="./covers/bach.jpg"`），但没有把图片放在 `public/` 或 `src/assets/` 中。**后果**：Vite 找不到文件，图片显示为裂图。**解决**：静态资源放在 `src/assets/` 中，用 `import` 导入；或者放在 `public/` 中，用绝对路径 `/covers/bach.jpg` 引用。
