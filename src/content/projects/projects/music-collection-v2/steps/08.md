最后一个关键功能：让数据在刷新后不丢失。
在 v1 中，你手动调用 `localStorage.setItem` 来保存。Vue 有更好的方式——**watch**。
`watch` 会自动"监视"一个响应式数据的变化，并在变化时执行你指定的函数。这就好比请了一个助手，时刻帮你盯着数据，一有变化就自动存档。
```vue
<script setup>
import { ref, watch } from 'vue'
const pieces = ref(loadFromStorage())
// 从 localStorage 读取初始数据
function loadFromStorage() {
  const saved = localStorage.getItem('music-collection')
  return saved ? JSON.parse(saved) : [/* 默认数据 */]
}
// 每当 pieces 变化，自动保存
watch(pieces, (newVal) => {
  localStorage.setItem('music-collection', JSON.stringify(newVal))
}, { deep: true })
</script>
```
注意 `{ deep: true }` ——因为 `pieces` 是一个数组（引用类型），deep 模式让 watch 能检测到数组**内部**的变化（添加、删除、修改元素）。
**对比 v1：**
- v1：每次操作后手动调用保存函数 → 容易忘记
- v2：watch 自动监听 → 永远不会漏掉
